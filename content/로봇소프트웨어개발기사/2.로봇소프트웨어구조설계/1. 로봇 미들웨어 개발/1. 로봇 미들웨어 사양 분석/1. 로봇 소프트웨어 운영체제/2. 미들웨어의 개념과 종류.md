# Summary

**[[미들웨어(Middleware)|미들웨어]]**는 응용 소프트웨어가 운영체제로부터 받는 서비스 이외에 **추가적인 서비스를 제공**하는 소프트웨어로, 서로 다른 소프트웨어·시스템 사이에서 중개 역할을 한다. 로봇에서는 운영 소프트웨어와 센서·액추에이터 응용프로그램 사이를 이어주는 역할을 한다.

# Notes

<aside>미들웨어란 무엇인가</aside>

미들웨어는 응용 소프트웨어(application software)와 운영체제 사이, 또는 서로 다른 응용프로그램 사이에서 **중개 역할**을 하며 추가 서비스를 제공하는 소프트웨어다. 네트워크로 연결된 여러 컴퓨터의 프로세스들에게 특정 서비스를 사용할 수 있도록 이어주는 소프트웨어로도 정의된다.

<aside>로봇에서 미들웨어를 쓰는 이유</aside>

미들웨어(또는 미들웨어를 포함하는 운영체제)를 사용하면 로봇 개발 과정에서 **시간·효율성·신뢰성**을 얻을 수 있다.

| 항목 | 미들웨어 사용 시 | 미들웨어 미사용 시 |
|---|---|---|
| 네트워크·시스템 부하 관리 | 필요한 데이터만 압축해 전송, 부하 분산 가능 | 불필요한 데이터까지 전송, 별도 부하 관리 도구 필요 |
| 분산 트랜잭션 관리 | 분산된 업무를 동시 처리(자료 일관성 유지) | 순차 처리로 동시 처리 불가(자료 불일치 위험) |
| 보안 기능 | 데이터 암호화·사용자 통제 관리 | 보안에 취약 |
| 상호 운용성·확장성 | 다양한 환경·이기종 시스템과 연동 가능 | 동일 환경 간 연동만 가능 |
| 응용프로그램 복잡도 | 클라이언트·서버 프로그램 개발 | 클라이언트 프로그램만 개발(단, 기능 제한) |

이미 안정적으로 검증된 미들웨어를 재사용하면, 매번 새로 소프트웨어를 작성하는 것보다 개발 효율성과 신뢰성을 함께 높일 수 있다 — 안드로이드 운영체제(미들웨어 포함)를 채택해 짧은 기간에 안정적인 제품을 만드는 핸드폰 개발사의 사례와 같은 원리다.

<aside>미들웨어의 대표적인 종류(개념 수준)</aside>

| 종류 | 개념 |
|---|---|
| 데이터베이스 접근 미들웨어 | 응용프로그램의 SQL 요청과 DB 서버 사이의 접근을 쉽게 해주는 미들웨어(JDBC, ODBC 등) |
| 트랜잭션 프로세싱 모니터 | 트랜잭션이 여러 서버를 거치며 완전하게 처리되도록 관리 |
| 분산 컴퓨터 환경(DCE) | 여러 크기의 서버가 지리적으로 흩어진 환경에서 분산 컴퓨팅·데이터 교환을 지원 |
| ORB(Object Request Broker) | 객체 간 클라이언트-서버 관계를 맺어주며, 클라이언트가 객체의 위치·구현 언어를 몰라도 메서드를 호출할 수 있게 함 |
| 원격 프로시저 호출(RPC) | 네트워크상의 다른 컴퓨터 프로그램에 서비스를 요청하는 프로토콜 |
| 메시지 지향 미들웨어(MOM) | 큐(queue)를 이용해 비동기·비연결형으로 메시지를 주고받는 미들웨어 |

"미들웨어를 사용하면 클라이언트 프로그램만 개발해도 모든 기능이 구현된다"는 서술은 오답이다 — 오히려 미들웨어 사용 시에는 클라이언트와 서버(또는 미들웨어와 연동하는) 프로그램을 함께 개발해야 하는 경우가 일반적이다.

<aside>gRPC — RPC 미들웨어의 현대적 구현체</aside>

원격 프로시저 호출(RPC)의 실제 구현 사례로 널리 쓰이는 것이 **gRPC** 다. Google이 개발한 오픈소스 RPC 프레임워크로, HTTP/2 위에서 동작하고 메시지를 **Protocol Buffers(protobuf)** 로 이진 직렬화해 REST/JSON 방식보다 가볍고 빠르다. 여러 프로그래밍 언어로 클라이언트·서버 코드를 자동 생성할 수 있어, 마이크로서비스나 여러 대의 로봇·백엔드 서비스를 연결하는 분산 시스템에서 널리 활용된다.

<aside>예시 — 로봇 시스템에서의 미들웨어 위치</aside>

**예시**: 로봇 소프트웨어는 UX/UI·지능·컨텐츠 같은 상위 응용 소프트웨어와, 모션 제어·액추에이터 제어·센서 인터페이스 같은 하위 로봇 기구/하드웨어 사이에 미들웨어가 위치해, 상위 응용이 하위 하드웨어의 세부 사항을 몰라도 필요한 기능을 호출할 수 있게 중개한다.

---

<aside>핵심 정리</aside>

- 미들웨어는 응용 소프트웨어와 운영체제(또는 다른 응용프로그램) 사이에서 추가 서비스를 제공하는 중개 소프트웨어다
- 미들웨어를 쓰면 부하 관리·분산 트랜잭션·보안·상호 운용성 면에서 이점을 얻지만, 클라이언트 프로그램만 개발하면 되는 것은 아니다
- DB 접근 미들웨어, TP 모니터, DCE, ORB, RPC, 메시지 지향 미들웨어 등 다양한 유형이 있다
- gRPC는 HTTP/2·Protocol Buffers 기반의 현대적인 RPC 구현체로, REST/JSON보다 가볍고 빠르며 여러 언어의 코드를 자동 생성할 수 있다
