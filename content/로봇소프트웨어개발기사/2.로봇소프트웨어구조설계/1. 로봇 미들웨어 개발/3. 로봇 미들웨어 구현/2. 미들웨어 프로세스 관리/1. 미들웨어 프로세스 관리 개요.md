# Summary

미들웨어가 구현된 뒤에는, 실행 중인 여러 프로세스(모듈·컴포넌트)의 **상태를 관리**하고 **메모리·이벤트를 처리**하는 실무적인 문제가 남는다. 이 세세항목은 프로세스 상태 관리, 메모리 관리(가비지 컬렉션), 이벤트 기반 처리를 다룬다.
