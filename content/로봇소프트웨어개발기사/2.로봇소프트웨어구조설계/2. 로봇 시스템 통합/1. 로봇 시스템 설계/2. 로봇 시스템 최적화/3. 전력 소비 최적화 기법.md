# Summary

배터리로 구동되는 로봇에서는 전력 소비 최적화가 곧 가동 시간과 직결되므로, 불필요한 연산·통신·클럭 사용을 줄이는 것이 CPU 최적화 못지않게 중요하다.

# Notes

<aside>전력 소비 최적화 기법</aside>

- **[[DVFS(Dynamic Voltage Frequency Scaling)\|DVFS]]**: 작업 부하에 따라 CPU 클럭 속도와 전압을 동적으로 낮춰 소비 전력을 줄이는 기법
- **저전력 모드 활용**: 유휴 상태(idle)일 때 CPU·주변장치를 저전력/슬립 모드로 전환
- **불필요한 통신 비활성화**: 사용하지 않는 Wi-Fi·Bluetooth 모듈을 꺼서 대기 전력 절감
- **센서 샘플링 주기 조정**: 실시간성이 필요 없는 센서는 샘플링 주기를 늘려 측정·전송 횟수를 줄임
- **이벤트 기반 처리 활용**: 지속적인 폴링 대신 [[3. 가비지 컬렉션과 이벤트 기반 처리\|이벤트 기반 처리]]로 유휴 시간에 CPU를 쉬게 함
- **[[클럭 게이팅과 파워 게이팅(Clock Gating·Power Gating)|클럭 게이팅·파워 게이팅]]**: DVFS가 클럭·전압을 동적으로 낮추는 것과 달리, 아예 쓰지 않는 회로 블록을 끄는 접근 — 클럭 게이팅은 클럭 신호만 차단(빠른 재개), 파워 게이팅은 전원 공급 자체를 차단(누설전력까지 절감하지만 재개가 느림)

"전력 소비를 최적화하려면 배터리 잔량과 관계없이 항상 CPU를 최고 클럭으로 유지해 작업을 빨리 끝내는 것이 유리하다"라는 서술은 오답이다 — 고정된 최고 클럭 유지는 오히려 소비 전력을 늘리며, DVFS처럼 **부하에 맞춰 클럭을 동적으로 낮추는 것**이 전력 최적화의 핵심이다.

<aside>CPU 최적화와의 관계</aside>

CPU 사용률 최적화(폴링 축소, 락 경합 감소 등)는 실행 시간을 줄이는 것 자체로도 전력 소비 감소에 기여한다. 즉, [[2. CPU·메모리 최적화 기법|CPU·메모리 최적화]]와 전력 최적화는 상당 부분 겹치며, DVFS·저전력 모드 같은 전력 특화 기법이 추가되는 구조다.

<aside>예시 — 이동 로봇의 전력 관리</aside>

**예시**: 순찰 로봇이 이동 중이 아닌 대기 상태일 때 모터 드라이버 전원을 차단하고 CPU를 저전력 모드로 전환하며, 배터리 잔량이 낮아지면 DVFS로 클럭을 낮춰 처리 성능은 다소 희생하더라도 가동 시간을 늘리는 전략을 취한다.

---

<aside>핵심 정리</aside>

- 전력 소비 최적화는 DVFS, 저전력 모드, 불필요한 통신·센서 비활성화, 이벤트 기반 처리로 이루어지며, 항상 최고 클럭을 유지하는 것은 최적화가 아니라 오답이다
- CPU 최적화(실행 시간 단축)는 전력 최적화와도 상당 부분 맞닿아 있다
- 클럭 게이팅(클럭만 차단, 빠른 재개)과 파워 게이팅(전원 자체 차단, 누설전력까지 절감하지만 느린 재개)은 DVFS와 달리 쓰지 않는 블록을 끄는 접근이다
