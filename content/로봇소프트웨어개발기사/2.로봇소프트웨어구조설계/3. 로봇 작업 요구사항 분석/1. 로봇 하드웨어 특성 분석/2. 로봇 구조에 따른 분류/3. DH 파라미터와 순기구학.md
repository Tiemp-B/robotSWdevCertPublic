# Summary

**[[DH 파라미터(Denavit-Hartenberg Parameters)|DH 파라미터]]**는 로봇 팔의 각 관절과 링크의 기하학적 관계를 4개의 표준 변수로 표현하는 방법이며, 이를 이용해 관절각에서 말단 위치를 구하는 계산이 **순기구학(Forward Kinematics)**이다.

# Notes

<aside>DH 파라미터의 구성 요소</aside>

DH(Denavit-Hartenberg) 파라미터는 인접한 두 링크 사이의 관계를 4개의 값으로 표현한다. 이 값들은 순전히 **기하학적(위치·각도)** 관계만을 표현하며, 질량·관성 같은 동역학적(dynamics) 속성은 포함하지 않는다 — 질량·관성 등은 동역학 영역에서 다루는 별개의 값이다.

| 파라미터 | 의미 |
|---|---|
| 링크 길이(a, link length) | 두 관절 축 사이의 최단 거리 |
| 링크 비틀림각(α, link twist) | 두 관절 축 사이의 각도 |
| 관절 오프셋(d, link offset) | 링크를 따라 측정한 관절 간 거리 |
| 관절각(θ, joint angle) | 관절의 회전각 |

<aside>순기구학(Forward Kinematics)</aside>

순기구학은 각 [[5. 로봇 모션 기초(좌표계·보간법)\|조인트 좌표계]]의 **관절각을 입력으로 주었을 때, 엔드이펙터의 위치·자세(월드 좌표계 기준)를 계산**하는 것이다. DH 파라미터로 구성한 각 관절의 변환 행렬을 순서대로 곱해 최종 위치를 구한다. 반대로 엔드이펙터의 목표 위치에서 필요한 각 관절의 각도를 구하는 계산은 **역기구학(Inverse Kinematics)**이다.

<aside>예시 — 2축 평면 로봇 팔의 순기구학</aside>

**예시**: 링크 길이 $l_1, l_2$를 가진 2축 평면 로봇 팔에서 각 관절각 $\theta_1, \theta_2$가 주어지면, 순기구학 계산으로 엔드이펙터의 좌표 $(x, y)$를 다음과 같이 구할 수 있다.

$$x = l_1\cos\theta_1 + l_2\cos(\theta_1+\theta_2)$$
$$y = l_1\sin\theta_1 + l_2\sin(\theta_1+\theta_2)$$

---

<aside>핵심 정리</aside>

- DH 파라미터는 링크 길이·비틀림각·관절 오프셋·관절각 4가지로 구성되며, 질량 같은 동역학적 값은 포함하지 않는다
- 순기구학은 관절각 → 위치를 구하는 계산이며, 반대(위치 → 관절각)는 역기구학이다
