# Summary

로봇을 사용하는 **사용자 그룹**을 목적·연령·전문성별로 분류하고, 사용자 특성이 UI·소프트웨어 설계에 미치는 영향을 분석하는 것이 이 세세항목의 핵심이다.

<aside>NCS 자료 대조</aside>

NCS 학습모듈(LM1903080301) 학습2의 학습 목표에는 "사용자 그룹을 사용 목적별·연령별·전문성별로 분류"가 명시되어 있으나, 본문의 필요 지식은 도메인 분석·사용 사례(Use Case) 작성 방법론 위주로 구성되어 있어 사용자 분류 기준 자체나 UI 설계 법칙은 다루지 않는다. 이 세세항목의 구체적 내용(Fitts·Hick·Miller 법칙 등)은 세세항목명과 문제은행 힌트를 근거로 구성했다.
