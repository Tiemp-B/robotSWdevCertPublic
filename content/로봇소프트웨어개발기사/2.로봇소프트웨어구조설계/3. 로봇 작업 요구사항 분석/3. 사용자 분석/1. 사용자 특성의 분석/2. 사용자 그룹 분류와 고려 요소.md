# Summary

로봇 사용자는 **사용 목적·연령·전문성**의 세 축으로 분류하며, 이 특성에 따라 UI의 복잡도·피드백 방식·안전장치 수준이 달라져야 한다.

# Notes

<aside>사용자 그룹 분류 기준</aside>

| 분류 축 | 예 |
|---|---|
| 사용 목적별 | 산업 현장 작업자, 가정용 서비스 이용자, 관리자(유지보수) |
| 연령별 | 아동, 성인, 고령자 — 반응 속도·시력·인지 부담 고려 |
| 전문성별 | 전문 오퍼레이터(숙련), 비전문 일반 사용자(비숙련) |

<aside>사용자 특성이 소프트웨어 설계에 미치는 영향</aside>

- 비전문 사용자 대상 UI는 전문 용어 대신 직관적 아이콘·안내 메시지 위주로 단순화해야 한다
- 고령자 대상 UI는 글자 크기·버튼 크기를 키우고 반응 대기 시간을 넉넉히 설정해야 한다
- 전문 오퍼레이터 대상 UI는 세부 파라미터 조정 등 고급 기능을 노출해도 무방하다

<aside>유니버설 디자인(Universal Design) — 그룹별 차별화를 넘어선 접근</aside>

앞서 다룬 사용자 그룹별 UI 차별화와 상호 보완적인 것이 **[[유니버설 디자인(Universal Design)|유니버설 디자인]]** 이다. 그룹별로 별도의 UI를 만드는 대신, 처음부터 **가능한 한 모든 사용자가 공통으로 쓸 수 있도록** 설계하는 철학으로, Ron Mace가 제시한 7원칙(공평한 사용·유연성·간단함·인지 가능한 정보·오류에 대한 관용·적은 신체적 노력·적절한 크기와 공간)으로 정리된다.

<aside>사용자 특성 분석 시 고려해야 할 요소</aside>

- 사용자의 로봇 조작 숙련도
- 사용자의 신체적 제약(시력, 반응 속도 등)
- 사용 빈도(가끔 사용 vs 상시 사용)
- 사용 환경에서 함께 작업하는 다른 사람·기기와의 관계

<aside>예시 — 사용자 그룹별 UI 차별화</aside>

**예시**: 같은 배송 로봇이라도, 물류센터 관리자용 UI는 로봇의 배터리 잔량·오류 로그·경로 재설정 등 세부 정보를 모두 노출하지만, 최종 수령자(일반 고객)용 UI는 "물품 수령" 버튼 하나만 크게 배치해 조작 부담을 최소화한다.

---

<aside>핵심 정리</aside>

- 사용자는 사용 목적·연령·전문성으로 분류하며, 각 특성에 맞게 UI 복잡도와 피드백 방식을 조정해야 한다
- 유니버설 디자인은 그룹별 차별화 대신 모든 사용자를 포괄하는 공통 설계를 지향하는 상호 보완적 접근이다
- 고려 요소는 사용자 자신의 숙련도·신체적 제약·사용 빈도이며, 제조 원가 같은 사업적 요소는 해당하지 않는다
