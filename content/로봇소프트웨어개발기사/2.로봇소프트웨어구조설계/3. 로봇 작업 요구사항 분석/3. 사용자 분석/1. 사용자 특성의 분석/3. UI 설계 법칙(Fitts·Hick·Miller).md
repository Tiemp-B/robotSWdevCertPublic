# Summary

**[[피츠의 법칙(Fitts' Law)|피츠의 법칙]]**은 대상까지의 이동 시간을, **[[힉의 법칙(Hick's Law)|힉의 법칙]]**은 선택지 개수에 따른 의사 결정 시간을, **[[밀러의 법칙(Miller's Law)|밀러의 법칙]]**은 사람이 한 번에 기억할 수 있는 항목 수를 각각 다룬다 — 셋 다 UI 설계에서 자주 혼동되므로 구분이 중요하다.

# Notes

<aside>세 법칙 비교</aside>

| 법칙 | 다루는 것 | 핵심 시사점 |
|---|---|---|
| 피츠의 법칙(Fitts' Law) | 목표물까지의 **이동 시간** | 목표물이 클수록, 가까울수록 도달 시간이 짧아짐 → 자주 누르는 버튼은 크고 가깝게 배치 |
| 힉의 법칙(Hick's Law) | 선택지 개수에 따른 **의사 결정 시간** | 선택지가 많아질수록 결정 시간이 길어짐(로그적으로 증가) → 메뉴 항목 수를 줄이면 결정이 빨라짐 |
| 밀러의 법칙(Miller's Law) | 단기 기억 용량(**7±2**) | 사람이 한 번에 기억·처리할 수 있는 항목은 약 5~9개 → 메뉴·목록을 이 범위로 그룹화 |

"힉의 법칙은 화면상의 버튼 크기와 거리가 클릭 시간에 미치는 영향을 설명하는 법칙이다"라는 서술은 **피츠의 법칙**과 뒤바뀐 오답이다 — 버튼의 크기·거리와 클릭 시간의 관계는 피츠의 법칙이며, 힉의 법칙은 **선택지 개수와 결정 시간**의 관계를 다룬다.

<aside>피츠의 법칙 상세</aside>

피츠의 법칙에 따르면 이동 시간은 목표까지의 거리에 비례하고 목표의 크기에 반비례한다. 즉 "버튼이 작고 멀수록 클릭하기 어렵고 시간이 오래 걸린다"는 직관을 정량화한 것이다.

"피츠의 법칙에 따르면 목표물의 크기가 작을수록 도달 시간이 짧아진다"라는 서술은 오답이다 — 피츠의 법칙에서 목표물이 **작을수록** 도달·클릭에 필요한 시간은 **더 길어진다**(정확도를 위해 더 신중하게 움직여야 하므로).

정량적으로는 **이동 시간(MT) = a + b·ID**, **난이도 지수(ID) = log₂(2A/W)** 로 표현된다(A: 목표까지의 거리, W: 목표의 폭, a·b: 실험적 상수). 거리(A)가 클수록, 폭(W)이 작을수록 ID(난이도)가 커지고 그만큼 이동 시간(MT)도 길어진다는 것을 이 공식으로 확인할 수 있다.

<aside>밀러의 법칙이 시사하는 바</aside>

밀러의 법칙(7±2)은 UI에서 한 화면에 너무 많은 메뉴 항목·선택지를 나열하지 말고, 관련 항목을 그룹화(청킹, chunking)해 사용자의 인지 부담을 줄여야 한다는 것을 시사한다.

"밀러의 법칙이 시사하는 바는 UI에 표시되는 정보량과 무관하게 항상 최대한 많은 정보를 한 화면에 담아야 한다는 것이다"라는 서술은 오답이다 — 밀러의 법칙은 오히려 **정보를 인지 가능한 소수의 묶음으로 그룹화**해야 한다는 것을 시사한다.

<aside>예시 — 로봇 원격 제어 UI에 세 법칙 적용</aside>

**예시**: 로봇 원격 제어 화면에서 자주 쓰는 "긴급 정지" 버튼은 크고 화면 중앙 가까이 배치하고(피츠의 법칙), 상단 메뉴는 5~7개 이하로 그룹화하며(밀러의 법칙), 하위 메뉴의 선택지 개수를 최소화해 빠른 의사 결정을 돕는다(힉의 법칙).

<aside>핵심 정리</aside>

- 피츠의 법칙(이동 시간·거리와 크기), 힉의 법칙(선택지 개수와 결정 시간), 밀러의 법칙(단기 기억 7±2)은 서로 다른 대상을 다루며 자주 뒤바뀌어 출제된다
- 피츠의 법칙은 MT=a+b·ID, ID=log₂(2A/W)로 정량화되며, 거리가 클수록·폭이 작을수록 이동 시간이 길어진다
