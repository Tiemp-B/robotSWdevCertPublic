# Summary

센서 연결에는 2선 방식의 **I2C**, 4선 동기식의 **SPI**, 비동기식의 **UART**, 산업 현장의 **RS-485**, 고속 범용 연결의 **USB**가 널리 쓰이며 각각 신호선 구성과 특징이 다르다.

# Notes

<aside>I2C(Inter-Integrated Circuit)</aside>

I2C는 **SDA(데이터)**와 **SCL(클럭)** 단 2개의 선으로 여러 장치를 연결하는 동기식 직렬 통신 방식이다.

- 마스터가 SDA를 클럭(SCL)이 High인 상태에서 High→Low로 변화시켜 **START 조건**을 생성하며, 통신을 시작함을 알림
- 각 슬레이브는 고유한 주소를 가지며, 마스터가 주소를 전송해 통신할 장치를 선택
- 데이터 수신 측은 매 바이트 뒤에 ACK(확인 응답) 비트로 정상 수신 여부를 알림

"I2C 통신에서 START 조건은 클럭(SCL)이 Low인 상태에서 데이터선(SDA)을 변화시켜 생성한다"라는 서술은 오답이다 — START 조건은 **SCL이 High인 상태에서 SDA를 High에서 Low로** 변화시켜 생성한다.

<aside>SPI(Serial Peripheral Interface)</aside>

SPI는 4개의 신호선을 사용하는 동기식 직렬 통신 방식이다.

| 신호선 | 의미 |
|---|---|
| MOSI(Master Out Slave In) | 마스터 → 슬레이브 데이터 전송 |
| MISO(Master In Slave Out) | 슬레이브 → 마스터 데이터 전송 |
| SCK(Serial Clock) | 동기화를 위한 클럭 신호 |
| SS(Slave Select) | 통신할 슬레이브를 선택하는 신호(Chip Select라고도 함) |

"SPI 통신에서 MISO는 마스터가 슬레이브로 데이터를 전송하는 선이다"라는 서술은 **MOSI**와 뒤바뀐 오답이다 — 마스터에서 슬레이브로 향하는 선은 MOSI이며, MISO는 반대로 **슬레이브에서 마스터**로 향하는 선이다.

<aside>UART(Universal Asynchronous Receiver/Transmitter)</aside>

UART는 클럭 신호선 없이 **비동기(asynchronous)**로 데이터를 주고받는 직렬 통신 방식이다. 송수신 측이 사전에 약속한 동일한 속도(baud rate)로 시작 비트-데이터 비트-(패리티 비트)-정지 비트 순서의 프레임을 주고받는다.

<aside>RS-485</aside>

RS-485는 +와 – 두 선으로 신호를 표현하는 차동(differential) 방식으로, 다수의 송신기와 다수의 수신기가 하나의 버스를 공유하는 N:N 통신을 지원하며, 송신할 때는 수신할 수 없는 **반이중(half duplex)** 방식이다(RS-232·RS-422와의 비교는 이전 세부항목에서 이미 다룸).

<aside>USB(Universal Serial Bus) 3.0</aside>

USB 3.0(SuperSpeed)은 이전 버전(USB 2.0) 대비 크게 향상된 속도(최대 5Gbps)를 제공하며, 별도의 송신·수신 전용 선을 추가해 **전이중(full duplex)** 통신이 가능하고, 이전 버전과의 하위 호환성을 유지한다.

"USB 3.0은 이전 버전인 USB 2.0과 호환되지 않아 완전히 새로운 포트와 케이블이 필요하다"라는 서술은 오답이다 — USB 3.0은 전송 속도가 크게 향상되었지만 **하위 호환성**을 유지하도록 설계되었다.

---

<aside>핵심 정리</aside>

- I2C는 SDA·SCL 2선, START 조건은 SCL High 상태에서 SDA를 Low로 변화
- SPI는 MOSI(마스터→슬레이브)·MISO(슬레이브→마스터)·SCK·SS 4선으로 구성
- USB 3.0은 속도가 빠르면서도 이전 버전과 하위 호환된다
