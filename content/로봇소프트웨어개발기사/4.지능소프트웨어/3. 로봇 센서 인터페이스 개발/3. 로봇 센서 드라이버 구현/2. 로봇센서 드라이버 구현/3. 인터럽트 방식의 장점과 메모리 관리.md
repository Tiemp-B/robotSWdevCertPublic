# Summary

센서 드라이버에서 인터럽트 방식은 **신호에 즉각 반응**하면서도 **MCU 리소스를 절약**할 수 있다는 장점이 있으며, 메모리가 제한된 임베디드 환경에서는 **메모리 누수 방지**가 특히 중요하다.

# Notes

<aside>센서 드라이버에서 인터럽트 방식의 장점</aside>

- **즉각적인 반응**: 신호 변화가 발생한 순간 바로 처리되어 지연이 없음(이미 [[2. 폴링과 인터럽트|폴링과 인터럽트]]에서 다룸)
- **MCU 리소스 절약**: 신호가 없을 때는 다른 작업을 계속 수행할 수 있어, 폴링처럼 계속 감시하며 리소스를 소모하지 않음
- **정확한 이벤트 포착**: 폴링 주기 사이에 발생했다가 사라지는 짧은 신호도 놓치지 않고 포착 가능

<aside>임베디드 메모리 관리 기법</aside>

임베디드 시스템은 메모리가 제한적이므로 다음과 같은 관리가 필요하다.

- **정적 메모리 할당 우선 사용**: 실행 중 동적 할당(malloc 등)을 최소화해 메모리 단편화·누수 위험을 줄임
- **스택·힙 크기 사전 설계**: 스택 오버플로우가 발생하지 않도록 재귀·지역 변수 크기를 고려
- **메모리 풀(memory pool) 활용**: 자주 생성·소멸되는 객체를 미리 할당해둔 풀에서 재사용
- **참조 카운팅·범위 관리**: 동적 할당을 사용할 경우 할당·해제 짝을 명확히 맞춰 메모리 누수 방지

---

<aside>핵심 정리</aside>

- 인터럽트 방식의 핵심 장점은 즉각 반응하면서도 신호가 없을 때 다른 작업을 자유롭게 수행해 리소스를 절약하는 것이다
- 메모리 관리는 정적 할당 우선·메모리 풀·명확한 해제로 누수를 방지하며, 해제하지 않고 유지하는 것은 누수 방지가 아니다
