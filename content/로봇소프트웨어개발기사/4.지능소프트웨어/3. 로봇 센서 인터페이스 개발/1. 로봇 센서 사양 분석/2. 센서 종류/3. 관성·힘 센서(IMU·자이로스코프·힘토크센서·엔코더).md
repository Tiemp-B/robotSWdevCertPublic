# Summary

**[[IMU(Inertial Measurement Unit)|IMU]]**는 가속도계·자이로스코프(·지자기 센서)로 구성되며, 힘/토크 센서는 **스트레인 게이지**로 미세한 변형을 측정하고, 엔코더는 절대·증분 방식으로 나뉜다.

# Notes

<aside>IMU(관성측정장치)의 구성 요소</aside>

IMU는 물체의 관성(가속도·회전)을 측정하는 장치로, 대표적으로 다음 센서들로 구성된다.

- **가속도계(Accelerometer)**: 선형 가속도를 측정
- **자이로스코프(Gyroscope)**: 각속도(회전 속도)를 측정
- (경우에 따라) **지자기 센서(Magnetometer)**: 지구 자기장을 이용해 방위(heading)를 측정

<aside>MEMS 자이로스코프의 측정 원리</aside>

MEMS(초소형 정밀기계) 자이로스코프는 물체가 회전할 때 진동하는 질량에 작용하는 **코리올리 힘(Coriolis force)**을 감지해 각속도를 측정한다.

- **바이어스 불안정성(Bias Instability)**: 회전이 전혀 없는 정지 상태에서도 온도 변화·내부 잡음 등으로 출력값이 서서히 표류(drift)하는 현상 — 시간이 지날수록 자세 추정 오차가 누적되는 원인이 됨

<aside>힘/토크 센서(Force/Torque Sensor)</aside>

힘/토크 센서는 주로 **스트레인 게이지(strain gauge)**를 이용해 물체에 힘이 가해질 때 발생하는 미세한 변형(strain)을 전기 저항 변화로 측정한다.

- 스트레인 게이지는 온도 변화에도 저항이 변하므로, 힘에 의한 저항 변화와 온도에 의한 저항 변화를 구분하기 어려움
- 이를 보상하기 위해 **휘트스톤 브릿지(Wheatstone Bridge)** 회로를 구성해, 온도 영향은 서로 상쇄되고 힘에 의한 변화만 증폭되도록 함

힘/토크 센서의 대표 용도는 말단에 부착해 접촉력을 직접 측정하는 **[[3. 매니퓰레이터 힘 제어와 여유자유도|직접 힘 제어]]**다(과목4 작업지능소프트웨어설계에서 이미 다룸).

<aside>엔코더(Encoder)의 종류</aside>

| 종류 | 특징 |
|---|---|
| 증분형(Incremental) | 회전량(변화량)만 출력 — 전원이 꺼지면 절대 위치 정보를 잃어버려, 재기동 시 원점 복귀(호밍)가 필요 |
| 절대형(Absolute) | 각 위치마다 고유한 코드를 출력 — 전원이 꺼져도 위치 정보가 유지됨 |

---

<aside>핵심 정리</aside>

- IMU는 가속도계·자이로스코프(·지자기 센서)로 구성되며, 자이로는 각속도를 측정한다(가속도계는 선형 가속도)
- 힘/토크 센서는 스트레인 게이지+휘트스톤 브릿지로 온도 영향을 보상하며, 엔코더는 증분형(전원차단시 위치소실)과 절대형(위치유지)으로 나뉜다
