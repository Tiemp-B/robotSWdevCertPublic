# Summary

로봇과 주변장치의 인터페이스는 크게 **센서(입력)·모션 생성/티칭(제어 입력)·상태 출력(디스플레이 등)**으로 구성되며, 이를 정확히 분석해야 작업지능 소프트웨어가 실제 하드웨어와 올바르게 연동된다.

# Notes

<aside>주변장치 인터페이스의 구성 요소</aside>

| 구성 | 예 |
|---|---|
| 센서(입력) | 초음파 센서, 카메라(영상인식), 힘/토크 센서, 위치 센서 |
| 모션 티칭/생성(제어 입력) | 모션 프로그래밍 패키지, 조작 버튼·손잡이(navigator/knob) |
| 상태 출력 | 디스플레이, 상태 표시 장치 |

이 구성은 로봇마다 다르며, 소프트웨어를 개발하기 전에 대상 로봇의 하드웨어 사양(웹사이트·매뉴얼 등)을 통해 정확히 파악해야 한다.

<aside>주변장치 인터페이스 분석에서 가장 중요한 고려사항</aside>

주변장치 인터페이스 분석에서 가장 중요한 것은 소프트웨어가 다뤄야 할 **각 주변장치의 데이터 종류·형식과 통신 방식(프로토콜)을 정확히 파악**하는 것이다. 센서마다 출력하는 데이터의 형식(예: 힘/토크 값의 단위, 영상 데이터의 해상도)과 통신 방식(유선/무선, 프로토콜)이 다르므로, 이를 정확히 알아야 소프트웨어가 실제 데이터를 올바르게 해석·활용할 수 있다.

<aside>툴체인저(Tool Changer) — 엔드이펙터 교체 인터페이스</aside>

로봇의 대표적인 주변장치 인터페이스 중 하나가 **[[툴체인저(Tool Changer)|툴체인저]]**다. 로봇 팔 쪽 **마스터 플레이트**와 엔드이펙터 쪽 **툴 플레이트**로 구성되며, 공압·전기 신호가 두 플레이트를 그대로 통과(pass-through)하도록 설계되어 도구 교체 시 배선을 다시 연결할 필요가 없다. 이를 통해 하나의 로봇이 그리퍼·용접건 등 여러 엔드이펙터를 자동으로 바꿔가며 다양한 작업을 수행할 수 있다.

<aside>예시 — 협동로봇의 주변장치 인터페이스 분석</aside>

**예시**: 어떤 협동로봇을 분석할 때, 센서로는 초음파 센서·카메라(헤드에 1개, 양쪽 그리퍼에 각 1개)·힘/토크 센서·위치 센서가 있고, 모션 생성은 모션 프로그래밍 패키지 개발이나 조작 버튼으로 이루어지며, 상태 출력은 헤드 디스플레이로 이루어진다는 것을 사전에 파악해두면, 이후 소프트웨어가 각 센서 데이터를 어떤 형식으로 받아 어떻게 처리할지 설계하는 데 직접적인 기초 자료가 된다.

---

<aside>핵심 정리</aside>

- 주변장치 인터페이스는 센서(입력)·모션 티칭/생성(제어 입력)·상태 출력, 그리고 툴체인저(엔드이펙터 교체) 등으로 구성된다
- 분석에서 가장 중요한 것은 각 장치의 데이터 형식과 통신 프로토콜을 정확히 파악하는 것이다
- 툴체인저는 마스터/툴 플레이트로 구성되며 공압·전기 신호가 그대로 통과해 도구 교체 시 배선 재연결이 필요 없다
