# Summary

**[[공유자율화(Shared Autonomy)|공유자율화]]**는 로봇의 완전자율화로 가는 전 단계로, 인간의 개입을 최소화하면서 로봇과 인간이 효율적으로 분업하는 기술이며, 정보획득-정보분석-판단과행동선택-작업구현의 4단계로 진행된다.

# Notes

<aside>공유자율화(Shared Autonomy)란</aside>

공유자율화는 로봇이 복잡한 작업을 수행하거나 인지적 판단이 필요할 때 인간의 명령·도움을 최소화하면서 로봇의 수행 능력을 극대화해, 인간과 로봇이 효율적으로 분업·협업하는 기술이다. 로봇의 **완전자율화(full autonomy)**로 가는 전 단계에 해당한다.

- 예: 최신형 텔레프레즌스 로봇에서 사용자가 목적지만 정해주면 로봇이 장애물 회피를 자동으로 수행하는 것
- 예: DARPA Robotics Challenge에서 인간 오퍼레이터와 로봇이 협업해 재난 현장 미션을 수행하는 것

<aside>공유자율화의 수행 단계</aside>

불규칙하게 놓인 물체를 인식·분류·파지하는 작업을 예로 들면, 공유자율화는 다음 4단계로 진행된다.

| 단계 | 내용 | 자율화 정도 |
|---|---|---|
| 정보 획득 | 카메라 영상, 거리 측정, 압력 센서 등으로 내외부 정보를 그대로 획득 | 높은 편 |
| 정보 분석 | 획득한 센서 원본 데이터로 물체를 인식·분류 | **낮은 편**(잡음·가림 등으로 어려움, 인간 개입 필요) |
| 판단과 행동 선택 | 분석된 정보로 상황을 판단하고 행동 후보를 제안(어느 방향으로 갈지, 어떻게 잡을지) | 상황에 따라 다름 |
| 작업 구현 | 선택된 작업을 실제로 수행 | 작업 난이도·지능 정도에 따라 다름 |

<aside>예시 — 비정형 환경에서의 공유자율화</aside>

**예시**: 컵이나 병 같은 단순한 물체는 로봇이 잘 인식·파지하지만, 가정이나 사무실처럼 비정형적이고 복잡한 환경에서 특정 물건을 잡아야 하는 경우에는 인간이 개입해 대상 물건과 그 파지 방법을 알려주는 것이 여전히 필요한 실정이다.

---

<aside>핵심 정리</aside>

- 공유자율화는 완전자율화의 전 단계이며 인간 개입의 완전 배제가 아니라 최소화가 목표다
- 정보획득-정보분석-판단과행동선택-작업구현 4단계 중 정보 분석 단계는 오히려 자율화 정도가 낮은 편이다
