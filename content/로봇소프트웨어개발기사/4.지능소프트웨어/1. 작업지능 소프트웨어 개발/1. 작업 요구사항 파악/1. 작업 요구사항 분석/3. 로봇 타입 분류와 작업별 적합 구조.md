# Summary

로봇은 **매니퓰레이터 구조**(직각좌표형·원통좌표형·수평관절형·수직관절형·극좌표형·병렬)와 **이동 수단**(고정형·바퀴형·족형·공중·수중)이라는 두 가지 기준으로 분류하며, 작업 분야마다 적합한 구조가 다르다.

# Notes

<aside>매니퓰레이터 구조에 따른 분류</aside>

직각좌표형·원통좌표형·수평관절형(SCARA)·극좌표형은 과목3 "로봇 하드웨어 특성 분석"에서 이미 다뤘으므로(수직관절형=다관절 로봇) 반복하지 않고 링크로 참조한다. 여기에 더해 **병렬 로봇(parallel robot)**은 여러 개의 링크가 하나의 말단장치를 동시에 지지하는 구조로, 고속·고강성이 필요한 작업에 활용된다.

<aside>이동 수단에 따른 분류</aside>

| 종류 | 특징 |
|---|---|
| 고정형(fixed) | 제조공정 대부분(용접·조립 등)에 사용되는 기본 형태 |
| 바퀴형(mobile) | 이동이 필요한 자재 운반 등에 사용 |
| 족형(legged) | 다리로 이동, 불규칙한 지형 대응 |
| 공중/수중 로봇 | 각각 비행·수중 환경에 특화 |

<aside>작업별 적합 로봇 구조</aside>

| 작업 분야 | 적합한 매니퓰레이터 구조 |
|---|---|
| 부품배치 | 직각좌표형, 원통좌표형, 수평관절형, 병렬 로봇 |
| 적재 및 하역 | 원통좌표형, 수평관절형, 바퀴형 로봇 |
| 용접·도장 | 수직관절형, 극좌표형 |
| 절삭가공·디버링·도포 | 직각좌표형 |
| 조립 | 직각좌표형, 원통좌표형, 수평관절형 |

"제조공정의 자재취급·공정처리·조립·검사 네 분야에 공통적으로 사용할 수 있는 로봇 구조는 극좌표형이며, 이동 수단은 바퀴형이다"라는 서술은 오답이다 — 네 분야에 공통으로 사용되는 구조는 매니퓰레이터 기준으로는 **수직관절형**, 이동 수단 기준으로는 **고정형**이다.

<aside>자유도(DOF)와 작업 요구</aside>

3차원 공간에서 임의 위치의 물체를 임의 방향으로 잡으려면 최소 **6자유도**의 매니퓰레이터가 필요하며, 제한된 작업 공간에서 정해진 위치의 물체만 다루는 단순 작업에는 **3자유도** 직각좌표형 로봇으로도 충분하다.

---

<aside>핵심 정리</aside>

- 제조공정 4대 분야에 공통으로 쓰이는 로봇은 매니퓰레이터 구조상 수직관절형, 이동 수단 기준으로는 고정형이다
- 임의 위치·방향의 물체를 다루려면 최소 6자유도가 필요하며, 정해진 위치의 단순 작업에는 3자유도로도 충분하다
