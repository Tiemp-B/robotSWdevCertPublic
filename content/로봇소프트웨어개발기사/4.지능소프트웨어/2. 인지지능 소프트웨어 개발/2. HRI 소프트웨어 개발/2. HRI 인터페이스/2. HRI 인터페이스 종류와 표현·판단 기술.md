# Summary

HRI 인터페이스는 음성·제스처·**햅틱(촉각)**·시각으로 구성되며, 로봇은 주행·감정 표현(LED)·**음성 합성(TTS)** 등 여러 매개체를 함께 쓰는 **다중 모드(multimodal) 표현**으로 사람과 소통한다.

# Notes

<aside>HRI 인터페이스의 종류</aside>

| 인터페이스 | 내용 |
|---|---|
| 음성 인터페이스 | 음성인식·음성합성을 통한 대화형 상호작용 |
| 제스처(동작) 인터페이스 | 몸짓·손동작으로 명령을 전달 |
| 햅틱(촉각) 인터페이스 | 힘·진동 등 촉각 피드백을 주고받는 상호작용 |
| 시각 인터페이스 | 디스플레이·LED·표정 등으로 시각적 정보를 주고받음 |

<aside>햅틱 인터페이스(Haptic Interface)의 특징</aside>

햅틱 인터페이스는 힘·진동·촉감 등 **촉각 피드백**을 통해 사람과 로봇이 정보를 주고받는 방식이다. 사용자가 로봇을 직접 잡고 움직이거나, 로봇이 사용자에게 힘·진동으로 반응을 전달하는 방식이 이에 해당한다.

"햅틱 인터페이스는 시각·청각 정보만을 이용하며 물리적인 접촉이나 힘 전달은 포함하지 않는다"라는 서술은 오답이다 — 햅틱 인터페이스의 핵심은 오히려 **물리적 접촉·힘·진동 같은 촉각 피드백**을 주고받는 것이며, 시각·청각과는 구분되는 별도의 채널이다.

<aside>표현 기술(Expression)</aside>

인식·판단 과정을 거쳐 얻은 정보를 바탕으로, 액추에이터·장치를 이용해 로봇의 의도·계획·감정을 사람에게 표현하는 기술이다.

- **주행(navigation)**: 바퀴·다리로 사용자에게 다가가거나 추종
- **감정 생성 및 표현**: 얼굴의 LED·디스플레이나 제스처로 표현(예: 걷는 속도·보폭을 조절해 감정을 표현하는 보행 패턴 변화)
- **음성 합성(TTS, Text to Speech)**: 텍스트를 음성으로 변환해 말소리로 전달

여러 매개체(주행·표정·음성 등)를 함께 이용해 의사를 표현하는 것을 **다중 모드(multimodal) 표현**이라 한다.

<aside>판단 기술과 인지 아키텍처</aside>

판단 기술은 인식한 정보를 인터랙션 모델·태스크 모델·**온톨로지(ontology)**를 기반으로 해석해, 로봇이 이해 가능한 정보로 변환하는 기술이다. 상황인식은 다양한 센서·상태 데이터를 종합적으로 고려하고 추론·학습해야 하므로, Soar 같은 **인지 에이전트 아키텍처**를 활용하기도 한다.

<aside>음성 인터페이스의 NLP 파이프라인</aside>

음성 인터페이스는 크게 **음성인식(STT) → [[NLP 파이프라인(형태소·구문·의미·담화 분석)|자연어처리(NLP)]] → 의도파악·대화관리 → 음성합성(TTS)** 순으로 동작한다. 이 중 NLP 처리는 다시 4단계로 이루어진다.

| 단계 | 내용 |
|---|---|
| ① 형태소 분석 | 문장을 최소 의미 단위(형태소)로 분리하고 품사를 태깅(예: "가방에 들어가신다" → 가방/명사+에/조사+들어가/동사+시/어미+ㄴ다/어미) |
| ② 구문 분석 | 문장 구성요소를 분해해 위계관계·구조를 파악 |
| ③ 의미 분석 | 문장의 뜻을 파악(문법은 맞지만 의미가 틀린 문장도 검출) |
| ④ 담화 분석 | 전체 문맥과 연결해 정확한 의미를 분석 |

"음성 인터페이스의 NLP 처리에서 의미 분석은 형태소 분석보다 먼저 이루어진다"라는 서술은 오답이다 — NLP 파이프라인은 **형태소분석 → 구문분석 → 의미분석 → 담화분석** 순으로, 더 작은 단위(형태소)를 먼저 분석한 뒤 점차 큰 단위(문맥)로 확장한다.

<aside>제스처 인식 알고리즘 설계 시 고려사항</aside>

[[제스처 인식 처리 단계|제스처 인식의 처리 단계]](데이터수집→전처리→특징추출→분류)가 "무엇을 거치는가"라면, 알고리즘 설계는 "각 단계를 어떤 알고리즘으로 구현할 것인가"의 문제다. 이때 가장 중요한 고려사항은 **정확도와 연산량(실시간성) 사이의 트레이드오프**다.

- 3D CNN·주파수 변환 등 복잡한 모델: 정확도는 높지만 연산 비용이 커 지연이 발생하기 쉬움
- MobileNet 등 경량 모델: 정확도를 다소 희생하는 대신 임베디드 환경에서도 실시간 처리 가능

로봇에 탑재되는 임베디드 환경에서는 목표 정확도를 만족하는 한도 내에서 최대한 가벼운 모델을 선택하는 것이 설계 원칙이다.

<aside>핵심 정리</aside>

- HRI 인터페이스는 음성·제스처·햅틱·시각으로 구성되며, 햅틱은 물리적 촉각 피드백이 핵심이다
- 표현 기술은 주행·감정표현·음성합성(TTS) 등을 조합한 다중 모드 표현으로 이루어지며, 판단 기술은 온톨로지·인지 아키텍처로 정보를 해석한다
- 음성 인터페이스의 NLP는 형태소→구문→의미→담화분석 순으로 처리되며, 제스처 인식 알고리즘은 정확도-연산량 트레이드오프를 고려해 설계한다
