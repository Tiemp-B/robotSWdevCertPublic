# Summary

딥러닝 기반 인지지능 모델을 설계할 때는 **PCA로 고차원 특징을 축소**하고, **ReLU로 기울기 소실을 완화**하며, **배치 정규화로 학습을 안정화**한다 — 다만 활성화 함수 자체는 과적합 방지 기법으로 분류되지 않는다.

# Notes

<aside>PCA(주성분 분석) — 특징 차원 축소</aside>

[[주성분 분석(PCA)|PCA]]는 분산이 가장 큰 축을 첫 주성분으로 삼아 데이터를 저차원으로 변환하는 직교 선형변환 기법이다. 예를 들어 100×100 영상은 10,000차원 특징벡터가 되는데, PCA로 차원을 축소하면 학습·인식 속도가 개선되고 과적합도 완화된다.

물체 인식에서는 모델 영상의 대표 특징(주성분)을 미리 구해두고, 인식 대상 영상의 특징 벡터와의 거리를 측정해 가장 가까운 모델을 인식 결과로 선택하는 방식(예: Eigenface 얼굴 인식)으로 활용된다.

<aside>ReLU(활성화 함수)</aside>

[[ReLU(활성화 함수)|ReLU]](Rectified Linear Unit)는 입력이 양수면 그대로, 음수면 0을 출력하는 활성화 함수다. 양수 구간에서 미분값이 항상 1이므로 **기울기 소실(Gradient Vanishing) 문제를 완화**해 더 깊은 신경망도 학습시킬 수 있게 해준다. 단, 음수 구간의 기울기는 0이므로 완전한 해결책은 아니다(dying ReLU 한계).

<aside>배치 정규화(Batch Normalization)</aside>

[[배치 정규화(Batch Normalization)|배치 정규화]]는 보통 선형층과 활성화 함수(ReLU 등) 사이에 배치되어, 배치 단위로 은닉층의 값을 정규화함으로써 학습을 안정시키는 기법이다. 가중치 초깃값에 덜 의존하게 되고, ReLU처럼 값의 범위가 정해지지 않은(unbounded) 활성화 함수의 수치 불안정성을 특히 완화한다.

"과적합을 방지하는 방법이 아닌 것은 무엇인가"라는 문제에서 **활성화 함수(ReLU 등)**가 정답(=과적합 방지 기법이 아님)인 경우가 많다 — 활성화 함수의 목적은 비선형성 추가와 기울기 소실 완화이며, 과적합 방지는 [[드롭아웃(Dropout)|드롭아웃]]·L1/L2 정규화·배치 정규화가 담당한다.

---

<aside>핵심 정리</aside>

- PCA는 고차원 특징을 저차원으로 축소해 연산량을 줄이고 과적합을 완화하는 차원 축소·특징 추출 기법이다
- ReLU는 기울기 소실을 완화해 깊은 신경망 학습을 가능하게 하지만, 음수 구간 기울기가 0이라는 한계가 있다
- 배치 정규화는 은닉층 값을 정규화해 학습을 안정시키며, 활성화 함수 자체와는 별개의 과적합 방지 기법이다
