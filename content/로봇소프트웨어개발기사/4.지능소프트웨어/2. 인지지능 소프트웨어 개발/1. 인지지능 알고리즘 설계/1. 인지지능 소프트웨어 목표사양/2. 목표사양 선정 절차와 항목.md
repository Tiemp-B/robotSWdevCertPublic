# Summary

인지지능 소프트웨어의 목표사양은 **물체·사람·환경**이라는 세 가지 인지 대상별로 인식 속도·정확성·반복성·강인성 요구사항을 정리하고, 자율화 지수를 기준으로 필요한 인지 방식(수동 라벨링 ~ DNN 자율 인식)을 결정한다.

# Notes

<aside>인지지능 기능 요구서의 항목</aside>

사용자 요구 분석서와 수행할 인지지능 태스크를 분석해, 다음 항목으로 구성된 인지지능 기능 요구서를 작성한다.

| 항목 | 의미 |
|---|---|
| 인식 속도 | 인지 결과를 얼마나 빠르게 산출하는가 |
| 정확성 | 인지 결과가 실제와 얼마나 일치하는가 |
| 반복성 | 같은 대상을 반복 인지했을 때 결과가 얼마나 일관적인가 |
| 강인성(robustness) | 잡음·가림·조명 변화 등에도 잘 인지하는가 |

인지지능 기능 요구서의 항목은 이처럼 **인식 성능**(속도·정확성·반복성·강인성)에 관한 것이며, 제조 단가 같은 사업성 요소는 해당하지 않는다.

<aside>인지 대상별 카메라·알고리즘 선택</aside>

인지지능을 수행할 로봇 타입과 인지 대상(물체·사람·환경)에 따라 적절한 [[카메라 선택 기준(해상도·화각·프레임레이트)|카메라·센서]]와 알고리즘을 선택한다.

카메라 스펙은 다음 기준으로 정한다.

| 기준 | 선택 원칙 |
|---|---|
| 해상도 | 인식해야 할 최소 특징(feature) 크기 대비 일정 배수의 픽셀을 확보하도록 산출한다 — 용도가 정밀할수록(전통 검사 → AI 인식 → OCR) 필요한 픽셀 배수가 커진다 |
| 화각(FOV) | 대상 물체의 실제 크기보다 여유 있게 커버해야 하며, 센서 크기·렌즈 조합에 따라 달라진다 |
| 프레임레이트 | 로봇의 작업 속도(라인 속도 등)를 따라갈 수 있어야 한다 |

해상도와 프레임레이트는 통신 인터페이스 대역폭 한계로 **상충 관계**에 있다 — 해상도가 높아질수록 달성 가능한 최대 프레임레이트는 낮아진다. 따라서 요구 성능을 만족하는 가장 낮은 해상도를 선택하는 것이 설계 원칙이다.

카메라·센서 선택 이후에는 알고리즘을 선택한다. 예를 들어 인식 속도가 빨라야 한다면 SURF(속도 우선) 알고리즘을, 느려도 된다면 SIFT(정확도 우선) 알고리즘을 선택하는 식으로 요구 조건에 맞춰 절충한다(SIFT·SURF의 구체적 특징은 다음 세세항목에서 다룸).

<aside>자율화 지수의 재활용</aside>

목표사양 선정에는 이미 다룬 [[2. 목표사양 4요소와 자율화 지수(ALFUS)|ALFUS 자율화 지수]]를 다시 활용한다.

- 자율화 지수가 **0에 가까우면**: 사람이 로봇의 영상 데이터를 보고 수동으로 물체를 인식해 라벨을 붙이는 방식
- 자율화 지수가 **10에 가까우면**: DNN 등을 이용해 로봇이 자율적으로 물체를 인식하는 방식

<aside>핵심 정리</aside>

- 인지지능 목표사양은 물체·사람·환경별로 인식 속도·정확성·반복성·강인성을 정리한 요구서로 구성된다
- 카메라 스펙은 해상도(최소 특징 크기 기준)·화각(대상보다 여유 있게)·프레임레이트(작업 속도 대응)로 정하며, 해상도-프레임레이트는 상충 관계다
- 자율화 지수가 낮을수록 사람의 수동 인식·라벨링에, 높을수록 DNN 기반 자율 인식에 가깝다
