# Summary

충돌회피는 센서가 정확히 장애물을 감지한다는 전제 위에서 작동하므로, 센서 자체가 고장 나도 안전하게 동작하도록 **정적·동적·하이브리드 중복 구조**로 결함을 허용(fault tolerance)하도록 설계한다.

# Notes

<aside>정적/동적 충돌 요소</aside>

| 구분 | 정의 | 예 |
|---|---|---|
| 정적 충돌 요소 | 위치가 고정된 장애물 | 정차된 차량, 작업장 구조물 |
| 동적 충돌 요소 | 위치가 계속 바뀌는 장애물 | 이동 중인 차량, 움직이는 작업자 |

주변 정보를 사전에 알고 있으면 정적 요소는 미리 대비할 수 있지만, 동적 요소는 센서로 실시간 계측해 판단해야 한다.

<aside>정적 중복 구조(Static Redundancy) — TMR</aside>

TMR(Triple Modular Redundancy, 삼중 모듈 중복) 구조는 동일한 입력을 3개의 모듈에 동시에 넣고, 보터(voter)가 세 출력값을 비교해 **다수결(또는 중간값)**로 최종 출력을 결정하는 구조다. 한 모듈에 결함이 생겨도 나머지 두 정상 모듈의 출력으로 정상적인 결과를 낸다.

<aside>동적 중복 구조(Dynamic Redundancy)</aside>

동적 중복 구조는 결함 검출(fault detection) → 결함 위치 파악(fault location) → 결함 회복(fault recovery)의 절차로, 결함이 발생한 모듈만 격리하고 다른 모듈로 교체(reconfiguration)하는 방식이다.

| 방식 | 특징 |
|---|---|
| Hot standby | 주 모듈과 예비 모듈이 **모두 동시에 동작**하며 완전히 동기화된 상태를 유지하다가, 결함 검출 시 출력 스위치만 예비 모듈 쪽으로 즉시 전환 |
| Warm standby | 예비 모듈이 **켜진 채로 대기**하지만 주 모듈만큼 완전히 동기화되지는 않은 상태 — 결함 발생 시 짧은 전환 시간을 거쳐 가동되어, Hot과 Cold의 중간 수준 |
| Cold standby | 주 모듈과 예비 모듈 중 **하나만 동작**하다가, 결함 발생 시 대기하던(꺼져 있던) 모듈을 가동시켜 전환 — 전환 시간이 가장 길다 |

"Cold standby 구조는 주 모듈과 예비 모듈이 항상 동시에 동작하며 출력만 전환하는 방식이다"라는 서술은 **Hot standby**와 뒤바뀐 오답이다 — 주 모듈과 예비 모듈이 동시에 동작하는 것은 Hot standby이며, Cold standby는 평소 **하나만 동작**하고 나머지는 꺼진 채 대기하다가 결함 시 가동된다.

"Warm standby는 Cold standby와 완전히 동일하게 예비 모듈이 꺼진 채로 대기한다"라는 서술은 오답이다 — Warm standby의 예비 모듈은 **켜진 채로** 대기하되 완전히 동기화되지 않은 상태이며, 이 점에서 예비 모듈이 꺼져 있는 Cold standby와 구분된다.

<aside>하이브리드 중복 구조(Hybrid Redundancy)</aside>

정적 중복 구조(다수 모듈 입력 → 보터로 출력 결정)와 동적 중복 구조(예비 모듈을 구성하고 결함 시 교체)를 혼합한 구조다. 결함이 매우 불규칙하고 순간적으로 발생하는 경향이 있으므로, 결함 발생 부분만 잠시 격리하는 동적 방식이 결함을 완벽히 차단하는 정적 방식보다 더 효율적인 경우가 많아, 실제로는 두 방식을 함께 쓰는 경우가 흔하다.

---

<aside>핵심 정리</aside>

- 정적 중복 구조(TMR)는 다수결로, 동적 중복 구조(Hot/Warm/Cold standby)는 결함 검출 후 모듈 교체로 결함을 허용한다
- Hot standby(동시 동작·즉시 전환), Warm standby(켜진 채 부분 동기화·짧은 전환), Cold standby(하나만 동작·꺼진 예비 모듈 가동)는 전환 속도 순서와 함께 자주 뒤바뀌어 출제된다
