# Summary

**점유격자지도**는 공간을 격자로 나눠 점유 확률을 저장하는 방식이고, **특징지도**는 벽·모서리 같은 구조물을 몇 개의 기하학적 파라미터로 표현하는 방식이다.

# Notes

<aside>점유격자지도(Occupancy Grid Map)</aside>

로봇의 환경 공간을 일정 간격의 2차원 격자(cell)로 나누고, 각 셀을 **주행 가능한 빈 공간·장애물이 있는 점유 공간·알 수 없는 공간**으로 표현하는 지도다. 센서 노이즈를 반영해 각 셀은 0(빈 공간)~1(점유) 사이의 **확률값**으로 저장되며, 이 확률은 [[로그 오즈(Log Odds)|로그 오즈(log odds)]] 형태로 변환해 계산하면 여러 센서 관측을 단순한 덧셈만으로 재귀적으로 업데이트할 수 있다.

- **장점**: 구축·관리가 쉽고, 임의의 비정형 공간 구조도 직관적으로 표현 가능
- **단점**: 공간이 넓어질수록 격자 수가 늘어나 지도 데이터의 저장량이 비례해서 커짐

"점유격자지도에서 로그 오즈 방식의 장점은 저장 공간을 획기적으로 줄여 격자 수 증가 문제를 근본적으로 해결하는 것이다"라는 서술은 오답이다 — 로그 오즈 방식의 실제 장점은 여러 센서 관측값을 **곱셈이 아닌 덧셈으로 재귀적으로 업데이트**할 수 있어 계산이 간단해진다는 것이며, 격자 수 자체가 늘어나는 문제(저장량 증가)를 해결하지는 못한다.

<aside>특징지도(Feature Map)</aside>

로봇이 센서로 계측 가능한 환경의 구조물(벽·모서리 등)을 **선(모서리), 면(벽면), 다각형, 원(램프)** 같은 기하학적 특징으로 표현하는 지도다. 예를 들어 벽이나 바닥의 거리 데이터를 하나의 직선(기울기·절편)으로 근사하는 최소자승법이나, 여러 직선이 섞인 데이터에서 각 직선을 강건하게 추출하는 RANSAC 알고리즘을 사용한다.

- **장점**: 선·면·원 등을 몇 개의 수식 파라미터만으로 표현할 수 있어 지도 데이터 용량이 크게 줄어들고, 격자처럼 공간을 이산화(discretization)하는 문제가 없음
- **단점**: 기하학적으로 정형화하기 어려운 비정형 환경 표현에는 부적합하며, 특징점이 늘어날수록 계산량이 비례해서 증가함

<aside>예시 — 두 지도의 선택 기준</aside>

**예시**: 형태가 복잡하고 예측하기 어려운 창고 내부는 점유격자지도로 표현하는 것이 직관적이고, 사무실처럼 벽과 통로가 직선 위주로 정형화된 공간은 특징지도로 표현하면 지도 용량을 크게 줄일 수 있다.

---

<aside>핵심 정리</aside>

- 점유격자지도는 구축이 쉽지만 공간이 넓어질수록 저장량이 늘어나며, 로그 오즈 방식은 저장량 문제가 아니라 업데이트 계산을 단순화하는 것이 장점이다
- 특징지도는 데이터 용량이 작지만 비정형 환경 표현에는 부적합하다
