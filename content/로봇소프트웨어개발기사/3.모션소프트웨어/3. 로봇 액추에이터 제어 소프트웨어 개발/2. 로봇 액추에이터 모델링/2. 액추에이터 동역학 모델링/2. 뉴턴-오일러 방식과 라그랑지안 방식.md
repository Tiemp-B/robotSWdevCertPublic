# Summary

**뉴턴-오일러(Newton-Euler) 방식**은 힘의 균형을 기반으로 계산량이 적어 실시간 제어에 유리하고, **라그랑지안(Lagrangian) 방식**은 운동에너지·위치에너지의 차이로 동역학을 표현해 유도가 간단하고 각 변수의 효과를 이해하기 쉽다.

# Notes

<aside>뉴턴-오일러(Newton-Euler) 방식</aside>

동적 시스템에 뉴턴의 운동 법칙을 직접 적용해, 각 링크의 좌표에서 힘과 모멘트로 동역학을 나타내는 방법이다.

- **힘의 균형(force balance)** 기반 접근
- 각 링크를 순서대로 따라가며 속도·가속도를 계산하는 순방향 계산과, 그 결과로 힘·토크를 구하는 역방향 계산으로 이루어짐
- **장점**: 계산량이 적어 실시간 제어(시뮬레이션·컴퓨터 계산)에 효율적

<aside>라그랑지안(Lagrangian, Euler-Lagrangian) 방식</aside>

시스템의 동적 특성을 **일과 에너지의 개념**으로 나타내는 방법으로, 라그랑지안 함수 $L = K - P$(운동에너지 $K$ 빼기 위치에너지 $P$)로부터 다음 방정식을 통해 동역학을 유도한다.

$$\frac{d}{dt}\left[\frac{\partial L}{\partial \dot q_i}\right] - \frac{\partial L}{\partial q_i} = \tau_i$$

- **에너지 기반(energy-based)** 접근으로, 뉴턴-오일러 방식보다 **간단**하며 일반좌표에 근거함
- **장점**: 로봇 운동에 작용하는 여러 변수(관성·중력 등)의 효과를 비교적 쉽게 이해할 수 있음

<aside>두 방식의 비교</aside>

| 구분 | 뉴턴-오일러 | 라그랑지안 |
|---|---|---|
| 접근 기반 | 힘의 균형 | 에너지(운동+위치) |
| 계산량 | 적음 → 실시간 제어에 유리 | 상대적으로 많음 |
| 유도 난이도 | 링크별 순차 계산 필요 | 에너지식 기반으로 비교적 간단 |
| 강점 | 시뮬레이션·실시간 계산 | 변수별 효과의 직관적 이해 |

<aside>표준 운동방정식 — 두 방식이 도달하는 같은 결과</aside>

뉴턴-오일러·라그랑지안 두 방식은 유도 과정은 다르지만, 결국 같은 **[[로봇 동역학 표준 운동방정식(M·C·g)|표준 운동방정식]]**으로 귀결된다.

$$M(q)\ddot q + C(q,\dot q)\dot q + g(q) = \tau$$

- $M(q)$(관성행렬): 관절각(자세)에 따라 값이 달라지는 대칭 행렬
- $C(q,\dot q)\dot q$(코리올리·원심력항): 자세와 속도에 함께 의존하는 상호작용력
- $g(q)$(중력항): 속도와 무관하게 자세에만 의존하는 항

실무에서는 로봇이 자중으로 늘어지지 않도록 중력항에 의한 중력보상은 반드시 반영하지만, 저속으로 동작하는 일반 산업용 로봇 팔에서는 코리올리·원심력항을 생략해 계산 부하를 줄이기도 한다.

<aside>예시 — 두 방식의 선택 기준</aside>

**예시**: 실시간으로 로봇을 제어해야 하는 임베디드 시스템에서는 계산량이 적은 뉴턴-오일러 방식이 유리하고, 로봇 설계 단계에서 각 관절의 관성·중력 항이 전체 동역학에 미치는 영향을 분석·이해하려는 목적에는 라그랑지안 방식이 유리하다.

---

<aside>핵심 정리</aside>

- 뉴턴-오일러는 힘 기반, 계산량이 적어 실시간 제어에 유리하다
- 라그랑지안은 에너지 기반, 유도가 간단하고 변수별 효과를 이해하기 쉬우며, 계산량이 적은 것이 장점은 아니다
- 두 방식 모두 표준 운동방정식 $M(q)\ddot q+C(q,\dot q)\dot q+g(q)=\tau$로 귀결되며, $M$은 자세 의존, $C$는 자세·속도 의존, $g$는 속도와 무관하게 자세에만 의존한다
