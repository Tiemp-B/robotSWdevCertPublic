# Summary

**펌웨어**는 하나의 하드웨어에서 응용프로그램 교체 없이 항상 같은 프로그램만 반복 실행하는 소프트웨어이며, 전원이 켜지면 **부트로더**가 이를 초기화해 실행 준비를 마친다.
