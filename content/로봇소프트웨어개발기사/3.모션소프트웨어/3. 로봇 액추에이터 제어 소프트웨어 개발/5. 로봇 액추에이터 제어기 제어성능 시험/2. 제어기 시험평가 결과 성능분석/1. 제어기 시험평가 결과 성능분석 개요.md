# Summary

제어기 시험평가 결과를 분석할 때는 응답 특성 수치뿐 아니라, 실시간 제어 시스템이 **정해진 시간(데드라인) 안에 동작을 완료하는지**를 나타내는 실시간성 지표도 함께 살펴봐야 한다.

<aside>이미 다룬 내용과의 관계</aside>

부하 테스트(Load Testing)는 과목2 "로봇 시스템 통합"에서, 단위 테스트(Unit Test)는 과목2 "로봇 시스템 시험평가"에서 이미 다뤘으므로 반복하지 않고 링크로 참조한다. 이 세세항목은 아직 다루지 않은 **실시간 제어 시스템의 성능평가 지표**에 집중한다.

<aside>이 세세항목의 구성</aside>
