# Summary

로봇 서보 제어계는 **전류 루프(가장 안쪽, 가장 빠름) → 속도 루프 → 위치 루프(가장 바깥쪽, 가장 느림)**의 3중 구조로 설계되며, 정밀한 위치 제어를 위해서는 마찰력 같은 비선형 외란을 별도로 보상한다.

# Notes

<aside>전류-속도-위치 다중 루프 구조</aside>

| 루프 | 위치(안쪽↔바깥쪽) | 제어 대상 | 응답 속도 |
|---|---|---|---|
| 전류 제어 루프 | 가장 안쪽 | 모터 전류(토크) | 가장 빠름 |
| 속도 제어 루프 | 중간 | 모터 속도 | 중간 |
| 위치 제어 루프 | 가장 바깥쪽 | 로봇 위치 | 가장 느림 |

전류 루프가 가장 먼저 원하는 전류(토크)를 만들고, 엔코더 신호를 미분해 얻은 속도를 속도 루프가 제어하며, 최종적으로 엔코딩 신호로 위치 루프가 원하는 위치에 도달하도록 제어한다. 안쪽 루프일수록 응답이 빠르고 응답 주파수 대역이 넓어야, 바깥쪽 루프가 안정적으로 동작할 수 있다.

"서보 제어의 다중 루프 구조에서 가장 응답이 빨라야 하는 루프는 가장 바깥쪽의 위치 제어 루프다"라는 서술은 오답이다 — 가장 응답이 빨라야 하는 것은 **가장 안쪽의 전류 제어 루프**이며, 위치 제어 루프는 가장 바깥쪽에서 가장 느리게 동작한다.

<aside>서보모터 위치 제어의 마찰력 보상</aside>

정밀 위치 제어에서는 베어링·기어 등에서 발생하는 마찰력(특히 저속에서 두드러지는 정지 마찰, 방향 전환 시 발생하는 스틱-슬립 현상)이 위치 오차의 원인이 된다. 대표적인 보상 방법은 다음과 같다.

- **마찰 모델 기반 보상**: 사전에 구한 마찰력 모델(속도의 함수)만큼 제어 입력에 추가로 더해줌(피드포워드 보상)
- **적분(I) 제어 활용**: 정상상태에서 남는 오차를 적분 제어로 서서히 제거
- **저더더링(dithering)**: 미세한 고주파 진동을 더해 정지 마찰의 비선형성을 완화

"서보모터 위치 제어에서 마찰력을 보상하는 방법으로는 엔코더의 분해능을 낮추는 것이 적절하다"라는 서술은 오답이다 — 엔코더 분해능을 낮추는 것은 위치 측정 정밀도만 떨어뜨릴 뿐 마찰력 보상과는 무관하며, 마찰 보상은 **마찰 모델 기반 피드포워드, 적분 제어, 저더링** 등으로 이루어진다.

<aside>핵심 정리</aside>

- 서보 제어는 전류(가장 빠름)-속도-위치(가장 느림) 순의 다중 루프로 설계된다
- 마찰력 보상은 마찰 모델 피드포워드, 적분 제어, 저더링 등으로 이루어지며 엔코더 분해능과는 무관하다
