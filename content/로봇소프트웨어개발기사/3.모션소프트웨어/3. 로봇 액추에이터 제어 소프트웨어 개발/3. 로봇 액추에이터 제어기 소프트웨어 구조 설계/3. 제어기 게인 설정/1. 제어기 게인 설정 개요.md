# Summary

PID 게인을 대상 시스템의 정밀한 수학적 모델 없이 실험적으로 결정하는 대표적 자동 동조(auto-tuning) 방법이 **지글러-니콜스(Ziegler-Nichols) 동조법**이다.

<aside>이미 다룬 내용과의 관계</aside>

PID 게인(Kp·Ki·Kd) 각각의 역할과 P/I/D 제어의 개별 효과는 1과목 "로봇 제어기 특성"에서 이미 다뤘으므로 반복하지 않고 링크로 참조한다. 이 세세항목은 아직 다루지 않은 **게인을 실제로 결정하는 동조(tuning) 방법**에 집중한다.

<aside>이 세세항목의 구성</aside>

다음 페이지는 [[2. 지글러-니콜스 동조법|지글러-니콜스 동조법]](임계 게인·임계 주기를 이용한 PID 게인 산출 공식)을 다룬다.
