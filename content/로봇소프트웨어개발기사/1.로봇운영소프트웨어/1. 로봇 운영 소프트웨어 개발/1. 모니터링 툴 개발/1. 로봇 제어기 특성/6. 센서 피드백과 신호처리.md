# Summary

로봇 제어기가 [[4. 제어 응답 특성 지표 전반|피드백 제어]]를 하려면 실제 위치를 측정하는 센서가 필요하며, 서보 위치 피드백의 표준 센서는 **[[엔코더(Encoder)|엔코더]]**다. 센서 신호에는 전기적 노이즈가 섞이므로 이를 완화하는 신호처리(필터링)가 함께 쓰이며, 목적과 정밀도에 따라 여러 종류의 필터가 사용된다.

# Notes

<aside>서보 위치 피드백과 엔코더</aside>

엔코더는 모터축의 기계적 회전을 전기 신호로 변환해 위치·속도·방향 정보를 제어기에 실시간 피드백하며, 제어기는 이 피드백과 목표값의 오차로 제어 신호를 갱신하는 **폐루프(closed-loop)** 구조를 만든다.

- **증분형(Incremental) 엔코더**: 회전량(펄스 수)만 측정 — 전원이 꺼지면 절대 위치 정보를 잃어 재기동 시 원점 복귀(호밍) 동작이 필요
- **절대형(Absolute) 엔코더**: 축의 절대 각도를 직접 출력 — 전원이 꺼졌다 켜져도 원점 복귀 없이 현재 위치를 바로 파악

가속도계·자이로도 로봇에 사용되지만, **서보 모터 위치 피드백**의 가장 대표적이고 직접적인 센서는 엔코더라는 점이 핵심이다.

<aside>센서 노이즈</aside>

산업 현장의 전자기 간섭(EMI)이 엔코더 신호를 왜곡시켜 위치·속도 값에 오차를 유발할 수 있다. 특히 엔코더의 위치 값을 그대로 미분해 속도를 추정하면 측정 노이즈가 그대로 증폭되어 제어 신호에 **채터링(chattering, 잦은 미세 진동)**이 나타날 수 있다 

노이즈 대응책
- 차폐 케이블·접지 
- 노이즈에 상대적으로 강인한 광학식 엔코더 채택
- 신호처리(필터링)

<aside>필터</aside>

필터(Filter)는 센서에서 들어오는 원신호에 섞인 노이즈를 제거하거나 완화하여, 제어기가 신뢰할 수 있는 값을 사용하도록 가공하는 신호처리 기법이다. 노이즈 제거 정도와 응답 지연은 대부분 트레이드오프 관계에 있다.

- **[[이동평균 필터(Moving Average Filter)|이동평균 필터]]** : 최근 N개 데이터를 평균 내어 현재 값으로 사용하는 가장 단순한 필터
    - 구현이 매우 간단하나, 윈도우(평균 구간)가 클수록 노이즈 제거 효과와 지연시간이 함께 커짐
- **[[저역통과 필터(Low-pass Filter)|저역통과 필터]]** : 낮은 주파수 성분은 통과시키고 높은 주파수(고주파 노이즈)는 감쇠시키는 필터
    - 이동평균 필터는 저역통과 필터의 한 가지 간단한 구현 형태로 볼 수 있음
- **[[칼만 필터(Kalman Filter)|칼만 필터]]** : 시스템의 운동 모델을 이용한 예측과 실제 측정값을 확률적으로 결합해 상태를 추정하는 재귀 필터
    - 위치·속도 등을 정밀 추정해야 할 때 이동평균 필터보다 정교한 선택지
- **[[상보 필터(Complementary Filter)|상보 필터]]** : 저역통과 필터와 고역통과 필터를 결합해 서로 다른 센서(예: 가속도계·자이로)의 장점만 취하는 필터
    - 계산이 간단하면서도 칼만 필터에 근접한 성능을 낼 때 사용

실시간 서보 제어 루프처럼 빠른 응답이 중요한 구간에서는 단순 이동평균 필터의 지연이 부담될 수 있어, 저역통과 필터나 칼만 필터처럼 지연을 더 정교하게 관리하는 방법이 함께 고려되기도 한다.

<aside>핵심 정리</aside>

- 서보 위치 피드백의 대표 센서 = **엔코더**(증분형: 전원차단 시 위치소실 / 절대형: 위치유지)
- EMI 노이즈는 엔코더 신호를 왜곡시키고, 위치의 단순 미분으로 속도 추정 시 노이즈가 증폭돼 **채터링** 유발
- 필터는 노이즈 제거와 응답 지연의 트레이드오프 관계 — 이동평균(단순) < 저역통과(주파수 기반) < 칼만/상보(모델·센서융합 기반) 순으로 정교해짐
