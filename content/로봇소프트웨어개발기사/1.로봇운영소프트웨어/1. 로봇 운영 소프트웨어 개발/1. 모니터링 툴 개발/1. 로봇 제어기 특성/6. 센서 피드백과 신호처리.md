# Summary

로봇 제어기가 [[4. 제어 응답 특성 지표 전반|피드백 제어]]를 하려면 실제 위치를 측정하는 센서가 필요하며, 서보 위치 피드백의 표준 센서는 **[[엔코더(Encoder)|엔코더]]**다. 센서 신호에는 전기적 노이즈가 섞이므로 이를 완화하는 신호처리(필터링)가 함께 쓰이며, 가장 단순한 방법이 **[[이동평균 필터(Moving Average Filter)|이동평균 필터]]**다.

# Notes

<aside>서보 위치 피드백과 엔코더</aside>

엔코더는 모터축의 기계적 회전을 전기 신호로 변환해 위치·속도·방향 정보를 제어기에 실시간 피드백하며, 제어기는 이 피드백과 목표값의 오차로 제어 신호를 갱신하는 **폐루프(closed-loop)** 구조를 만든다.

- **증분형(Incremental) 엔코더**: 회전량(펄스 수)만 측정 — 전원이 꺼지면 절대 위치 정보를 잃어 재기동 시 원점 복귀(호밍) 동작이 필요
- **절대형(Absolute) 엔코더**: 축의 절대 각도를 직접 출력 — 전원이 꺼졌다 켜져도 원점 복귀 없이 현재 위치를 바로 파악

가속도계·자이로도 로봇에 사용되지만, **서보 모터 위치 피드백**의 가장 대표적이고 직접적인 센서는 엔코더라는 점이 핵심이다.

<aside>센서 노이즈 문제</aside>

산업 현장의 전자기 간섭(EMI)이 엔코더 신호를 왜곡시켜 위치·속도 값에 오차를 유발할 수 있다. 특히 엔코더의 위치 값을 그대로 미분해 속도를 추정하면 측정 노이즈가 그대로 증폭되어 제어 신호에 **채터링(chattering, 잦은 미세 진동)**이 나타날 수 있다 — 노이즈 대응책은 차폐 케이블·접지, 노이즈에 상대적으로 강인한 광학식 엔코더 채택, 그리고 아래의 신호처리(필터링)다.

<aside>이동평균 필터(Moving Average Filter)</aside>

과거 N개의 데이터를 평균 내어 현재 값을 계산하는 가장 단순한 필터다.

- **장점**: 구현이 매우 간단하고 무작위 노이즈를 효과적으로 완화
- **단점 — 지연시간(Lag)**: 과거 값을 평균하므로 실제 신호가 급격히 변해도 필터 통과 값은 뒤늦게 반응한다. 윈도우(평균에 쓰는 데이터 개수)가 클수록 노이즈 제거 효과는 커지지만 지연시간도 함께 커진다 — 노이즈 제거와 응답 지연은 트레이드오프 관계다

이 지연 특성 때문에 실시간 서보 제어 루프처럼 빠른 응답이 중요한 구간에는 [[저역통과 필터(Low-pass Filter)|저역통과 필터]]나 [[칼만 필터(Kalman Filter)|칼만 필터]]처럼 지연을 더 정교하게 관리하는 방법이 함께 고려되기도 한다("이동평균필터는 잡음 완화가 목적, 칼만필터는 예측모델을 반영한 정밀 추정이 목적"이라는 선택 기준으로 구분한다 — 칼만 필터의 본격적인 원리는 이동로봇 위치추정 페이지에서 다루므로 반복하지 않는다).

---

<aside>핵심 정리</aside>

- 서보 위치 피드백의 대표 센서 = **엔코더**(증분형: 전원차단 시 위치소실 / 절대형: 위치유지)
- EMI 노이즈는 엔코더 신호를 왜곡시키고, 위치의 단순 미분으로 속도 추정 시 노이즈가 증폭돼 **채터링** 유발
- 이동평균 필터 = 과거 N개 평균, 노이즈 완화는 되지만 **지연시간** 발생(윈도우 ↑ → 노이즈제거 ↑, 지연 ↑)
