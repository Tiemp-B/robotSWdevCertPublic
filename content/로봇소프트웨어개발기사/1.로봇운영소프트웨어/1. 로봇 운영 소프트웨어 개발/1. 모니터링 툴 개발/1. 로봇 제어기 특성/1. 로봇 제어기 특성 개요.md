# Summary

**로봇 제어기**는 연산·구동·감지·통신·안전 하드웨어와 실시간 OS부터 응용 계층까지 이어지는 소프트웨어 계층이 결합된 시스템이다. 모니터링 프로그램을 만들려면 제어기가 PC와 어떤 경로로 데이터를 주고받는지, 제어기의 구조·실시간성·통신 방식이 무엇인지 파악해야 한다. 이 노트는 “로봇 제어기 특성”의 허브 역할을 하며, 세부 주제는 하단 관련 노트로 연결한다.

# Notes

<aside>제어기와 PC의 통신</aside>

로봇 제어기를 모니터링하려면 제어기에서 측정한 값을 PC로 보내고, 필요할 때 PC의 설정·명령을 제어기에 전달해야 한다. 사용 환경에 따라 시리얼 통신, 산업용 필드버스, 이더넷 기반 통신을 사용한다.

- **시리얼 통신**: 구현이 단순하고 소형 MCU와 PC를 연결하기 쉽다. RS-232, RS-485, USB-시리얼 방식이 대표적이다.
- **필드버스**: CAN, EtherCAT 등은 드라이브·분산 I/O·센서 모듈을 연결하는 데 사용한다. 제어 주기와 결정성이 중요한 경우에 적합하다.
- **네트워크 통신**: Ethernet/TCP-IP, ROS 기반 메시지 등은 상위 PC, 서버, HMI와 상태·명령을 교환하는 데 사용한다.

PC 측 모니터링 프로그램은 통신 포트·연결 상태를 관리하고, 수신한 위치·속도·토크·온도·에러 코드 등을 표시·기록한다. 어떤 값을 수집할지는 사용자 요구사항과 제어기에서 제공하는 인터페이스에 따라 결정한다.

<aside>제어기 하드웨어 구성</aside>

로봇 제어기의 하드웨어는 다음과 같이 구성된다.

- **연산 보드**: 제어 알고리즘을 실행하는 처리 장치이며, 산업용 PC, MCU, FPGA 등이 사용된다.
- **모터 드라이버·서보 앰프**: 상위 제어 명령을 전류·전압 등 실제 구동 신호로 변환해 모터를 구동한다.
- **센서 인터페이스 회로**: 엔코더, 전류 센서, IMU 등의 아날로그·디지털 신호를 수집·변환해 연산부에 전달한다.
- **통신 모듈**: 상위 제어기·PC·서버 및 분산 장치와 데이터를 송수신한다.
- **전원·안전 회로**: 전력 공급과 과전류·과열 보호, 비상정지 신호 처리를 담당한다.

연산부와 드라이버부가 하나로 통합된 **일체형**과 별도 모듈로 분리된 **분리형**으로 구성할 수 있다. 이 차이는 모니터링 데이터를 상위 PC 레벨에서 수집할지, 드라이버 레벨까지 수집할지에 영향을 준다.

<aside>제어기 소프트웨어 계층</aside>

- **OS 계층**: RTOS 또는 일반 OS가 태스크 실행과 자원 관리를 담당한다.
- **저수준 제어 계층**: 위치·속도·전류를 PID 등의 제어기로 처리하는 서보 루프다. 짧은 주기로 실행되는 실시간 영역이다.
- **미들웨어·통신 계층**: 상위 응용과 하드웨어 사이에서 프로토콜 스택과 메시지 교환을 담당한다.
- **응용·관리 계층**: 모니터링, 로깅, 진단, 사용자 인터페이스를 제공한다.

저수준 제어 계층에서 생성된 상태 데이터(위치·속도·토크·에러)는 응용 계층의 모니터링 프로그램이 주기적으로 읽는다. 제어 계층으로 갈수록 요구되는 제어 주기는 짧고 엄격하며, 모니터링·UI·로깅은 상대적으로 느슨한 주기로 동작한다.

<aside>제어기 분류 방식</aside>

**구조에 따른 분류**

| 유형 | 특징 | 예 |
|---|---|---|
| 중앙집중형 | 단일 컨트롤러가 전체 관절을 직접 제어 | 산업용 매니퓰레이터 |
| 분산형 | 관절·모듈별 로컬 제어기와 상위 통합 관리자로 구성 | 협동로봇, 모듈형 로봇팔 |
| 계층형 | 상위 작업계획, 중위 궤적생성, 하위 서보제어로 역할 분리 | 산업·서비스 로봇 |

**실시간성에 따른 분류**: 실시간 제어기는 정해진 주기와 데드라인 안에 응답을 완료하는지를 기준으로 한다. 모니터링·UI·로깅은 시간 제약이 느슨한 비실시간 영역으로 구분할 수 있다.

**통신 방식에 따른 분류**: EtherCAT·CAN·Modbus 등의 필드버스형, TCP/IP·ROS 토픽 등의 네트워크형, RS-232·RS-485 등의 시리얼형으로 구분할 수 있다.

<aside>핵심 정리</aside>

- 로봇 제어기는 하드웨어와 소프트웨어 계층이 결합된 제어 시스템이다.
- 구성 요소는 연산·구동·감지·통신·전원/안전으로 나눌 수 있다.
- 모니터링 툴은 제어기를 직접 대체하지 않고, 제어기 상태·성능·알람을 수집해 표시·기록하는 상위 계층이다.
- 제어기는 구조, 실시간성, 통신 방식에 따라 분류할 수 있다.
