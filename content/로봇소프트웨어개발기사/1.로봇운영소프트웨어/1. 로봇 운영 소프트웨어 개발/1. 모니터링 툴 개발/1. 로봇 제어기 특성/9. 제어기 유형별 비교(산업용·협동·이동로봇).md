# Summary

같은 "로봇 제어기"라도 산업용 매니퓰레이터·협동로봇·이동로봇은 제어 대상과 목표가 다르다. 산업용은 **정확한 위치**를, 협동로봇은 **사람과 접촉해도 안전한 힘/토크**를, 이동로봇은 **속도·조향과 위치 인식**을 주로 제어한다. 이 페이지는 [[1. 로봇 제어기 특성 개요]]에서 다룬 구조 분류(중앙집중형/분산형/계층형)를 로봇 유형 관점에서 구체화한다.

# Notes

<aside>산업용 매니퓰레이터 제어기</aside>

- **제어 대상**: 각 관절의 **위치(Position Control)** — 정해진 좌표로 정확·고속 이동이 목표
- **환경 가정**: 안전펜스 안, 사람과 격리된 고정 작업 환경을 전제
- **대표 기법**: 위치 PID + 궤적 생성(보간법)을 통한 정밀 위치 제어
- **하드웨어 특징**: 고강성(rigid) 구조, 고출력 서보 모터, 높은 위치 반복 정밀도

<aside>협동로봇(Cobot) 제어기</aside>

**[[협동로봇(Cobot)|협동로봇]]**은 안전펜스 없이 사람과 같은 공간에서 함께 작업하도록 설계된다.

- **제어 대상**: 위치뿐 아니라 **힘/토크(Force/Torque Control)** — 사람과의 접촉을 즉시 감지해 힘을 제한해야 하기 때문
- **[[컴플라이언스 제어(Compliance Control)|컴플라이언스 제어]]**: 관절이 스프링처럼 유연하게 반응해 외부 접촉 시 딱딱하게 버티지 않고 부드럽게 밀려나도록 하는 기법 — 순수 위치 제어만으로는 구현할 수 없고 토크 센서 기반 힘 제어가 필요
- **ISO/TS 15066의 동력·힘 제한(Power and Force Limiting)** 모드가 이 컴플라이언스 제어를 안전기준 차원에서 뒷받침한다 — 4대 협업 모드 전체는 [[8. 안전 회로와 기능안전]] 참고
- 산업 사례에서는 제어를 계층으로 나눠, 접촉을 즉시 감지·반응하는 **안전 지능/컴플라이언스 제어 계층**과 정밀한 궤적 보정을 담당하는 **정밀 작업 계층**을 함께 구성해 안전성과 정밀도를 동시에 확보하는 구조가 흔하다

<aside>이동로봇 제어기</aside>

- **제어 대상**: 관절 위치가 아니라 로봇 전체의 **속도·조향(Velocity/Steering Control)** — 목표 지점까지 경로를 따르도록 바퀴(또는 다리) 속도를 제어
- **대표 구동 방식**: 차동 구동(좌우 바퀴 속도 차이로 방향 전환), 옴니휠(전방향 이동) 등
- **계층 구조**: 상위(고수준) 플래너가 목표 지점 획득·경로계획을 담당하고, 하위(저수준) 제어기가 로봇의 운동학/동역학 모델을 바탕으로 개별 액추에이터 입력으로 변환한다. 저수준 제어기는 각 액추에이터의 오차를 PID로 계산하며, **오도메트리**(엔코더 등에서 산출한 위치추정, [[추측항법(Dead Reckoning)|추측항법]] 기반)를 실제 속도 피드백으로 사용해 상위 명령과 비교한다
- 산업용/협동로봇과 달리 작업 공간이 고정돼 있지 않고 계속 변화하는 환경(장애물 등)에 실시간 대응해야 하며, 목적지까지 이동하려면 위치 인식·지도 작성(SLAM 등)이 결합돼야 한다

<aside>세 유형 비교</aside>

| 구분 | 산업용 매니퓰레이터 | 협동로봇(Cobot) | 이동로봇 |
|---|---|---|---|
| 주 제어 대상 | 관절 위치 | 위치 + 힘/토크 | 속도/조향 |
| 대표 제어 기법 | 위치 PID + 궤적 생성 | 컴플라이언스 제어(힘 기반) | 속도 제어 + 오도메트리 + 위치인식/지도작성 |
| 사람과의 공존 | 안전펜스로 격리 | 같은 공간에서 직접 협업 | 개방된 공간에서 이동하며 공존 |
| 핵심 안전 요구 | 접근 금지(펜스·인터록) | 접촉력 제한, 충돌 감지(ISO/TS 15066) | 장애물 회피, 충돌 방지 |

---

<aside>핵심 정리</aside>

- 산업용 = **위치 제어** 중심, 협동로봇 = **위치+힘/토크(컴플라이언스) 제어**, 이동로봇 = **속도/조향 + 오도메트리 기반 위치인식**
- 협동로봇 컴플라이언스 제어는 순수 위치 제어로 구현 불가 — 토크 센서 기반 힘 제어 + ISO/TS 15066 PFL 모드가 뒷받침
- 이동로봇은 상위(경로계획)-하위(액추에이터 제어) 계층 구조이며, 오도메트리를 속도 피드백으로 사용
