# Summary

로봇 제어기의 성능은 계단 입력(목표값이 순간적으로 바뀌는 입력)에 대한 응답을 정량화한 **응답 특성 지표**(상승시간·정착시간·오버슈트·정상상태오차)로 평가된다. 대부분의 로봇 제어기는 **[[PID 제어|PID]] 제어기**로 이 지표들을 조정하며, 오차를 사후에 보정하는 **피드백 제어**와 모델 기반으로 미리 보정하는 **피드포워드 제어**를 함께 사용하는 경우가 많다.

<aside>PID 제어기의 세 요소</aside>

PID 제어기는 **비례(P)+적분(I)+미분(D)** 세 동작의 합으로 구성된다.

$$u(t) = K_p\,e(t) + K_i\int e(t)\,dt + K_d\,\frac{de(t)}{dt}$$

- **P(비례)**: 현재 오차 크기에 비례한 출력. 게인을 높이면 응답은 빨라지지만 지나치면 오버슈트·불안정 위험 증가
- **I(적분)**: 과거 오차를 누적 반영해 **정상상태오차를 제거**하는 역할. 게인을 과도하게 높이면 오차가 과누적돼 오버슈트가 커지고 오히려 안정성이 떨어질 수 있다
- **D(미분)**: 오차 변화율에 반응해 오버슈트를 억제하고 응답을 빠르게 감쇠시키지만, 측정 노이즈에 민감해지는 단점이 있다

<aside>피드백 제어 vs 피드포워드 제어</aside>

| 구분 | 피드백 제어 | 피드포워드 제어 |
|---|---|---|
| 동작 | 출력을 센서로 측정해 목표값과 비교 후 보정(사후) | 시스템 모델로 오차 발생 전에 미리 보정(사전) |
| 센서 | 반드시 필요 | 이론상 불필요(모델 기반 예측) |
| 외란 대응 | 외란이 반영된 뒤 사후 보정 → 외란에 강함 | 예측 못 한 외란에는 대응 불가 |
| 요구사항 | 정확한 오차 측정 | 정확한 시스템 모델 필수 |

실무에서는 피드포워드로 예상되는 큰 흐름(목표 궤적에 따른 예상 토크 등)을 미리 보정하고, 피드백으로 남은 오차·외란을 보정하는 **혼합 구조**가 흔하다.

<aside>핵심 정리</aside>

- 응답 지표 $t_r$(상승시간)·$t_s$(정착시간)·$M_p$(오버슈트)·$e_{ss}$(정상상태오차)는 서로 트레이드오프
- PID = **P(비례)+I(적분)+D(미분)**, I는 정상상태오차 제거·과도하면 안정성 저하, D는 오버슈트 억제·노이즈에 민감
- 피드백: 센서 필수·외란에 강함 / 피드포워드: 모델 필수·예측 못 한 외란에 취약, 실무는 혼합 구조가 흔함
