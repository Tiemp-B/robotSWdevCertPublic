# Summary

**[[SCADA]]**(Supervisory Control And Data Acquisition)는 지리적으로 분산된 다수의 현장 설비(로봇 셀, 공정 장비 등)를 하나의 중앙 시스템에서 감시·기록·알람 처리하는 산업용 모니터링 체계다. 이름에 "제어(Control)"가 들어가지만, 서보 모터의 위치·전류 루프 같은 **고속 폐루프 제어를 직접 수행하지는 않는다** — 그 역할은 현장의 PLC/로봇 제어기가 맡고, SCADA는 그보다 상위에서 데이터를 모으고 사람이 개입할 지점(알람, 원격 명령)을 제공하는 **감시(Supervisory) 계층**이다.

# Notes

<aside>SCADA 시스템의 계층 구조</aside>

| 계층 | 구성 요소 | 역할 |
|---|---|---|
| 현장 계층 | 센서, 액추에이터, 로봇 제어기 | 물리적 상태 생성·직접 구동 |
| 현장 제어 계층 | [[PLC(Programmable Logic Controller)\|PLC]], [[RTU(Remote Terminal Unit)\|RTU]] | 현장 신호를 직접 읽고 로컬 제어 로직 실행 |
| 통신 계층 | [[필드버스(Fieldbus)]], TCP/IP, [[MQTT]] 등 | 현장 데이터를 SCADA 서버로 전달([[2. MQTT·WebSocket과 실시간 모니터링 통신]] 참고) |
| SCADA 서버(MTU) | 데이터 수집·가공·이력 저장 | 다수 현장의 데이터를 통합, 알람 판정, 명령 하달 |
| HMI 계층 | 대시보드, 관제 화면 | 운영자에게 시각화·조작 인터페이스 제공([[4. 데이터 시각화와 알람(HMI)]] 참고) |

<aside>RTU vs PLC</aside>

- **[[RTU(Remote Terminal Unit)|RTU]]**: 지리적으로 멀리 떨어진 현장(원격 로봇 스테이션 등)의 신호를 수집해 통신망으로 SCADA 서버에 전달 — 원격지·저대역폭 환경, 이벤트/트리거 기반 통신에 특화되도록 설계되는 경우가 많음
- **[[PLC(Programmable Logic Controller)|PLC]]**: 현장에서 직접 로직 연산·제어를 수행하는 결정론적(millisecond급 스캔 주기) 산업용 컨트롤러 — 로봇 셀 내부 인터록, 컨베이어 연동 등 근거리·고밀도 I/O 제어에 주로 사용
- 최근에는 하나의 장치가 RTU와 PLC 기능을 함께 수행하는 경우도 많아 경계가 엄격하지 않다 — 핵심은 "현장 신호 수집·로컬 제어를 SCADA 서버보다 먼저 담당하는 계층"이라는 점

<aside>SCADA의 주요 기능</aside>

| 기능 | 설명 |
|---|---|
| 데이터 수집 | 현장 센서·상태값을 주기적/이벤트 기반으로 수집 |
| 감시 | 수집된 데이터를 기준으로 현재 상태를 실시간 표시 |
| 알람 | 임계값 이탈·이상 상태를 감지해 운영자에게 통보 |
| 이력 저장(Historian) | 수집 데이터를 시계열로 장기 보관, 추후 분석에 활용([[5. 데이터 로깅과 이상치 탐지]] 참고) |
| 원격 명령 | 운영자 판단에 따라 현장 장비에 시작/정지 등 상위 명령 하달 |

SCADA의 "제어" 기능은 **초 단위 이하의 실시간 폐루프 제어(서보 위치 제어, 전류 루프 등)를 직접 수행하는 것이 아니다** — 그런 고속·결정론적 제어는 현장 PLC·로봇 제어기가 담당하고, SCADA는 "정지/시작/모드 전환"처럼 사람의 판단이 개입하는 상위 감독 명령만 하달한다.

<aside>SCADA vs DCS</aside>

| 항목 | SCADA | [[DCS(Distributed Control System)\|DCS]] |
|---|---|---|
| 적용 대상 | 지리적으로 넓게 분산된 다수 사이트 | 단일 플랜트 내 밀집된 공정 |
| 통신 특성 | 폴링/이벤트 기반, 지연 허용도 높음 | 전용망 기반 고속·저지연 |
| 제어 성격 | 감시 위주, 상위 명령 하달 | 공정 전반의 조밀한 실시간 제어 루프 포함 |

이 구분은 산업 자동화의 표준적인 개념 구분이며, 실제로는 두 시스템의 경계가 흐려지는(blurred) 현대 사례도 있으나 시험에서는 위 표의 전형적 구분을 기준으로 삼는다.

<aside>예시 — 로봇 플릿의 SCADA 통합 관제</aside>

**예시**: 세 곳의 공장에 흩어진 용접 로봇 셀들의 가동률·에러 코드·비상정지 상태를 본사 관제 센터의 SCADA 화면 하나에서 통합 감시할 때, 각 공장의 PLC/로봇 제어기가 로컬 인터록과 안전 제어([[E-stop(비상정지)|E-stop]] 등)를 직접 처리하고, SCADA 서버는 이 상태 데이터를 취합해 이력으로 남기고 임계치 이탈 시 알람만 전달한다 — 실시간 서보 제어는 SCADA를 거치지 않는다.

---

<aside>핵심 정리</aside>

- SCADA는 분산된 현장을 통합 감시하는 **감시 계층** — 현장 → RTU/PLC → 통신망 → SCADA 서버(MTU) → HMI
- 주요 기능: 데이터 수집·감시·알람·이력 저장·원격 명령 — **고속 폐루프 제어는 SCADA 기능이 아님**(PLC/로봇 제어기 몫)
- SCADA는 지리적 분산·지연 허용, DCS는 단일 플랜트 내 조밀한 실시간 제어라는 점에서 구분
