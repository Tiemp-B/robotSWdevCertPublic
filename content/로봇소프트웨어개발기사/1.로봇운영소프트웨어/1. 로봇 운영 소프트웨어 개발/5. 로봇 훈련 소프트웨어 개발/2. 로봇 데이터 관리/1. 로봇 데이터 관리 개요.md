# Summary

로봇을 학습시키고 운영하려면 센서·로그 등 대량의 데이터를 효율적으로 **저장·정제·분석**할 수 있어야 한다. 이 세세항목은 [[1. 로봇 훈련 프로그램 개요|로봇 훈련 프로그램]]이 사용하는 데이터를 어떤 데이터베이스에, 어떤 절차로 담고 활용하는지를 다룬다.

# Notes

<aside>로봇 데이터 관리란</aside>

로봇이 생성하는 데이터(센서 값, 위치, 로그, 학습용 이미지 등)는 양이 많고 형태도 다양하다. 이 데이터를 목적에 맞는 방식으로 저장하고, 필요할 때 빠르게 조회·분석할 수 있도록 관리하는 것이 이 세세항목의 초점이다.

<aside>세부항목 안에서의 위치</aside>

| 세세항목 | 초점 |
|---|---|
| 1. 로봇 훈련 프로그램 | 데이터를 이용해 무엇을, 어떻게 학습시키는가(알고리즘) |
| 2. 로봇 데이터 관리(이 세세항목) | 그 학습·운영에 쓰이는 데이터를 어떻게 저장·관리·분석하는가 |

<aside>이 세세항목의 구성</aside>

이후 페이지들은 다음을 다룬다: [[2. 시계열 데이터베이스와 NoSQL|시계열 데이터베이스와 NoSQL]](센서 로그·상태 데이터를 저장하는 데이터베이스 유형), [[3. 데이터 웨어하우스와 ETL|데이터 웨어하우스와 ETL]](여러 소스의 데이터를 통합·정제하는 절차), [[4. 데이터 마이닝과 샤딩|데이터 마이닝과 샤딩]](축적된 데이터에서 패턴을 찾는 방법과, 대용량 데이터를 분산 저장하는 방법).

<aside>예시 — 로봇 데이터 관리의 전체 흐름</aside>

**예시**: 수십 대의 로봇이 실시간으로 보고하는 센서 값은 시계열 데이터베이스에 쌓이고, 매일 밤 이 원본 로그는 ETL 과정을 거쳐 정제된 형태로 데이터 웨어하우스에 적재되며, 분석팀은 여기서 데이터 마이닝으로 "특정 부품이 고장 나기 전 어떤 패턴이 반복되는지" 같은 규칙을 찾아낸다.

<aside>핵심 정리</aside>

- 로봇 데이터 관리는 로봇이 생성하는 대량·다양한 데이터를 저장·정제·분석하는 것을 다룬다
- 이후 페이지는 저장(시계열DB/NoSQL) → 통합·정제(ETL/데이터 웨어하우스) → 분석·확장(데이터 마이닝/샤딩) 순으로 전개된다
