# Summary

로봇과 연동되는 IoT 디바이스 각각의 센서 값은 저마다 오차와 한계를 가진다. **[[센서 데이터 융합(Sensor Fusion)|센서 데이터 융합]]** 은 서로 다른 여러 센서(또는 IoT 디바이스)의 데이터를 결합해, 어느 한 센서만 사용할 때보다 **더 정확하고 신뢰도 높은 상태 추정**을 얻는 기법이다.

# Notes

<aside>왜 센서 데이터 융합이 필요한가</aside>

개별 센서는 저마다 약점이 있다 — 예를 들어 카메라는 어두운 곳에서 성능이 떨어지고, 초음파 센서는 얇거나 흡음성 있는 물체를 놓치기 쉬우며, 원격 IoT 온도 센서 하나만으로는 통신 오류로 인한 이상값을 걸러내기 어렵다. 여러 종류의 센서·디바이스 데이터를 함께 활용하면 **한 센서의 약점을 다른 센서의 데이터로 보완**할 수 있다.

<aside>센서 데이터 융합의 주요 목적</aside>

| 목적 | 설명 |
|---|---|
| 정확도 향상 | 여러 측정값을 결합해 잡음을 줄이고 실제 값에 더 가까운 추정치를 얻음 |
| 신뢰성 확보 | 한 센서가 통신 오류·고장으로 이상값을 보내도, 다른 센서 데이터와 비교해 걸러낼 수 있음 |
| 정보의 보완 | 서로 다른 종류의 센서가 각자 다른 측면(위치, 온도, 영상 등)을 담당해 종합적인 상황 인식이 가능 |

<aside>대표적인 융합 방식(개념 수준)</aside>

- **평균·가중 평균**: 여러 센서 값의 (가중) 평균을 취해 잡음을 줄이는 가장 단순한 방식
- **[[칼만 필터(Kalman Filter)|칼만 필터]] 기반 추정**: 이전 상태 예측값과 새로운 센서 측정값을 확률적으로 결합해, 잡음이 섞인 측정에서도 신뢰도 높은 상태(위치, 속도 등)를 지속적으로 추정하는 방법 — 각 센서·예측의 불확실성 정도에 따라 반영 비중을 다르게 준다
- **다수결/투표 방식**: 여러 센서 중 다수가 동의하는 값을 채택해, 소수의 이상값(고장 센서)을 걸러냄
- **[[상보 필터(Complementary Filter)|상보 필터]]**: 칼만 필터처럼 확률 모델을 쓰지 않고, 느린 변화에 강한 센서(예: 가속도계)의 저주파 성분과 빠른 변화에 강한 센서(예: 자이로)의 고주파 성분을 단순 가중합으로 결합 — 계산량이 훨씬 적어 저사양 로봇 MCU에도 적합하지만, 정상상태 정확도는 칼만 필터보다 다소 낮음

<aside>예시 — 로봇의 위치 추정</aside>

**예시**: 이동 로봇이 GPS(옥외 위치, 실내에서는 부정확), IMU(가속도·각속도, 누적 오차 발생), 그리고 IoT 비콘(실내 근접 위치 신호)의 데이터를 함께 융합하면, 어느 한 센서만으로는 얻기 어려운 안정적인 실내외 연속 위치 추정이 가능해진다.

---

<aside>핵심 정리</aside>

- 센서 데이터 융합은 여러 센서·IoT 디바이스의 데이터를 결합해 정확도와 신뢰성을 높이는 기법이다
- 목적은 "센서 개수를 줄이는 것"이 아니라 "여러 센서를 함께 활용해 약점을 서로 보완하는 것"
- 단순 평균부터 칼만 필터 기반 확률적 결합까지 다양한 수준의 방식이 있다
- 상보 필터는 확률 모델 없이 저주파·고주파 성분을 나눠 가중합하는 경량 대안으로, 계산량과 정확도 사이에서 칼만 필터와 다른 트레이드오프를 가진다
