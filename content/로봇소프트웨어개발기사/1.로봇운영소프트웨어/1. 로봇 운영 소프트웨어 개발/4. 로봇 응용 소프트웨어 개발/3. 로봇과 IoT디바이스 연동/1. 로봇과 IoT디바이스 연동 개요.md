# Summary

로봇은 혼자 동작하기보다 주변의 다양한 **IoT 디바이스**(저전력 센서, 원격지 게이트웨이, 스마트홈 기기 등)와 데이터를 주고받으며 협업하는 경우가 많다. 이 세세항목은 [[1. 로봇과 ICT 융합 개요|로봇과 ICT 융합]]이 다룬 클라우드·엣지 같은 상위 인프라와 달리, **로봇과 개별 디바이스 사이의 구체적인 통신 프로토콜과 데이터 처리 방식**에 초점을 맞춘다.

# Notes

<aside>로봇과 IoT디바이스 연동이란</aside>

로봇이 배터리·연산력이 제한된 다수의 소형 IoT 디바이스(온습도 센서, 도어락, 조명, 웨어러블 등)와 네트워크로 연결되어 정보를 주고받고, 그 정보를 바탕으로 판단·동작하는 것을 말한다. 디바이스 하나하나가 저전력·저대역폭 제약을 가지므로, 클라우드/엣지 컴퓨팅과는 다른 **경량 통신 프로토콜과 데이터 신뢰성 확보 기법**이 필요하다.

<aside>세부항목 안에서의 위치</aside>

| 세세항목 | 초점 |
|---|---|
| 1. 로봇 컨텐츠 개발 | 멀티미디어·로봇 동작이 결합된 콘텐츠 자체의 기획·구현 |
| 2. 로봇과 ICT 융합 | 로봇과 클라우드·엣지·디지털 트윈 같은 상위 ICT 인프라의 연계 |
| 3. 로봇과 IoT디바이스 연동(이 세세항목) | 로봇과 개별 IoT 디바이스 간의 구체적 통신 프로토콜·데이터 처리 |

<aside>이미 다룬 프로토콜과의 관계</aside>

MQTT의 구조·QoS 레벨과 WebSocket은 [[2. MQTT·WebSocket과 실시간 모니터링 통신]]에서 이미 상세히 다뤘으므로 이 세세항목에서는 반복하지 않는다. 이 세세항목은 그 위에서, IoT 디바이스 특유의 **더 경량화된 프로토콜(CoAP)**, **더 넓은 범위·저전력 무선(LoRaWAN)**, **다수 센서 데이터의 결합(센서 데이터 융합)**, **불안정한 네트워크에서의 동기화·신뢰성 확보**를 새로 다룬다.

<aside>이 세세항목의 구성</aside>

이후 페이지들은 다음을 다룬다: [[2. CoAP와 경량 IoT 프로토콜|CoAP]](초저전력 디바이스를 위한 경량 프로토콜), [[3. LoRaWAN과 저전력 광역 통신|LoRaWAN]](넓은 범위를 저전력으로 커버하는 무선), [[4. 센서 데이터 융합(Sensor Fusion)|센서 데이터 융합]](여러 센서 정보를 결합해 신뢰도를 높이는 방법), [[5. IoT 디바이스 데이터 동기화와 신뢰성 확보|데이터 동기화와 신뢰성]](불안정한 네트워크에서도 일관된 데이터를 유지하는 방법).

<aside>예시 — 로봇과 IoT 센서망의 협업</aside>

**예시**: 실내 배송 로봇이 여러 층에 설치된 저전력 온습도 센서(CoAP로 통신)와 화재 감지 센서 값을 함께 참고해 이동 경로를 조정하고, 일부 구간에서는 LoRaWAN으로 연결된 원거리 야외 센서 데이터까지 결합(센서 데이터 융합)해 상황을 판단한다.

<aside>핵심 정리</aside>

- 이 세세항목은 로봇과 개별 IoT 디바이스 간의 경량 통신 프로토콜·데이터 처리에 초점을 맞춘다
