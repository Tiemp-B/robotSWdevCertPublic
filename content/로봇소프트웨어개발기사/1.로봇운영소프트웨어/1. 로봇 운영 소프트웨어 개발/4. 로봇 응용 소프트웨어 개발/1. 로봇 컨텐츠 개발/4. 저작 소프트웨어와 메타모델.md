# Summary

콘텐츠 설계서가 완성되면 이를 실제로 구현할 저작 소프트웨어와, 로봇 동작·멀티미디어를 시나리오대로 실행하기 위한 **[[메타모델(Meta-model)|메타모델]]**이 필요하다. 최근에는 **[[Unity3D]]** 같은 게임 엔진을 저작 도구로 활용하기도 하며, 사용자의 몰입도를 높이기 위해 **[[게임화(Gamification)|게임화]]** 기법을 적용하기도 한다.

# Notes

<aside>메타모델(Meta-model) 개념</aside>

멀티미디어와 로봇 동작을 시나리오 기반으로 실행하기 위한 절차서다. [[3. 작업절차서와 콘텐츠 설계서|콘텐츠 설계서]]의 내용을 실제로 실행 가능한 형태로 옮긴 것이라 이해하면 된다.

<aside>로봇 콘텐츠 저작 소프트웨어</aside>

| 저작 소프트웨어 | 특징 |
|---|---|
| OPRoS | 컴포넌트 기반 오픈소스 플랫폼 |
| 로보이드 스튜디오 | GUI 기반, 타임라인 모션 에디터와 콘텐츠 컴포저 제공, 멀티미디어-모션 동기화 기본 제공 |
| 스크립트 기반 저작 | GUI 저작 도구가 없을 때 텍스트로 메타모델 파일을 직접 작성 |

<aside>메타모델 작성과 모션-멀티미디어 동기화</aside>

타임라인 기반 표(시간·모션·음성 재생·배경음악/효과·조명 등)로 씬 전체의 흐름을 정리한다. 음성·효과음 파일의 재생 길이를 측정해 모션의 진행 시간과 맞추는 것이 동기화의 핵심이다.

<aside>콘텐츠를 실행하는 휴머노이드 로봇 플랫폼</aside>

메타모델로 작성한 콘텐츠는 결국 실제(또는 가상) 로봇 위에서 실행된다. NCS 학습모듈은 실행 대상 로봇을 체급별로 분류한다.

| 분류 | 예시 |
|---|---|
| 성인급 휴머노이드 | HONDA ASIMO, AIST HRP, KAIST HUBO, 로보티즈 똘망(THOR-MANG), Boston Dynamics ATLAS, IIT iCub |
| 어린이급 휴머노이드 | 알데바란 NAO, 로보티즈 ROBOTIS-OP |
| 바퀴형 상체 휴머노이드 | 소프트뱅크 PEPPER, 로보케어 실벗(SILBOT) |

몸 전체가 다리로 걷는 성인급·어린이급과 달리, 바퀴형 상체 휴머노이드는 하체가 바퀴 구동부라 보행 모션 대신 이동 모션을 다뤄야 한다는 차이가 있다.

<aside>Unity3D — 현대적 저작 도구</aside>

로봇 콘텐츠, 특히 교육·엔터테인먼트용 콘텐츠는 3D 그래픽 렌더링·물리 시뮬레이션·사용자 입력 처리가 필요한 경우가 많아, Unity3D 같은 게임 엔진을 저작 도구로 활용하는 경우가 흔하다.

<aside>Unity3D의 Update()와 FixedUpdate()</aside>

- **Update()**: 매 프레임마다 호출되며, 호출 간격이 프레임 속도(프레임레이트)에 따라 달라진다 — 그래픽 갱신, 사용자 입력 처리에 적합
- **FixedUpdate()**: 고정된 시간 간격으로 호출되며, 프레임레이트와 무관하게 일정하다 — 중력·충돌 같은 물리 연산처럼 시간 간격이 일정해야 하는 계산에 적합



<aside>게임화(Gamification) 기법의 목적</aside>

포인트·보상·레벨·랭킹 같은 게임 요소를 콘텐츠에 적용해 **사용자의 몰입도와 참여 동기를 높이는 것**이 목적이다. 특히 교육용 로봇 콘텐츠에서는 단순한 재미 제공이 아니라 학습 지속성과 참여도를 높이는 수단으로 활용된다. "게임화의 목적은 콘텐츠의 개발 난이도를 낮추는 것이다"는 옳지 않다 — 게임화는 사용자 경험을 높이는 기법이지 개발 편의를 위한 기법이 아니다.

<aside>예시 — 로봇 드라마 콘텐츠 저작</aside>

**예시**: 로보이드 스튜디오로 로봇 드라마의 메타모델을 작성해 타임라인 상에서 모션과 음성 재생 시점을 맞추고, 같은 콘텐츠를 교육용으로 각색한다면 미션을 완료할 때마다 포인트를 지급하는 게임화 요소를 추가해 학습 동기를 높인다.

---

<aside>핵심 정리</aside>

- 메타모델은 콘텐츠 설계서를 실행 가능한 형태로 옮긴 것이며, OPRoS·로보이드 스튜디오·스크립트 기반 등으로 저작한다
- 실행 대상 로봇은 성인급(ASIMO·HUBO·ATLAS 등)·어린이급(NAO·ROBOTIS-OP)·바퀴형 상체(PEPPER·실벗)로 나뉘며, 바퀴형은 보행 대신 이동 모션을 다룬다
- Unity3D의 **Update()는 프레임마다(가변 간격), FixedUpdate()는 고정 간격으로 호출**되며, 물리 연산은 FixedUpdate()에서 처리해야 한다
- 게임화의 목적은 **사용자의 몰입도·참여 동기 향상**이며, 개발 난이도 완화가 아니다
