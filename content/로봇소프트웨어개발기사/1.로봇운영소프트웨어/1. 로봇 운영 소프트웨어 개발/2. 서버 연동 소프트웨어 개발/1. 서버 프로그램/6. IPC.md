# Summary

**[[IPC(Inter-Process Communication)|프로세스 간 통신(IPC)]]**은 같은 기기 내에서 서로 독립된 프로세스들이 데이터를 주고받기 위한 메커니즘이다. 파이프, 공유 메모리, 소켓, [[메시지 큐(Message Queue)|메시지 큐]] 등이 있으며, 이 중 메시지 큐는 발신자와 수신자가 동시에 실행 중이지 않아도 동작하는 비동기적 디커플링에 강점이 있다. 네트워크를 통한 기기 간 메시징(MQTT 등)과는 통신 범위가 다르다는 점에 유의한다.

# Notes

<aside>IPC 개념과 필요성</aside>

동일 기기 내에서 메모리 공간이 분리된 서로 다른 프로세스가 데이터를 주고받는 방법을 통칭한다. [[2. 동시성 처리 모델]]에서 다룬 프로세스 기반 모델처럼 작업을 여러 프로세스로 나눌 때, 이들 사이의 협업을 위해 IPC가 필요하다.

<aside>IPC의 주요 방식</aside>

| 방식 | 특징 |
|---|---|
| 파이프(Pipe) | 관련 프로세스(부모-자식) 간 단방향/양방향 통신, FIFO 구조 |
| 공유 메모리(Shared Memory) | 여러 프로세스가 같은 메모리 영역에 접근 — 가장 빠르지만 동기화를 직접 구현해야 함 |
| 소켓(Socket) | 같은 기기 내(유닉스 도메인 소켓)와 네트워크 모두에 사용 가능 — 유연하나 오버헤드 존재 |
| [[메시지 큐(Message Queue)\|메시지 큐]] | 구조화된 메시지를 큐에 넣고 비동기로 꺼내가는 방식 |

<aside>메시지 큐의 특징</aside>

- 발신자와 수신자가 **동시에 실행되고 있지 않아도** 동작한다 — 발신자가 메시지를 큐에 넣어두면 수신자는 자신의 타이밍에 꺼내갈 수 있다(비동기/디커플링)
- 메시지에 우선순위를 부여할 수 있고, 여러 프로세스가 하나의 큐를 공유해 작업을 나눠 가져갈 수 있다(작업 분배)

"메시지 큐는 발신자와 수신자가 반드시 동시에 실행되고 있어야 동작한다"는 틀렸다 — 오히려 **동시 실행이 불필요하다는 점**이 메시지 큐가 파이프·공유 메모리와 구별되는 핵심 장점이다.

<aside>메시지 큐 vs 공유 메모리</aside>

| 항목 | 공유 메모리 | 메시지 큐 |
|---|---|---|
| 속도 | 빠름(직접 메모리 접근) | 상대적으로 느림(큐를 거침) |
| 동기화 | 개발자가 락 등으로 직접 구현 | 큐 자체가 동기화 보장 |
| 결합도 | 강한 결합(같은 메모리 구조 공유) | 느슨한 결합(메시지 형식만 맞으면 됨) |

<aside>IPC와 네트워크 메시징의 구분</aside>

IPC(파이프·공유메모리·소켓·메시지큐)는 기본적으로 **동일 기기 내** 프로세스 간 통신을 가리키며, [[2. MQTT·WebSocket과 실시간 모니터링 통신]]에서 다룬 MQTT·WebSocket은 **네트워크를 통한 기기 간** 통신이다. 다만 소켓은 유닉스 도메인 소켓(로컬)과 TCP/IP 소켓(네트워크) 모두에 쓰이므로, 문맥에 따라 IPC로도 네트워크 통신으로도 분류될 수 있다는 점은 예외로 기억해 둔다.

<aside>예시 — 로봇 제어 프로세스와 모니터링 프로세스 간 IPC</aside>

**예시**: 하나의 로봇 컨트롤러 안에서 실시간 제어를 담당하는 프로세스와 그 상태를 외부로 전송하는 모니터링 프로세스가 별도로 동작한다고 하자. 제어 프로세스는 계산한 최신 상태값을 메시지 큐에 넣어두기만 하면 되고, 모니터링 프로세스는 자신의 타이밍에 맞춰 큐에서 값을 꺼내 MQTT로 발행한다 — **IPC(메시지 큐)로 프로세스 간 데이터를 넘기고, 그 뒤를 네트워크 통신(MQTT)이 잇는 구조**가 실무에서 흔히 쓰인다.

---

<aside>핵심 정리</aside>

- IPC는 파이프·공유메모리·소켓·메시지큐로 구현되며, **동일 기기 내** 프로세스 간 통신
- 메시지 큐의 핵심은 **발신자·수신자가 동시에 실행되지 않아도 되는 비동기적 디커플링**
- 공유 메모리는 빠르지만 동기화 부담 큼, 메시지 큐는 느리지만 동기화·결합도 면에서 안전
- IPC(기기 내)와 MQTT 같은 네트워크 메시징(기기 간)은 범위가 다름
