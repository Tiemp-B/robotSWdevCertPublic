# Summary

로봇 원격제어 시스템의 **[[HMI(Human-Machine Interface)|HMI]]** 설계는 운영자가 직관적으로 조작하고 로봇의 상태를 실시간으로 파악하며, 특히 위급 상황에서 즉시 대응할 수 있도록 이뤄져야 한다. **비상정지 접근성, 직관적 조작, 실시간 상태 표시, 사용자 실수 최소화**가 핵심 설계 원칙이다.

# Notes

<aside>비상정지(E-stop) 접근성</aside>

**[[E-stop(비상정지)|비상정지]]** 버튼은 화면에서 가장 눈에 띄고 즉시 누를 수 있는 위치에, 다른 조작 버튼과 명확히 구분되는 형태(예: 큰 빨간 버튼, 항상 고정된 위치)로 배치해야 한다. 로봇 제어기 자체의 물리적 E-stop과 마찬가지로, HMI 화면 안에서도 비상정지는 최우선 접근성을 가져야 한다.

<aside>직관적 조작(Intuitive Operation)</aside>

운영자가 별도의 매뉴얼 없이도 자연스럽게 조작할 수 있도록 아이콘과 배치를 일관되게 구성하고, 자주 쓰는 기능을 접근하기 쉬운 위치에 둔다.

<aside>실시간 상태 표시</aside>

로봇의 현재 상태(위치, 배터리, 에러 등)를 지연 없이 화면에 반영해야, 운영자가 실제 상태와 어긋난 정보를 보고 잘못된 판단을 내리는 일을 막을 수 있다 — [[4. 데이터 시각화와 알람(HMI)]]에서 다룬 게이지·트렌드그래프·알람 설계 원칙이 여기에도 그대로 적용된다.

<aside>사용자 실수 최소화</aside>

되돌릴 수 없거나 위험한 명령(예: 전원 차단)은 곧바로 실행되지 않고 확인 절차(2단계 확인, Confirm 팝업 등)를 거치게 하며, 자주 혼동될 수 있는 인접 버튼끼리는 충분한 간격과 시각적 구분을 둔다.

<aside>HMI 설계 원칙으로 부적절한 사례</aside>

"화면을 단순화하기 위해 비상정지 버튼을 다른 메뉴 안에 숨겨 둔다"거나 "조작 속도를 높이기 위해 위험한 명령도 확인 절차 없이 즉시 실행되게 한다"는 서술은 HMI 설계 원칙에 부합하지 않는다 — 비상정지는 항상 최우선 접근성을 가져야 하고, 위험한 명령일수록 확인 절차가 필요하다.

<aside>예시 — 로봇 원격제어 HMI 화면 구성</aside>

**예시**: 화면 상단 고정 위치에 대형 비상정지 버튼을 배치하고, 중앙에는 실시간 위치·배터리 게이지를 표시하며, "전원 차단"처럼 위험한 버튼은 클릭 시 재확인 팝업이 뜨도록 구성하는 것이 전형적인 설계다.

---

<aside>핵심 정리</aside>

- HMI 설계의 핵심 원칙은 **비상정지 최우선 접근성 · 직관적 조작 · 실시간 상태 표시 · 사용자 실수 최소화**다
- 비상정지를 메뉴 안에 숨기거나, 위험한 명령을 확인 절차 없이 즉시 실행되게 하는 것은 원칙에 어긋난다
- 실시간 상태 표시는 "로봇 모니터링 프로그램"의 HMI 시각화 원칙과 동일한 기반을 공유한다
