# Summary

로봇 원격제어 **[[HMI(Human-Machine Interface)|HMI]]** 설계는 국제표준(ISO 9241-110의 상호작용 원칙, ISO 13850의 비상정지 설계원칙)에 근거해, 운영자가 직관적으로 조작하면서도 위급 상황에는 즉시 대응할 수 있도록 이뤄져야 한다. **비상정지 접근성, 직관적 조작, 실시간 상태 표시, 사용자 실수 최소화**가 핵심이다.

# Notes

<aside>비상정지(E-stop) 접근성 — ISO 13850</aside>

국제표준 **ISO 13850**(비상정지 기능의 설계원칙)은 비상정지가 조작자의 손이 항상 닿는 위치에, 각 고정 조작 스테이션마다 설치되어야 한다고 규정한다. **[[E-stop(비상정지)|비상정지]]**는 단일 동작으로 즉시 활성화되어야 하며, **활성화 후 자동으로 재시작되지 않고 위험 요인 해소를 확인한 뒤 수동으로 리셋**해야만 정상 운전이 재개된다. HMI 화면 안의 비상정지 버튼도 이 원칙에 따라 가장 눈에 띄고 즉시 누를 수 있는, 다른 버튼과 명확히 구분되는 위치에 고정 배치해야 한다.

중요한 점은 비상정지가 안전장치(가드 등)나 본질적으로 안전한 설계를 **대체하는 수단이 아니라 보완적 보호수단**이라는 것이다.

<aside>직관적 조작 — ISO 9241-110 상호작용 원칙</aside>

ISO 9241-110(2020)은 사용자 친화적 대화형 시스템 설계를 위한 7가지 상호작용 원칙(작업 적합성·자기 기술성·사용자 기대 부합·학습 용이성·**제어 가능성**·**사용 오류 강건성**·사용자 참여)을 제시한다. 이 중 **제어 가능성**(사용자가 진행 과정을 통제할 수 있어야 함)과 **오류 강건성**(실수해도 심각한 결과로 이어지지 않아야 함)이 원격제어 HMI 설계에서 특히 중요하다. 다만 이 표준은 일반 대화형 시스템 원칙이며 안전 필수 시스템의 구체적 요구사항까지 다루지는 않으므로, 로봇 HMI에는 ISO 9241-110 위에 ISO 13850 같은 산업안전표준을 추가로 적용해야 한다.

<aside>실시간 상태 표시</aside>

로봇의 현재 상태(위치·배터리·에러 등)를 지연 없이 반영해야, 운영자가 실제 상태와 어긋난 정보로 잘못된 판단을 내리는 일을 막을 수 있다 — [[4. 데이터 시각화와 알람(HMI)]]에서 다룬 게이지·트렌드그래프·알람 설계 원칙이 여기에도 그대로 적용된다.

<aside>사용자 실수 최소화(오류 강건성)</aside>

되돌릴 수 없거나 위험한 명령(전원 차단 등)은 곧바로 실행되지 않고 확인 절차(2단계 확인, Confirm 팝업 등)를 거치게 하며, 혼동되기 쉬운 인접 버튼끼리는 충분한 간격과 시각적 구분을 둔다. 이는 ISO 9241-110의 오류 강건성 원칙을 구체적으로 구현한 것이다.

<aside>HMI 설계 원칙으로 부적절한 사례</aside>

"화면을 단순화하기 위해 비상정지 버튼을 메뉴 안에 숨긴다"거나 "조작 속도를 높이기 위해 위험한 명령도 확인 절차 없이 즉시 실행되게 한다"는 서술은 원칙에 어긋난다 — 비상정지는 항상 최우선 접근성을, 위험한 명령일수록 더 엄격한 확인 절차를 가져야 한다.

<aside>예시 — 로봇 원격제어 HMI 화면 구성</aside>

**예시**: 화면 상단 고정 위치에 대형 비상정지 버튼을 배치하고, 중앙에는 실시간 위치·배터리 게이지를 표시하며, "전원 차단"처럼 위험한 버튼은 클릭 시 재확인 팝업이 뜨도록 구성하는 것이 전형적인 설계다.

---

<aside>핵심 정리</aside>

- HMI 설계의 핵심은 **비상정지 최우선 접근성(ISO 13850) · 직관적 조작과 오류 강건성(ISO 9241-110) · 실시간 상태 표시 · 사용자 실수 최소화**다
- 비상정지는 자동 재시작되지 않고 수동 리셋이 필요하며, 다른 안전장치를 대체하는 수단이 아니라 보완적 수단이다
- 비상정지를 숨기거나 위험 명령을 확인 없이 즉시 실행되게 하는 것은 원칙에 어긋난다
