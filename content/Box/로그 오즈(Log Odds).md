# Summary

로그 오즈(Log Odds)는 어떤 셀(격자)이 점유되어 있을 확률을 **오즈(odds)의 로그값**으로 표현한 것으로, 점유격자지도에서 여러 센서 측정을 반복적으로 반영할 때 곱셈 대신 덧셈만으로 확률을 갱신할 수 있게 해준다.

# Notes

<aside>로그 오즈를 쓰는 이유</aside>

$$L = \log\left(\frac{p}{1-p}\right)$$

- 점유격자지도는 각 격자 셀의 점유 확률을 센서 측정이 들어올 때마다 갱신해야 하는데, 확률을 직접 곱셈으로 갱신하면 계산이 복잡하고 수치적으로 불안정해질 수 있음
- 확률을 로그 오즈로 변환하면, 새로운 센서 측정을 반영할 때 **단순히 값을 더하기만 하면** 되어 계산이 간단해지고 수치적으로도 안정적임
- 필요할 때 로그 오즈 값을 다시 확률로 변환($p = 1/(1+e^{-L})$)해 사용

"점유격자지도에서 로그 오즈를 사용하는 이유는 확률값을 사람이 더 직관적으로 읽을 수 있게 하기 위해서다"라는 서술은 오답이다 — 로그 오즈를 쓰는 핵심 이유는 직관적 가독성이 아니라, **여러 센서 측정을 반복 반영할 때 곱셈을 덧셈으로 바꿔 계산을 단순화·안정화**하기 위해서다.

<aside>점유격자지도에서의 활용</aside>

이동로봇이 라이다 등으로 주변을 여러 번 스캔하며 지도를 갱신할 때마다, 각 셀의 로그 오즈 값에 새 측정 결과를 더해나가는 방식으로 점유 확률을 누적 갱신한다.

---

<aside>핵심 정리</aside>

- 로그 오즈는 점유 확률을 오즈의 로그값으로 표현해, 여러 측정을 덧셈만으로 누적 반영할 수 있게 한다
- 가독성이 아니라 계산의 단순화·수치 안정성이 핵심 이유다
