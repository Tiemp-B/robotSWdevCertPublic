# Summary

쿠키는 서버가 클라이언트(브라우저)에 전달해 **클라이언트 측에 저장**해두는 작은 데이터 조각으로, 이후 요청마다 자동으로 함께 전송되어 무상태(stateless)인 HTTP에 상태 정보를 연결하는 역할을 한다.

# Notes

<aside>쿠키의 동작 방식</aside>

- 서버가 응답에 쿠키를 담아 보내면, 브라우저는 그 쿠키를 저장해두고 **같은 서버로의 이후 모든 요청에 자동으로 포함**시켜 전송함
- [[세션(Session)]] ID를 쿠키에 담아 전달하면, 서버는 매 요청마다 그 ID로 어떤 사용자의 세션인지 식별할 수 있음
- 만료 시간, 보안 속성(HttpOnly, Secure 등)을 설정해 쿠키의 유효 기간과 접근 범위를 제어함

<aside>세션과의 관계</aside>

전통적인 세션 기반 인증에서는 쿠키가 세션 ID를 담아 전달하는 역할을 하며, 서버는 그 ID로 [[세션(Session)]] 저장소에서 실제 사용자 상태를 조회한다.

---

<aside>핵심 정리</aside>

- 쿠키는 서버가 클라이언트 측에 저장해두는 작은 데이터로, 이후 요청마다 자동으로 함께 전송된다
