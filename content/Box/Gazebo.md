# Summary

Gazebo는 로봇의 물리적 동작(중력, 충돌, 마찰 등)을 정밀하게 재현하는 **오픈소스 로봇 물리 시뮬레이터**로, 실제 로봇 없이 소프트웨어를 개발·검증할 수 있게 해준다.

# Notes

<aside>Gazebo의 역할</aside>

- 물리 엔진을 통해 로봇과 환경의 충돌, 중력, 마찰, 센서 노이즈 등을 시뮬레이션
- [[ROS(Robot Operating System)]]와 긴밀히 연동되어, 시뮬레이션 상의 가상 로봇에 실제 로봇과 동일한 ROS 노드·토픽 구조로 명령을 보내고 센서 데이터를 받을 수 있음
- 실제 하드웨어 없이도 제어 알고리즘·경로계획을 미리 검증할 수 있어 개발 비용·위험을 줄임

<aside>다른 시뮬레이션·저작 도구와의 관계</aside>

Gazebo가 물리 기반 로봇 시뮬레이션에 특화된 반면, [[Unity3D]]는 범용 게임 엔진으로 시각화·상호작용 콘텐츠 제작에 더 강점이 있다 — 목적(정밀한 물리 검증 vs 콘텐츠·시각화)에 따라 도구를 선택한다.

---

<aside>핵심 정리</aside>

- Gazebo는 물리 법칙을 반영해 로봇 동작을 검증하는 오픈소스 로봇 시뮬레이터이며, ROS와 긴밀히 연동된다
