# Summary

워치독 타이머는 정상 동작 중인 소프트웨어가 **주기적으로 타이머를 리셋(kick)하지 않으면 자동으로 시스템을 재시작**시키는 하드웨어(또는 소프트웨어) 감시 장치로, 소프트웨어가 멈추거나 무한루프에 빠졌을 때 스스로 복구하게 한다.

# Notes

<aside>워치독 타이머의 동작 원리</aside>

- 정상 동작 중인 프로그램은 주기적으로(예: 100ms마다) 워치독 타이머를 리셋(kick)하는 코드를 실행함
- 프로그램이 무한루프나 데드락에 빠져 이 리셋 코드를 더 이상 실행하지 못하면, 타이머가 정해진 시간 안에 리셋되지 않아 **자동으로 시스템 재시작(리셋)을 트리거**함
- 사람이 개입하지 않아도 임베디드 시스템이 오작동에서 스스로 복구하도록 하는 안전장치

"워치독 타이머는 정상 동작 중인 소프트웨어가 타이머를 계속 리셋하면 시스템을 강제로 재시작시키는 장치다"라는 서술은 오답이다 — 워치독 타이머의 핵심은 정반대로 **타이머를 리셋하지 못했을 때(오작동 신호)** 시스템을 재시작시키는 것이며, 정상적으로 리셋되는 동안에는 아무 조치도 취하지 않는다.

<aside>윈도우 워치독(Window Watchdog)</aside>

일반 워치독은 리셋 신호가 너무 늦게 오는 경우만 감지하지만, 윈도우 워치독은 리셋 신호가 정해진 최소 시간보다 **너무 이르게** 오는 경우도 함께 감지해 리셋을 트리거한다. 이를 통해 소프트웨어가 비정상적으로 빠른 루프에 갇힌 상황까지 탐지할 수 있다.

<aside>임베디드 프로그래밍에서의 의미</aside>

로봇 액추에이터 제어기처럼 사람이 계속 지켜볼 수 없는 임베디드 장치에서, 워치독 타이머는 소프트웨어 결함으로 인한 멈춤 상태를 사람 개입 없이 스스로 감지·복구하는 기본적인 안전 설계 요소다.

---

<aside>핵심 정리</aside>

- 워치독 타이머는 정상 소프트웨어가 주기적으로 리셋하지 않으면 자동으로 시스템을 재시작시키는 감시 장치다
- 정상적으로 리셋되는 동안은 재시작을 유발하지 않으며, 리셋이 멈췄을 때가 문제 신호다
- 윈도우 워치독은 너무 늦은 리셋뿐 아니라 너무 이른 리셋도 감지한다는 점에서 일반 워치독과 다르다
