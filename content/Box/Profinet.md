# Summary

Profinet은 표준 이더넷 위에서 동작하는 산업용 실시간 통신 프로토콜로, 실시간성 요구 수준에 따라 **비실시간·실시간·등시성 실시간(IRT) 세 등급의 통신 클래스**를 제공한다.

# Notes

<aside>Profinet의 통신 클래스</aside>

| 클래스 | 실시간성 | 용도 |
|---|---|---|
| TCP/UDP(비실시간) | 낮음 | 설정, 진단, 일반 데이터 |
| RT(실시간) | 중간 | 대부분의 제어 데이터 |
| IRT(등시성 실시간) | 매우 높음(마이크로초 단위) | 다축 모션 제어 동기화 등 |

이렇게 여러 등급을 나눠 제공함으로써, 같은 네트워크 안에서 덜 급한 데이터와 매우 급한 제어 데이터를 함께 효율적으로 다룰 수 있다.

"Profinet은 모든 데이터를 하나의 동일한 실시간 등급으로만 처리하는 단일 등급 프로토콜이다"라는 서술은 오답이다 — Profinet의 핵심은 오히려 **비실시간·실시간·등시성 실시간의 여러 등급을 구분해 제공**하는 것이며, 데이터 성격에 맞는 등급을 선택할 수 있다.

<aside>다른 이더넷 기반 필드버스와의 관계</aside>

Profinet, [[EtherCAT]], [[POWERLINK]]는 모두 표준 이더넷 물리 계층 위에서 실시간성을 확보하려는 산업용 프로토콜이지만, Profinet은 특히 여러 실시간 등급을 유연하게 나눠 제공한다는 점이 특징적이다.

---

<aside>핵심 정리</aside>

- Profinet은 비실시간·실시간·등시성 실시간(IRT) 세 등급을 구분해 제공하는 이더넷 기반 산업용 프로토콜이다
- 모든 데이터를 단일 등급으로만 처리하지 않는다
