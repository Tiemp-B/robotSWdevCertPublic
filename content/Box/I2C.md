# Summary

I2C는 **SDA(데이터)와 SCL(클럭) 단 두 개의 선**만으로 하나의 마스터가 여러 슬레이브 장치와 통신할 수 있는 저속·근거리 시리얼 통신 프로토콜로, 센서·소형 주변장치 연결에 널리 쓰인다.

# Notes

<aside>I2C의 동작 방식</aside>

- 두 개의 신호선(SDA: 데이터, SCL: 클럭)만으로 다중 장치를 연결하는 2-wire 버스 방식
- START 조건(SCL이 High인 상태에서 SDA가 Low로 바뀜)으로 통신을 시작하고, 각 슬레이브는 고유 주소로 구분됨
- 하나의 버스에 여러 슬레이브를 매달 수 있지만, [[SPI]]보다 속도는 느림(대신 배선 수는 훨씬 적음)

"I2C는 마스터-슬레이브 구분 없이 모든 장치가 동등하게 클럭을 생성하는 방식이다"라는 서술은 오답이다 — I2C의 핵심은 오히려 **마스터가 클럭(SCL)을 생성하고 여러 슬레이브가 고유 주소로 응답**하는 구조라는 점이다.

<aside>SPI·UART와의 비교</aside>

I2C(2선, 다중 슬레이브, 중간 속도), [[SPI]](4선, 고속, 별도 슬레이브 선택선 필요), UART(2선, 1:1 비동기 통신)는 모두 근거리 시리얼 통신이지만 배선 수·속도·연결 가능 장치 수에서 트레이드오프가 다르다 — 여러 개의 저속 센서를 최소 배선으로 연결하려면 I2C가 적합하다.

---

<aside>핵심 정리</aside>

- I2C는 SDA·SCL 2선으로 마스터 하나가 여러 슬레이브와 통신하는 시리얼 버스다
- START 조건과 슬레이브 주소로 통신을 구분하며, 모든 장치가 동등한 구조가 아니다
