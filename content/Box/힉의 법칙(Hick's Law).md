# Summary

힉의 법칙은 사용자가 선택해야 할 **선택지의 수가 많아질수록 의사결정에 걸리는 시간이 늘어난다**는 인간공학 법칙으로, UI에서 메뉴·옵션 수를 적절히 제한해야 하는 근거로 쓰인다.

# Notes

<aside>힉의 법칙이 UI 설계에 주는 시사점</aside>

- 한 화면에 너무 많은 선택지(버튼, 메뉴 항목)를 한꺼번에 나열하면, 사용자가 그중 무엇을 골라야 할지 판단하는 데 시간이 오래 걸리고 부담을 느낌
- 선택지를 카테고리로 묶거나 단계별로 나눠 한 번에 보여주는 수를 줄이면, 오히려 전체적인 의사결정 속도가 빨라짐
- 로봇 조작 UI에서 자주 쓰는 기능은 상위 메뉴에, 드물게 쓰는 기능은 하위 메뉴로 나누는 것이 힉의 법칙에 기반한 설계

<aside>밀러의 법칙·피츠의 법칙과의 구분</aside>

[[밀러의 법칙(Miller's Law)]]이 "한 번에 기억할 수 있는 항목 수(약 7±2개)"의 한계를 다룬다면, 힉의 법칙은 "선택지 수와 의사결정 시간의 관계"를 다루고, [[피츠의 법칙(Fitts' Law)]]은 "대상까지의 거리·크기와 도달 시간"을 다뤄, 세 법칙은 서로 다른 UI 설계 측면을 설명한다.

---

<aside>핵심 정리</aside>

- 힉의 법칙은 선택지 수가 많아질수록 의사결정 시간이 늘어난다는 법칙이다
- 선택지를 줄이거나 계층화하면 의사결정 속도를 높일 수 있다는 UI 설계 근거가 된다
