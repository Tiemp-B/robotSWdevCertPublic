# Summary

강화학습은 에이전트가 환경과 상호작용하며 **행동에 대한 보상(reward)을 최대화하는 방향으로 정책을 학습**하는 기계학습 패러다임으로, 정답 레이블 없이 시행착오를 통해 학습한다는 점이 지도학습과 다르다.

# Notes

<aside>강화학습의 핵심 요소</aside>

| 요소 | 의미 |
|---|---|
| 에이전트(Agent) | 학습하고 행동을 결정하는 주체(로봇) |
| 환경(Environment) | 에이전트가 상호작용하는 대상 |
| 상태(State) | 현재 환경의 상황 |
| 행동(Action) | 에이전트가 상태에서 선택할 수 있는 동작 |
| 보상(Reward) | 행동의 결과로 받는 피드백(좋은지 나쁜지) |
| 정책(Policy) | 상태에서 어떤 행동을 선택할지의 전략 |

에이전트는 정답을 직접 배우는 것이 아니라, **누적 보상을 최대화하는 정책**을 시행착오를 통해 스스로 찾아나간다.

<aside>Q-learning과의 관계</aside>

[[Q-learning]]은 강화학습의 핵심 요소(상태·행동·보상)를 이용해 상태-행동 가치(Q값)를 학습하는 구체적인 강화학습 알고리즘 중 하나다.

---

<aside>핵심 정리</aside>

- 강화학습은 에이전트가 환경과 상호작용하며 보상을 최대화하는 정책을 시행착오로 학습하는 패러다임이다
- 정답 레이블이 주어지는 지도학습과 달리, 보상 신호만으로 학습한다
