# Summary

ReLU(Rectified Linear Unit)는 양수 입력은 그대로, 음수 입력은 0으로 출력하는 활성화 함수로, 기울기 소실 문제를 완화해 깊은 신경망 학습을 가능하게 한다.

# Notes

<aside>ReLU의 동작과 효과</aside>

ReLU는 양수 구간에서 미분값이 항상 1이므로 역전파 시 **기울기 소실(Gradient Vanishing) 문제를 완화**한다. 이 덕분에 기존 활성화 함수로는 학습이 어려웠던 더 깊은 신경망도 무리 없이 학습시킬 수 있으며, 학습이 진행될수록 손실 값이 감소하는 속도도 빠르다.

<aside>ReLU의 한계</aside>

음수 구간에서는 기울기가 항상 0이므로 기울기 소실 문제가 완전히 해결된 것은 아니다(dying ReLU). 또한 활성화 함수는 비선형성 추가와 기울기 소실 완화가 목적이며, 과적합을 직접 방지하는 기법으로는 분류되지 않는다 — 과적합 방지는 드롭아웃·L1/L2 정규화·배치 정규화가 담당한다.

"과적합을 방지하는 방법이 아닌 것은?"이라는 문제에서 **활성화 함수(ReLU 등)**가 정답인 경우가 많다.

---

<aside>핵심 정리</aside>

- ReLU는 양수는 그대로, 음수는 0을 출력해 기울기 소실을 완화하는 활성화 함수다
- 음수 구간 기울기가 0이라는 한계가 있으며, 과적합 방지 기법으로는 분류되지 않는다
