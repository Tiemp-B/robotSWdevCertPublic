# Summary

FreeRTOS는 메모리 사용량이 매우 작고 소스가 공개된 **경량 오픈소스 실시간 운영체제(RTOS) 커널**로, 마이크로컨트롤러 기반 임베디드 로봇 제어기에서 널리 쓰인다.

# Notes

<aside>FreeRTOS의 특징</aside>

- 커널 자체가 매우 작아(수 KB 수준) 자원이 제한된 마이크로컨트롤러에도 탑재 가능
- 태스크(작업) 생성, 우선순위 기반 선점형 스케줄링, [[뮤텍스(Mutex)]]·[[세마포어(Semaphore)]]·큐 등 동기화 자료구조를 기본 제공
- [[QNX]]·[[VxWorks]]처럼 상용 RTOS와 달리 무료·오픈소스이면서도 산업 현장에서 실사용 검증이 많이 된 커널

"FreeRTOS는 우선순위 기반 스케줄링을 지원하지 않고 태스크를 생성된 순서대로만 실행하는 단순 루프 구조다"라는 서술은 오답이다 — FreeRTOS의 핵심은 오히려 **우선순위 기반 선점형 스케줄링**을 지원해, 더 중요한 태스크가 즉시 CPU를 차지할 수 있다는 점이다.

<aside>다른 RTOS와의 관계</aside>

FreeRTOS, [[RTOS]](일반 개념), [[QNX]], [[VxWorks]], [[RT-Linux]], [[Xenomai]], [[PREEMPT_RT]]는 모두 "정해진 시간 안에 응답을 보장한다"는 실시간성 목표는 같지만, 라이선스(오픈소스/상용)와 구현 방식(마이크로커널/리눅스 패치)이 다르다.

---

<aside>핵심 정리</aside>

- FreeRTOS는 경량 오픈소스 RTOS 커널로, 우선순위 기반 선점형 스케줄링과 동기화 자료구조를 제공한다
- 태스크를 생성 순서대로만 실행하는 단순 루프가 아니다
