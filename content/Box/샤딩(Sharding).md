# Summary

샤딩은 하나의 큰 데이터베이스를 **여러 개의 작은 조각(샤드)으로 나눠 여러 서버에 분산 저장**하는 기법으로, 데이터 양이 한 서버의 한계를 넘어설 때 수평 확장을 가능하게 한다.

# Notes

<aside>샤딩의 동작 방식</aside>

- 특정 기준(예: 사용자 ID, 로봇 ID 범위 등)에 따라 데이터를 여러 샤드로 나눠, 각 샤드를 서로 다른 서버에 저장
- 하나의 서버 용량으로는 감당할 수 없는 대용량 데이터를 여러 서버가 나눠 처리하게 되어 **전체 저장·처리 용량을 확장**할 수 있음
- [[로드밸런싱(Load Balancing)]]이 요청(트래픽)을 분산시키는 것이라면, 샤딩은 데이터 자체를 분산 저장한다는 차이가 있음

<aside>데이터 마이닝에서의 활용</aside>

로봇에서 수집되는 방대한 로그 데이터를 하나의 DB 서버로 감당할 수 없을 때, 샤딩으로 여러 서버에 나눠 저장한 뒤 그 위에서 [[데이터 마이닝(Data Mining)]]을 수행하는 식으로 대용량 데이터를 처리한다.

---

<aside>핵심 정리</aside>

- 샤딩은 하나의 데이터베이스를 여러 조각으로 나눠 여러 서버에 분산 저장하는 기법이다
- 하나의 서버 안에서 압축하는 것이 아니라, 여러 서버로 데이터를 분산시키는 것이 핵심이다
