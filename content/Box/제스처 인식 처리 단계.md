# Summary

제스처 인식은 입력 방식(카메라·깊이센서·근육센서 등)에 관계없이 **데이터 수집 → 전처리 → 특징 추출 → 분류(인식)**의 4단계 골격을 공통으로 따른다.

# Notes

<aside>4단계 처리 파이프라인</aside>

| 단계 | 내용 |
|---|---|
| ① 데이터 수집 | 카메라·깊이센서·근육센서 등으로 동작 데이터 획득 |
| ② 전처리 | 노이즈 제거, 관심 영역(손 등) 분할·정규화 |
| ③ 특징 추출 | 정제된 데이터에서 인식에 필요한 특징 추출 |
| ④ 분류(인식) | 추출된 특징을 바탕으로 제스처 종류를 인식 |

접촉식(마이오 등)·비접촉식(키넥트·립모션 등) 등 입력 장치의 종류와 무관하게 이 4단계 골격은 공통으로 적용되며, 세부 구현만 입력 방식에 따라 달라진다.

---

<aside>핵심 정리</aside>

- 제스처 인식은 데이터수집→전처리→특징추출→분류의 4단계로 처리된다
- 입력 장치(접촉식/비접촉식) 종류와 무관하게 이 골격은 공통이다
