# Summary

Elastic Force(탄성력) 알고리즘은 로봇이 이동할 경로를 **고무줄처럼 탄성체로 모델링**해, 장애물에서는 밀어내는 힘을, 경로 진행 방향으로는 당기는 힘을 받도록 하여 실시간으로 경로를 국소적으로 조정하는 지역 경로계획 기법이다.

# Notes

<aside>Elastic Force의 동작 원리</aside>

- 경로를 여러 개의 점(노드)이 연결된 탄성 밴드로 표현
- 각 노드는 인접 노드와의 인장력(경로를 팽팽하게 유지하려는 힘)과, 주변 장애물이 밀어내는 척력을 동시에 받음
- 두 힘의 균형점을 반복 계산하면서 경로가 장애물을 피해가는 형태로 국소적으로 변형됨

"Elastic Force 알고리즘은 장애물과 무관하게 경로의 인장력만으로 최단 경로를 계산하는 전역 경로계획 기법이다"라는 서술은 오답이다 — Elastic Force의 핵심은 오히려 **장애물의 척력과 경로의 인장력을 함께 고려해 국소적으로 경로를 실시간 조정**하는 지역(local) 경로계획 기법이라는 점이다.

<aside>가상센서 알고리즘과의 관계</aside>

Elastic Force는 흔히 [[가상센서 알고리즘(Virtual Sensor Algorithm)]]과 함께 쓰여, 실제 센서로 감지하기 어려운 영역까지 가상의 장애물 정보를 보완해 척력 계산의 정확도를 높인다 — 두 기법은 같은 세세항목에서 짝을 이뤄 다뤄진다.

---

<aside>핵심 정리</aside>

- Elastic Force 알고리즘은 경로를 탄성 밴드로 모델링해, 장애물 척력과 경로 인장력의 균형으로 경로를 국소 조정하는 지역 경로계획 기법이다
- 전역 최단 경로 계산이 아니라 실시간 국소 조정에 초점이 있다
