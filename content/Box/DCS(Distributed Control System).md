# Summary

DCS(분산 제어 시스템)는 하나의 중앙 컴퓨터가 모든 제어를 담당하는 대신, **공정의 각 영역마다 독립된 제어기를 분산 배치**해 서로 통신하며 전체 공정을 제어하는 산업 자동화 구조다.

# Notes

<aside>DCS의 분산 구조</aside>

- 대규모 공정(화학 플랜트 등)을 여러 구역으로 나누고, 구역마다 별도의 제어기를 두어 해당 구역을 직접 제어
- 각 제어기는 상위 감시 시스템과 통신하지만, **개별 제어 루프는 자신의 제어기 안에서 독립적으로 완결**되어 있어 한 제어기 장애가 전체 공정을 마비시키지 않음
- 이 점이 하나의 중앙 컴퓨터가 모든 것을 제어하는 집중형 구조와의 핵심 차이

"DCS는 하나의 중앙 컴퓨터가 모든 공정 구역의 제어 루프를 직접 계산하는 집중형 구조다"라는 서술은 오답이다 — DCS의 핵심은 오히려 **제어 기능 자체를 여러 지역 제어기로 분산**시키는 것이며, 중앙 시스템은 감시·조정 역할에 가깝다.

<aside>SCADA와의 차이</aside>

[[SCADA]]는 넓은 지역에 흩어진 설비를 원격으로 감시·수집하는 데 초점을 둔 반면, DCS는 하나의 플랜트 내에서 제어 기능 자체를 분산 배치하는 데 초점을 둔다 — 실제로는 두 개념이 결합된 시스템도 많다.

---

<aside>핵심 정리</aside>

- DCS는 제어 기능을 여러 지역 제어기로 분산 배치하는 산업 자동화 구조다
- 하나의 제어기 장애가 전체 공정을 마비시키지 않는다는 것이 집중형 구조와의 핵심 차이다
