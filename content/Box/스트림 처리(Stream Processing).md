# Summary

스트림 처리는 데이터를 모아두지 않고 **발생하는 즉시(또는 매우 작은 단위로) 실시간으로 처리**하는 방식으로, 모았다가 한꺼번에 처리하는 [[배치 처리(Batch Processing)]]보다 지연시간이 훨씬 짧다.

# Notes

<aside>스트림 처리의 특징</aside>

- 데이터가 끊임없이 흘러 들어오는 것을 전제로, 각 데이터(또는 작은 윈도우)가 도착하는 즉시 처리·집계·판단을 수행
- 로봇의 이상 상태를 즉시 감지해 알람을 울려야 하는 것처럼, **지연이 곧 위험이나 손실로 이어지는 상황**에 적합
- [[윈도우 연산(Windowing)]]으로 최근 일정 구간의 데이터만 모아 통계를 계산하는 방식이 스트림 처리에서 흔히 쓰임

<aside>윈도우 연산과의 관계</aside>

스트림 데이터는 끝없이 계속 들어오므로, 통계를 계산하려면 [[윈도우 연산(Windowing)]]으로 "최근 1분간"처럼 구간을 잘라 그 안에서만 계산하는 방식이 일반적으로 함께 쓰인다.

---

<aside>핵심 정리</aside>

- 스트림 처리는 데이터를 발생 즉시 실시간으로 처리하는 방식이다
- 데이터를 모았다가 한꺼번에 처리하는 배치 처리와 대비되며, 지연이 훨씬 짧다
