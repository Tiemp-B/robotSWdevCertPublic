# Summary

TCP/IP는 **연결 지향·순서 보장·재전송**을 통해 신뢰성을 최우선으로 확보하는 전송 계층 기반 기술로, [[UDP]]와 함께 인터넷·로봇 네트워크 통신의 근간을 이룬다.

# Notes

<aside>TCP/IP가 신뢰성을 확보하는 방식</aside>

- 통신 전 연결을 먼저 수립(3-way handshake)하고, 각 패킷에 순서 번호를 부여해 도착 순서가 뒤바뀌어도 재정렬
- 패킷이 유실되면 확인 응답(ACK)이 오지 않은 것을 감지해 **자동으로 재전송**
- 이런 신뢰성 확보 절차(연결 수립, 순서 재정렬, 재전송 대기) 자체가 지연시간과 지터를 늘리는 대가를 치름

"TCP/IP는 UDP보다 항상 지연시간이 짧고 실시간성이 뛰어나다"는 서술은 오답이다 — TCP/IP는 오히려 **신뢰성을 우선한 대가로 UDP보다 지연시간·지터가 커지는** 경향이 있으며, 신뢰성과 실시간성은 트레이드오프 관계다.

<aside>UDP와의 비교, 로봇 통신에서의 선택</aside>

로봇 제어 명령처럼 유실되면 안 되는 데이터는 TCP/IP(또는 TCP 기반 [[MQTT]])로, 카메라 영상처럼 약간의 유실보다 지연이 더 치명적인 데이터는 [[UDP]] 기반([[WebRTC]] 등)으로 전송하는 식으로 데이터 성격에 맞게 선택한다.

---

<aside>핵심 정리</aside>

- TCP/IP는 연결 지향·순서 보장·재전송으로 신뢰성을 최우선으로 확보하는 전송 기술이다
- 신뢰성 확보 절차 때문에 UDP보다 지연시간·지터가 커질 수 있다
