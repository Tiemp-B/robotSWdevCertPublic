# Summary

엣지 컴퓨팅은 데이터를 클라우드(중앙 서버)까지 보내지 않고 **로봇·현장 장치와 가까운 곳(엣지)에서 직접 연산·처리**하는 방식으로, 클라우드로 데이터를 왕복시키는 지연을 줄이는 것이 핵심 목표다.

# Notes

<aside>엣지 컴퓨팅이 필요한 이유</aside>

- 클라우드 컴퓨팅은 강력한 연산 자원을 제공하지만, 데이터를 멀리 떨어진 클라우드 서버까지 보내고 결과를 받아오는 데 [[네트워크 지연(Latency)]]이 발생함
- 로봇의 즉각적인 반응이 필요한 연산(장애물 회피 등)은 이 지연이 치명적일 수 있어, **로봇 근처(엣지)에서 바로 처리**해 지연을 최소화함
- 모든 연산을 엣지에서 처리하는 것이 아니라, 즉각성이 중요한 연산은 엣지에서, 대용량 학습·분석처럼 즉각성이 덜 중요한 연산은 클라우드에서 나눠 처리하는 것이 일반적

"엣지 컴퓨팅은 모든 연산을 원거리의 강력한 클라우드 서버로 집중시켜 처리하는 방식을 의미한다"라는 서술은 오답이다 — 그것은 오히려 클라우드 컴퓨팅에 가까우며, 엣지 컴퓨팅의 핵심은 **로봇과 가까운 곳에서 직접 연산해 지연을 줄이는 것**이다.

<aside>온디바이스 AI와의 관계</aside>

[[온디바이스 AI(On-device AI)]]는 엣지 컴퓨팅의 한 형태로, 로봇 자체(장치 내부)에서 AI 추론까지 수행해 클라우드 왕복 없이 즉시 판단하는 것을 목표로 한다.

---

<aside>핵심 정리</aside>

- 엣지 컴퓨팅은 로봇과 가까운 곳에서 직접 연산해 클라우드 왕복 지연을 줄이는 방식이다
- 모든 연산을 클라우드로 집중시키는 것과는 반대되는 접근이다
