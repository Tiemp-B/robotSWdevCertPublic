# Summary

RS-485는 [[RS-422]]와 같은 차동 신호 방식을 쓰면서, **여러 장치가 하나의 버스를 공유**할 수 있도록(멀티드롭) 확장된 시리얼 통신 규격으로, 산업 현장에서 다수의 센서·장치를 하나의 케이블로 연결하는 데 널리 쓰인다.

# Notes

<aside>RS-485의 멀티드롭 구조</aside>

- 차동 신호 방식([[RS-422]]와 동일한 원리)으로 노이즈에 강하고 장거리(최대 약 1,200m) 전송 가능
- 하나의 버스(선로)에 **최대 수십 개의 장치를 함께 연결**할 수 있어, 여러 센서·모터 드라이버를 하나의 케이블로 묶는 산업 현장에서 널리 쓰임
- 반이중(half-duplex) 방식이 일반적이라, 한 시점에는 버스 위의 한 장치만 송신할 수 있음(충돌 방지를 위한 프로토콜 필요)

"RS-485는 RS-422처럼 하나의 송신기가 여러 수신기에만 보낼 수 있고, 여러 장치가 버스를 공유하는 멀티드롭은 지원하지 않는다"라는 서술은 오답이다 — RS-485의 핵심은 오히려 **여러 장치가 하나의 버스를 공유하는 멀티드롭**을 지원한다는 점이며, 이것이 RS-422와의 핵심 차이다.

<aside>Modbus와의 관계</aside>

[[Modbus]] RTU는 흔히 RS-485의 물리 계층 위에서 동작한다 — RS-485가 여러 장치를 연결하는 배선을 제공하고, 그 위에서 Modbus가 마스터-슬레이브 요청-응답 방식으로 실제 데이터를 주고받는 식으로 계층이 나뉜다.

---

<aside>핵심 정리</aside>

- RS-485는 차동 신호 방식이면서 여러 장치가 하나의 버스를 공유하는 멀티드롭을 지원하는 시리얼 통신 규격이다
- RS-422와 달리 1:다가 아니라 다수 장치 간 공유 버스 방식이다
