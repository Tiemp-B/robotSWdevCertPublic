# Summary

스텝모터는 펄스 신호 하나당 정해진 각도만큼 회전하는 개루프(open-loop) 구동 방식의 모터로, 엔코더 피드백으로 위치를 계속 확인·보정하는 폐루프(closed-loop) 방식인 [[3. 구동장치 성능(서보모터)|서보모터]]와 대비된다.

# Notes

<aside>스텝모터의 개루프 동작</aside>

- 드라이버가 펄스를 하나 보내면 로터가 정해진 스텝 각도(예: 1.8˚)만큼 회전 — 피드백 센서 없이 "펄스를 보냈으니 그만큼 돌았을 것"이라고 **가정**만 함
- 부하가 모터의 보유 토크(holding torque)를 넘어서면 회전이 밀리는 **탈조(step skip/loss)** 가 발생할 수 있는데, 개루프 구조라 이를 감지·보정하지 못하고 그대로 다음 명령을 진행함

<aside>스텝모터 vs 서보모터 선택 기준</aside>

| 기준 | 스텝모터 | 서보모터 |
|---|---|---|
| 제어 방식 | 개루프(피드백 없음) | 폐루프(엔코더 피드백) |
| 탈조/오차 감지 | 불가능 | 가능(즉시 보정) |
| 최대 토크·속도 | 상대적으로 낮음 | 상대적으로 높음 |
| 비용·구조 | 저렴·단순 | 고가·복잡 |
| 적합한 용도 | 부하가 예측 가능한 저비용 응용(3D 프린터 등) | 정밀도·부하 보정이 중요한 로봇 관절 등 |

---

<aside>핵심 정리</aside>

- 스텝모터는 피드백 없는 개루프 구동이라 탈조가 발생해도 감지·보정하지 못한다
- 서보모터는 엔코더 피드백 기반 폐루프 구동으로, 더 큰 토크·속도와 정밀 보정이 가능하지만 구조가 복잡하고 비싸다
