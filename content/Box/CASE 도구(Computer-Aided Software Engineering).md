# Summary

CASE 도구는 요구사항 분석·설계·구현·테스트 등 **소프트웨어 개발 과정 전반을 자동화·지원**하는 도구의 총칭으로, UML 모델링 도구·형상관리 도구 등이 포함된다.

---

# Notes

<aside>CASE 도구의 분류</aside>

| 구분 | 지원 범위 | 예시 |
|---|---|---|
| Upper CASE | 요구사항 분석·설계 단계 지원 | UML 모델링 도구 |
| Lower CASE | 구현·테스트·유지보수 단계 지원 | 코드 생성기, 디버거 |
| Integrated CASE | 분석부터 유지보수까지 전 과정 통합 지원 | 통합 개발 환경(IDE) 계열 |

<aside>버전 관리와의 관계</aside>

[[Git]] 같은 버전 관리 시스템도 CASE 도구의 한 범주(형상관리 지원 도구)로 분류된다 — 여러 개발자가 동시에 로봇 소프트웨어 아키텍처를 설계·구현할 때 변경 이력을 추적하고 충돌을 관리하는 역할을 한다.

---

<aside>핵심 정리</aside>

- CASE 도구는 개발 과정 전반(분석·설계·구현·테스트)을 지원하는 도구의 총칭이며, Upper/Lower/Integrated로 분류된다
- Git 같은 형상관리 도구도 CASE 도구의 한 범주다
