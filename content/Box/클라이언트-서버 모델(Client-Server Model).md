# Summary

클라이언트-서버 모델은 서비스를 요청하는 **클라이언트**와 그 요청을 처리해 응답하는 **서버**로 역할을 명확히 분리하는 네트워크 아키텍처로, 대부분의 웹·로봇 원격제어 시스템의 기본 구조다.

# Notes

<aside>클라이언트와 서버의 역할 분리</aside>

- 클라이언트: 사용자와 상호작용하며 요청을 보내는 쪽(예: 로봇 모니터링 앱, 브라우저)
- 서버: 요청을 받아 처리하고 자원(데이터, 로봇 상태 등)을 제공하는 쪽 — 보통 여러 클라이언트의 요청을 동시에 처리해야 함
- 여러 클라이언트가 하나의 서버에 접속할 수 있어, 다수의 사용자·로봇이 중앙 서버를 통해 정보를 주고받는 구조를 구성하기 쉬움

<aside>C10K 문제와의 관계</aside>

서버가 다수의 클라이언트 연결을 동시에 처리해야 하는 이 구조에서, 연결 수가 매우 많아지면 [[C10K 문제(C10K Problem)]]처럼 서버의 동시 처리 능력이 병목이 될 수 있다.

---

<aside>핵심 정리</aside>

- 클라이언트-서버 모델은 요청하는 클라이언트와 응답하는 서버의 역할을 명확히 분리한 구조다
- 모든 장치가 대등하게 통신하는 P2P 구조와는 다르다
