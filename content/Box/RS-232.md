# Summary

RS-232는 두 장치 간 **1:1(point-to-point) 시리얼 통신**을 위한 오래된 전기적 규격으로, 단일 종단(unbalanced) 신호 방식 때문에 전송 거리와 노이즈 내성이 [[RS-422]]·[[RS-485]]보다 제한적이다. 클록선 없이 시작 비트로 타이밍을 맞추는 비동기 전송 방식이며, TTL과 반대 극성의 전압 체계(MARK/SPACE)를 사용한다.

# Notes

<aside>RS-232의 특징</aside>

- 신호를 하나의 선과 공통 접지(GND) 사이의 전압 차이로 표현하는 단일 종단(single-ended) 방식 — 노이즈가 접지 기준 전압에 그대로 영향을 줄 수 있음
- 이 때문에 전송 거리가 짧고(수 m~십수 m), 연결 가능한 장치도 1:1(포인트 투 포인트)로 제한됨
- 구조가 단순해 오래전부터 널리 쓰였고, PC의 시리얼 포트나 산업 장비의 설정용 인터페이스로 여전히 남아있는 경우가 많음

"RS-232는 여러 장치를 하나의 버스에 매달아 마스터-슬레이브 방식으로 통신하는 멀티드롭 규격이다"라는 서술은 오답이다 — RS-232의 핵심은 오히려 **두 장치 간 1:1 연결**만 지원한다는 점이며, 멀티드롭(여러 장치 연결)은 [[RS-485]]의 특징이다.

<aside>RS-422·RS-485와의 비교</aside>

RS-232(단일 종단, 1:1, 단거리)와 달리 [[RS-422]]·[[RS-485]]는 차동(differential) 신호 방식을 써서 노이즈에 강하고 더 먼 거리(수백~천 m 이상) 전송이 가능하며, RS-485는 여러 장치를 하나의 버스에 연결하는 멀티드롭까지 지원한다.

<aside>비동기 직렬 전송 구조</aside>

RS-232는 별도의 클록 신호선 없이 송수신 양쪽이 미리 정해둔 전송속도(Baud Rate)에만 맞춰 데이터를 주고받는 **비동기(Asynchronous) 전송** 방식이다.

- **유휴 상태(Idle)**: 아무 데이터도 보내지 않을 때 신호선은 논리 1(MARK) 상태를 유지한다
- **시작 비트(Start Bit)**: 전송이 시작되면 신호가 유휴 상태(1)에서 논리 0(SPACE)으로 전환되며, 수신 측은 이 하강 엣지를 감지해 프레임의 시작을 인식하고 타이밍(샘플링)을 동기화한다
- **데이터 비트 → (패리티 비트) → 정지 비트(Stop Bit)** 순으로 이어지며, 정지 비트는 다시 유휴 상태(1)와 같은 논리 1으로 신호선을 되돌려 다음 프레임을 받을 준비를 한다
- 대표 프레임 형식 예: **8N1**(데이터 8비트, 패리티 없음, 정지비트 1개)

"RS-232는 별도의 클록 신호선으로 송수신 타이밍을 맞추는 동기(Synchronous) 방식이다"라는 서술은 오답이다 — RS-232의 핵심은 클록선 없이 시작 비트로 타이밍을 잡는 **비동기** 방식이라는 점이다.

<aside>RS-232C 기본 신호 핀(DB9)</aside>

| 핀 기능 | 역할 |
|---|---|
| TXD (송신 데이터) | 데이터를 상대 장치로 전송 |
| RXD (수신 데이터) | 상대 장치로부터 데이터 수신 |
| GND (신호 접지) | 단일 종단 신호의 전압 기준점 |
| RTS / CTS | 하드웨어 흐름 제어(송신 요청/송신 가능) |
| DTR / DSR | 장비 연결 상태 제어(단말기 준비/데이터셋 준비) |

가장 단순한 연결은 TXD·RXD·GND 3선만으로도 가능하며, RTS/CTS·DTR/DSR은 흐름 제어·장비 상태 확인이 필요할 때 추가로 사용한다.

<aside>RS-232 전압 논리</aside>

RS-232는 TTL/CMOS(0V~5V 기준, LOW 0~0.8V/HIGH 2V 이상)와는 전압 체계 자체가 다르며, 두 논리 값을 서로 반대 극성의 전압대로 표현한다.

- **논리 1 (MARK)**: −3V ~ −15V (유휴 상태·정지 비트가 이 전압)
- **논리 0 (SPACE)**: +3V ~ +15V (시작 비트가 이 전압)
- ±25V까지 허용되며, 이 전압 체계 때문에 MCU(TTL/CMOS 레벨)와 직접 연결할 수 없고 **레벨 변환기(MAX232 등)**가 필요하다

"RS-232는 TTL과 동일하게 양(+)의 전압만으로 0과 1을 구분한다"라는 서술은 오답이다 — RS-232의 핵심은 오히려 **음(−)전압을 논리 1, 양(+)전압을 논리 0으로 쓰는 반전된 양극성 체계**라는 점이다.

---

<aside>핵심 정리</aside>

- RS-232는 단일 종단 신호 방식의 1:1 시리얼 통신 규격으로, 전송 거리가 짧고 노이즈에 약하다
- 여러 장치를 연결하는 멀티드롭 방식이 아니다
- 클록선 없이 시작 비트로 타이밍을 맞추는 비동기 전송이며, 유휴 상태·정지 비트는 논리1(MARK), 시작 비트는 논리0(SPACE)이다
- 전압 논리는 TTL과 반대 극성(MARK −3~−15V / SPACE +3~+15V)이라 MCU 연결 시 레벨 변환기가 필요하다
- 기본 신호 핀은 TXD/RXD/GND이며, RTS·CTS/DTR·DSR은 흐름 제어·장비 상태 확인용으로 추가된다
