# Summary

UI(사용자 인터페이스)는 사용자가 시스템과 상호작용하는 **화면·버튼·입력 요소 등 접점 자체**를 가리키며, 사용자가 그 상호작용에서 느끼는 만족도·편의성을 뜻하는 [[UX(User Experience)]]와 구분된다.

# Notes

<aside>UI와 UX의 구분</aside>

- UI는 버튼·아이콘·레이아웃처럼 눈에 보이고 손으로 조작하는 **인터페이스 요소 자체**
- UX는 그 인터페이스를 사용하면서 사용자가 느끼는 전반적인 경험(편리한지, 직관적인지, 만족스러운지)
- 같은 기능이라도 UI 디자인이 다르면 UX(사용자 경험)가 크게 달라질 수 있음 — UI는 UX를 구성하는 하나의 요소

<aside>로봇 콘텐츠 시나리오 기획에서의 위치</aside>

로봇 콘텐츠의 시나리오를 기획할 때 UI(화면 요소·버튼 배치)와 UX(전체 상호작용 흐름·만족도)를 함께 고려해야, 기능은 갖췄지만 사용하기 불편한 콘텐츠가 되는 것을 피할 수 있다.

---

<aside>핵심 정리</aside>

- UI는 사용자와 시스템이 상호작용하는 인터페이스 요소 자체를 가리킨다
- UX(전체 경험)와 동일 개념이 아니라, UI는 UX를 구성하는 하나의 요소다
