# Summary

툴체인저는 로봇 팔과 엔드이펙터(그리퍼·용접건 등) 사이에 장착해 도구를 빠르게 자동으로 교체할 수 있게 하는 기계적 인터페이스로, 하나의 로봇으로 여러 작업을 수행할 수 있게 해준다.

# Notes

<aside>구조 — 마스터 플레이트와 툴 플레이트</aside>

| 구성 | 위치 |
|---|---|
| 마스터 플레이트(Master Plate) | 로봇 팔(손목) 쪽에 장착 |
| 툴 플레이트(Tool Plate) | 엔드이펙터(그리퍼 등) 쪽에 장착 |

마스터 플레이트가 툴 플레이트를 잠금(공압·자석 등의 방식으로)해 결합하며, 공압 라인과 전기 신호선이 두 플레이트를 그대로 통과(pass-through)하도록 설계되어 있어 도구를 교체해도 배선을 다시 연결할 필요가 없다.

<aside>활용 목적</aside>

- **셋업 시간 단축**: 작업 전환 시 도구를 수동으로 교체·배선하는 시간을 줄임
- **다기능화**: 하나의 로봇이 여러 종류의 엔드이펙터(그리퍼·용접건·흡착패드 등)를 자동으로 바꿔가며 다양한 공정을 수행할 수 있게 함

---

<aside>핵심 정리</aside>

- 툴체인저는 로봇쪽 마스터 플레이트와 공구쪽 툴 플레이트로 구성되며, 공압·전기 신호가 그대로 통과하도록 설계된다
- 도구 교체 시간을 줄이고, 하나의 로봇으로 여러 작업을 수행할 수 있게 하는 것이 핵심 목적이다
