# Summary

상보 필터는 서로 다른 센서의 **저주파 성분과 고주파 성분을 단순 가중합으로 결합**해 자세를 추정하는 필터로, [[칼만 필터(Kalman Filter)]]보다 계산량이 훨씬 적어 저사양 장치에서도 쓰기 쉽다.

# Notes

<aside>상보 필터의 원리</aside>

- 가속도계처럼 **느린 변화(저주파)에는 강하지만 진동에 약한 센서**의 저주파 성분과, 자이로처럼 **빠른 변화(고주파)는 정확하지만 누적 오차(드리프트)가 쌓이는 센서**의 고주파 성분을 각각 걸러내 더한다
- 확률 모델이나 행렬 연산 없이 단순 가중합으로 계산하므로 구현이 간단하고 연산량이 적다

"상보 필터는 칼만 필터와 동일하게 확률적 예측-보정 사이클을 사용한다"라는 서술은 오답이다 — 상보 필터는 오히려 확률 모델 없이 **단순 가중합**으로 결합하는 방식이며, 이 점이 칼만 필터와의 핵심 차이다.

<aside>칼만 필터와의 선택 기준</aside>

| 기준 | 상보 필터 | 칼만 필터 |
|---|---|---|
| 계산량 | 적음(저사양 MCU에도 적합) | 많음(행렬 연산) |
| 정상상태 정확도 | 상대적으로 낮음 | 상대적으로 높음 |
| 급격한 변화 반응 | 빠른 편 | 상대적으로 느릴 수 있음 |

정밀도가 중요한 상황은 칼만 필터, 자원이 부족하거나 빠른 구현이 필요한 소형 로봇·드론은 상보 필터가 실용적인 선택이 된다.

---

<aside>핵심 정리</aside>

- 상보 필터는 저주파·고주파 성분을 센서별로 나눠 가중합으로 결합하는 경량 자세 추정 필터다
- 칼만 필터 같은 확률적 예측-보정 사이클이 없어 계산량이 적지만, 정상상태 정확도는 다소 낮다
