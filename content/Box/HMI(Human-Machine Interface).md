# Summary

HMI(Human-Machine Interface)는 사람이 로봇·산업 설비의 상태를 **직관적으로 보고, 명령을 내릴 수 있게** 해주는 화면·조작 인터페이스로, 실시간 상태 표시와 알람, 조작 버튼 등으로 구성된다.

# Notes

<aside>HMI 설계의 핵심 원칙</aside>

- 중요한 정보(이상 상태, 알람)를 한눈에 파악할 수 있도록 시각적 우선순위를 명확히 함(색상·크기로 긴급도 구분)
- 조작자가 실수로 위험한 명령을 누르지 않도록 확인 절차·명확한 레이블링을 둠
- [[E-stop(비상정지)]] 상태처럼 안전과 직결된 정보는 항상 눈에 띄는 위치에 고정 표시

<aside>SCADA·모니터링과의 관계</aside>

HMI는 [[SCADA]] 시스템의 사람이 직접 보는 화면 부분에 해당하며, SCADA가 수집한 데이터를 HMI가 시각화하고 알람으로 표현한다 — 데이터 수집·제어(SCADA)와 사람과의 접점(HMI)은 서로 다른 계층의 개념이다.

---

<aside>핵심 정리</aside>

- HMI는 정보의 우선순위를 가려 직관적으로 표시하고 안전하게 조작하도록 돕는 사람-기계 인터페이스다
- 모든 정보를 빠짐없이 나열하는 것이 아니라, 우선순위에 따른 명확한 전달이 핵심이다
