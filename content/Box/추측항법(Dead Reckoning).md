# Summary

추측항법(Dead Reckoning)은 외부 절대 위치 정보(GPS 등) 없이, **이전 위치와 이동한 방향·거리(속도·시간)를 누적 계산**해 현재 위치를 추정하는 방식으로, 시간이 지날수록 오차가 누적된다는 근본적인 한계가 있다.

# Notes

<aside>추측항법의 동작과 오차 누적 문제</aside>

- 엔코더로 측정한 바퀴 회전량, IMU로 측정한 가속도·각속도 등을 적분해 "이전 위치에서 얼마나, 어느 방향으로 이동했는지"를 계산하고 이를 계속 누적함
- 매 계산마다 작은 측정 오차가 섞이는데, 이 오차가 **적분(누적) 과정에서 계속 쌓여** 시간이 지날수록 실제 위치와의 오차가 점점 커짐
- GPS나 랜드마크 인식처럼 절대 위치를 알려주는 외부 정보로 주기적으로 오차를 보정해주지 않으면, 추측항법만으로는 장시간 정확한 위치를 유지하기 어려움

<aside>칼만 필터·센서 융합과의 관계</aside>

추측항법의 오차 누적 문제를 완화하기 위해, [[칼만 필터(Kalman Filter)]]로 추측항법 결과와 GPS·랜드마크 같은 절대 위치 정보를 [[센서 데이터 융합(Sensor Fusion)]]해 오차를 주기적으로 보정하는 방식이 널리 쓰인다.

---

<aside>핵심 정리</aside>

- 추측항법은 이전 위치와 이동량을 누적 계산해 현재 위치를 추정하는 방식이다
- 측정 오차가 시간이 지날수록 누적되어 정확도가 점점 떨어진다는 근본적 한계가 있다
