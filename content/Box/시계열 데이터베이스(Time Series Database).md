# Summary

시계열 데이터베이스(TSDB)는 **타임스탬프가 붙은 데이터를 시간 순서대로 대량으로 빠르게 저장·조회**하도록 특화된 데이터베이스로, 로봇 센서 로그처럼 계속 쌓이는 시간 기반 데이터에 적합하다.

# Notes

<aside>시계열 데이터베이스의 특화 지점</aside>

- 대부분의 데이터에 "언제 측정되었는가"라는 시간 축이 핵심이며, 시간 범위로 조회하거나 시간에 따른 집계(평균, 최댓값 등)를 계산하는 연산이 매우 빈번함
- 일반 관계형 DB보다 시간 기반 대량 쓰기(계속 추가되는 로그)와 시간 범위 조회에 최적화된 저장 구조·압축 방식을 사용
- 로봇의 배터리 잔량, 온도, 위치 등을 초 단위로 계속 기록하는 로그 데이터를 저장하는 데 적합

<aside>다운샘플링(Downsampling)과 롤업</aside>

오래된 원본 데이터를 그대로 무한정 쌓아두면 저장 공간이 계속 커지므로, 시간 구간별로 평균·최댓값 등 집계 함수를 적용해 더 성긴 간격의 요약 데이터(**롤업**)로 압축하는 다운샘플링을 흔히 함께 쓴다. 최근 데이터는 원본 그대로, 오래된 데이터는 롤업만 남기는 방식이 일반적이다.

<aside>NoSQL과의 관계</aside>

시계열 데이터베이스는 흔히 [[NoSQL]] 계열로 분류되며, 고정된 스키마보다는 대량의 시간 기반 쓰기·조회 성능에 최적화된 구조를 갖는다는 공통점이 있다.

---

<aside>핵심 정리</aside>

- 시계열 데이터베이스는 타임스탬프 기반 데이터를 시간 순서로 대량 저장·조회하는 데 특화된 DB다
- 시간과 무관한 정적 참조 데이터가 아니라, 계속 쌓이는 시간 기반 데이터에 최적화되어 있다
