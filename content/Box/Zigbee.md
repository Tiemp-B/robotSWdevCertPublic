# Summary

Zigbee는 저전력·저속 통신에 특화된 무선 규격으로, 장치들이 서로를 중계해주는 **메시(mesh) 네트워크 토폴로지**를 지원해 넓은 영역에 분산된 다수의 IoT 센서를 연결하는 데 적합하다.

# Notes

<aside>Zigbee의 메시 네트워크</aside>

- 각 장치(노드)가 인접한 다른 노드로 데이터를 중계할 수 있어, 하나의 AP·게이트웨이 범위를 벗어난 먼 노드도 다른 노드를 거쳐 통신 가능
- [[LoRaWAN]]의 스타(star) 토폴로지와 달리, Zigbee는 노드끼리 서로 연결·중계하는 구조로 네트워크 전체 커버리지를 확장할 수 있음
- 저전력·저속에 최적화되어 있어 대용량 데이터보다는 다수의 센서·스위치 같은 간헐적 소량 데이터에 적합

<aside>다른 무선 IoT 규격과의 비교</aside>

Zigbee(메시, 근~중거리), [[LoRaWAN]](스타, 초광역), [[Bluetooth]](근거리, 1:1 또는 소수 장치)는 모두 저전력 무선 통신이지만 토폴로지와 커버리지 범위가 서로 다르다 — 넓은 지역에 흩어진 다수의 IoT 노드를 서로 중계시켜 연결하려면 Zigbee의 메시 구조가 적합하다.

---

<aside>핵심 정리</aside>

- Zigbee는 저전력·저속 통신에 특화되며, 노드 간 중계가 가능한 메시 네트워크를 지원하는 무선 규격이다
- 스타 토폴로지만 지원하는 방식이 아니라, 노드끼리 서로 중계할 수 있다는 점이 핵심이다
