# Summary

Unity3D는 원래 게임 개발용으로 만들어진 범용 3D 엔진으로, 뛰어난 시각화·상호작용 콘텐츠 제작 기능을 활용해 로봇 콘텐츠·시뮬레이션 저작 도구로도 널리 쓰인다.

# Notes

<aside>Unity3D의 강점</aside>

- 그래픽 렌더링, 애니메이션, 사용자 상호작용(UI) 제작에 특화된 범용 게임 엔진
- 다양한 플랫폼(PC, 모바일, VR/AR 등)으로 동일한 콘텐츠를 손쉽게 배포할 수 있는 크로스 플랫폼 지원
- 물리 시뮬레이션 기능도 있지만, [[Gazebo]]만큼 로봇 공학에 특화된 정밀한 물리 검증보다는 시각화·콘텐츠·상호작용 제작에 더 강점이 있음

"Unity3D는 로봇 물리 시뮬레이션의 정밀한 검증에 특화된 로봇 전용 도구로, 시각화나 상호작용 콘텐츠 제작에는 적합하지 않다"라는 서술은 오답이다 — Unity3D의 핵심 강점은 오히려 **범용 시각화·상호작용 콘텐츠 제작**이며, 정밀한 로봇 물리 검증은 [[Gazebo]] 같은 전용 시뮬레이터의 강점이다.

<aside>메타모델·저작 소프트웨어와의 관계</aside>

로봇 콘텐츠 저작 소프트웨어에서 Unity3D 같은 엔진은 [[메타모델(Meta-model)]]로 정의된 콘텐츠 구조를 실제로 시각화하고 사용자와 상호작용하게 만드는 실행 엔진 역할을 한다.

---

<aside>핵심 정리</aside>

- Unity3D는 시각화·상호작용 콘텐츠 제작에 강점이 있는 범용 3D 게임 엔진이다
- 로봇 물리 검증 전용 도구가 아니며, 그 역할은 Gazebo 같은 로봇 시뮬레이터가 더 특화되어 있다
