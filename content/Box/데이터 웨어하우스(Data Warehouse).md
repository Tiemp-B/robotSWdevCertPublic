# Summary

데이터 웨어하우스는 여러 시스템에서 수집한 데이터를 **분석·의사결정 목적에 맞게 통합·정제해 장기간 저장**하는 대규모 저장소로, 일상적인 트랜잭션 처리용 DB와는 목적이 다르다.

# Notes

<aside>데이터 웨어하우스의 목적</aside>

- 일반 운영 DB는 실시간 입출력(주문 처리 등)에 최적화되어 있는 반면, 데이터 웨어하우스는 **과거 데이터를 모아 분석·보고서 작성에 최적화**됨
- 여러 원천 시스템의 데이터를 [[ETL(Extract Transform Load)]] 과정을 거쳐 통합·정제한 뒤 적재함
- 시간에 따라 데이터를 계속 누적하는 것이 일반적이며(과거 데이터를 삭제하지 않음), 트렌드 분석에 활용

"데이터 웨어하우스는 실시간 거래 처리(주문 입력 등)에 최적화된 운영 데이터베이스와 동일한 목적으로 설계된다"라는 서술은 오답이다 — 데이터 웨어하우스의 핵심 목적은 오히려 **분석·의사결정을 위한 과거 데이터의 통합·축적**이며, 실시간 트랜잭션 처리가 목적인 운영 DB와는 설계 목적 자체가 다르다.

<aside>ETL·데이터 마이닝과의 관계</aside>

여러 로봇에서 수집한 원시 로그는 [[ETL(Extract Transform Load)]] 과정을 거쳐 데이터 웨어하우스에 쌓이고, 이렇게 축적된 데이터를 대상으로 [[데이터 마이닝(Data Mining)]]을 수행해 패턴을 찾아낸다.

---

<aside>핵심 정리</aside>

- 데이터 웨어하우스는 분석·의사결정을 위해 통합·정제된 데이터를 장기간 축적하는 저장소다
- 실시간 트랜잭션 처리가 목적인 운영 DB와는 목적이 다르다
