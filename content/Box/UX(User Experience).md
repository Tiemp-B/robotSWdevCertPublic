# Summary

UX(사용자 경험)는 사용자가 시스템을 사용하면서 겪는 **전반적인 만족도·편의성·감정적 경험**을 가리키며, 인터페이스 요소 자체인 [[UI(User Interface)]]보다 더 넓은 개념이다.

# Notes

<aside>UX가 포괄하는 범위</aside>

- 화면 디자인(UI)뿐 아니라, 정보 구조, 상호작용 흐름, 응답 속도, 심지어 첫인상까지 사용자가 겪는 모든 경험을 포함
- 같은 기능이라도 사용자가 목표를 얼마나 쉽고 자연스럽게 달성할 수 있는지에 따라 UX 품질이 달라짐
- [[사용성 테스트(Usability Testing)]]·[[휴리스틱 평가(Heuristic Evaluation)]] 같은 방법으로 UX를 평가·개선함

"UX는 화면의 시각적 디자인(색상, 아이콘 등)만을 가리키는 개념이다"라는 서술은 오답이다 — 화면 시각 디자인은 UI의 영역이며, UX의 핵심은 오히려 **상호작용 전반에 걸친 사용자의 경험과 만족도**를 가리키는 더 넓은 개념이다.

<aside>로봇 콘텐츠 기획에서의 의미</aside>

로봇 콘텐츠 시나리오를 기획할 때, 버튼 배치(UI)가 예뻐도 사용자가 원하는 기능을 찾기 어렵거나 응답이 느리면 UX는 나빠질 수 있다 — 두 요소를 함께 설계해야 한다.

---

<aside>핵심 정리</aside>

- UX는 사용자가 시스템을 사용하며 겪는 전반적인 경험·만족도를 가리킨다
- 화면 시각 디자인(UI)보다 넓은 개념으로, 상호작용 흐름 전체를 포함한다
