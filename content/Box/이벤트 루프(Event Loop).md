# Summary

이벤트 루프는 **하나의 스레드가 반복문(루프)을 돌며 발생한 이벤트를 순서대로 꺼내 처리**하는 실행 모델로, 스레드를 늘리지 않고도 다수의 I/O 작업을 논블로킹 방식으로 동시에 처리할 수 있게 한다.

# Notes

<aside>이벤트 루프의 동작 방식</aside>

- 이벤트 큐에 쌓인 이벤트(네트워크 응답 도착, 타이머 만료 등)를 하나씩 꺼내 그에 등록된 콜백 함수를 실행
- I/O 작업(네트워크 요청 등)을 시작만 해두고 결과를 기다리는 동안 스레드를 블로킹하지 않고, 다른 이벤트를 계속 처리함 — 결과가 오면 그때 콜백이 큐에 추가되어 처리됨
- 이런 논블로킹 방식 덕분에 [[C10K 문제(C10K Problem)]]처럼 수많은 동시 연결을 소수의 스레드로도 효율적으로 처리 가능

<aside>Promise·비동기 처리와의 관계</aside>

[[Promise(프라미스)]] 기반의 비동기 코드는 이벤트 루프 위에서 동작하며, 비동기 작업이 완료되었을 때의 처리(`.then()`)가 이벤트 큐에 등록되어 이벤트 루프가 순서대로 실행하는 방식으로 이뤄진다.

---

<aside>핵심 정리</aside>

- 이벤트 루프는 소수의 스레드가 이벤트 큐를 반복 처리하며 논블로킹 I/O를 다루는 실행 모델이다
- 이벤트마다 새 스레드를 생성하는 멀티스레드 방식이 아니다
