# Summary

위치 정밀도(Accuracy)는 로봇이 도달한 위치가 **목표(참값)에 얼마나 가까운지**를 나타내는 성능 지표로, 여러 번 반복했을 때의 일관성을 나타내는 [[반복 정밀도(Repeatability)]]와는 다른 개념이다.

# Notes

<aside>위치 정밀도와 반복 정밀도의 독립성</aside>

- 위치 정밀도: 목표 위치와 실제 도달 위치 사이의 **차이(오차)의 크기**
- [[반복 정밀도(Repeatability)]]: 같은 동작을 반복했을 때 도달 위치들끼리의 **분산(흩어짐)**
- 두 지표는 서로 독립적이다 — 로봇이 매번 같은 (잘못된) 위치로 일관되게 이동한다면 반복 정밀도는 높지만 위치 정밀도는 낮은 상황이 가능하며, 그 반대도 가능함

"위치 정밀도가 높다는 것은 로봇이 같은 동작을 반복했을 때 도달 위치들이 서로 가깝다는 것을 의미한다"라는 서술은 오답이다 — 그것은 오히려 [[반복 정밀도(Repeatability)]]의 정의이며, 위치 정밀도의 핵심은 **목표(참값)와의 오차가 얼마나 작은가**이다.

<aside>위치 정밀도를 저하시키는 요인</aside>

- **기구학적 오차**: 제조·조립 공차로 인한 링크 길이 오차, 관절 영점 오차 등 — 전체 오차의 대부분(약 90%)을 차지
- **비기구학적 오차**: 온도 변화에 따른 열팽창, 기어 백래시, 관절·링크의 컴플라이언스(강성 부족)

<aside>ISO 9283에서의 위치</aside>

ISO 9283 로봇 성능 지표는 위치 정밀도와 반복 정밀도를 별도로 정의하고 각각 측정하도록 요구한다 — 로봇의 성능을 온전히 평가하려면 두 지표를 혼동하지 않고 함께 확인해야 한다.

---

<aside>핵심 정리</aside>

- 위치 정밀도는 목표(참값)와 실제 도달 위치 사이의 오차 크기를 나타낸다
- 반복 시도들 간의 일관성을 나타내는 반복 정밀도와는 독립적인 별개의 지표다
- 기구학적 오차(제조·조립 공차)와 비기구학적 오차(열팽창·백래시·컴플라이언스)가 위치 정밀도를 저하시킨다
