# Summary

XSS(크로스 사이트 스크립팅)는 공격자가 웹 페이지에 **악성 스크립트를 삽입**해, 다른 사용자의 브라우저에서 그 스크립트가 실행되도록 만드는 웹 애플리케이션 취약점이다.

# Notes

<aside>XSS의 동작 원리</aside>

- 게시판 글, 댓글 등 사용자 입력값이 검증 없이 그대로 웹 페이지에 출력되면, 그 안에 삽입된 `<script>` 태그가 다른 사용자의 브라우저에서 실행됨
- 이렇게 실행된 악성 스크립트는 사용자의 [[쿠키(Cookie)]]·[[세션(Session)]] 정보를 탈취하거나, 사용자 몰래 다른 동작을 수행하게 할 수 있음
- [[SQL Injection]]이 서버의 데이터베이스를 대상으로 한다면, XSS는 **다른 사용자의 브라우저**를 대상으로 한다는 차이가 있음

<aside>방어 기법</aside>

사용자 입력값을 화면에 출력하기 전에 HTML 특수문자(`<`, `>` 등)를 이스케이프 처리해, 입력값이 스크립트 태그로 해석되지 않도록 하는 것이 XSS의 기본 방어책이다.

---

<aside>핵심 정리</aside>

- XSS는 웹 페이지에 악성 스크립트를 삽입해 다른 사용자의 브라우저에서 실행시키는 취약점이다
- 서버 DB를 직접 겨냥하는 SQL Injection과 달리, 다른 사용자의 브라우저를 대상으로 한다
