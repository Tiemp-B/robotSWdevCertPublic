# Summary

NTP(Network Time Protocol)는 네트워크로 연결된 여러 장치의 **시스템 시각을 하나의 기준 시각에 맞춰 동기화**하는 프로토콜로, 여러 로봇·센서의 타임스탬프를 일치시키는 데 쓰인다.

# Notes

<aside>NTP의 동작 방식</aside>

- 클라이언트가 서버에 시각 요청을 보내고, 요청·응답에 걸린 왕복 지연시간을 측정해 **네트워크 전송 지연을 보정한 정확한 시각**을 계산
- 여러 단계의 시각 서버(계층, stratum)를 거쳐 기준 시각(원자시계 등)에서부터 점점 전파되는 구조
- 시각이 어긋난 장치는 NTP를 통해 점진적으로 또는 즉시 시각을 맞춤

<aside>로봇 센서 융합에서의 의미</aside>

여러 센서·로봇이 각각 다른 타임스탬프 기준을 쓰면 [[센서 데이터 융합(Sensor Fusion)]] 시 시점이 어긋나 오차가 생긴다 — NTP(또는 더 정밀한 PTP)로 시계를 동기화하는 것이 통신 프로토콜 설계에서 시간 동기화 고려사항의 기본이다.

---

<aside>핵심 정리</aside>

- NTP는 왕복 지연시간을 보정해 여러 장치의 시각을 하나의 기준에 동기화하는 프로토콜이다
