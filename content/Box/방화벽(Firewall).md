# Summary

방화벽은 미리 정의된 규칙에 따라 네트워크로 드나드는 트래픽을 **허용하거나 차단**하는 보안 장치로, 로봇 제어 네트워크를 외부의 불필요하거나 악의적인 접근으로부터 보호하는 첫 방어선이다.

# Notes

<aside>방화벽의 기본 동작</aside>

- 출발지/목적지 IP, 포트 번호, 프로토콜 종류 등을 기준으로 트래픽을 검사해, 규칙에 맞지 않는 트래픽을 차단
- 기본적으로 필요한 통신(예: 특정 포트로의 제어 명령)만 허용하고, **나머지는 기본적으로 차단**하는 화이트리스트 방식이 보안상 더 안전함
- 로봇 제어 네트워크에서는 외부 인터넷에서 직접 제어 포트에 접근하지 못하도록 방화벽으로 차단하는 것이 기본적인 네트워크 보안 강화 조치

<aside>다른 보안 요소와의 관계</aside>

방화벽이 네트워크 경계에서의 접근 자체를 통제한다면, [[SSL_TLS]]는 허용된 통신의 내용을 암호화·인증하고, [[침입 탐지 시스템(IDS)]]는 방화벽을 통과한 트래픽 중 이상 징후를 추가로 감시하는 등 여러 계층이 함께 방어를 구성한다.

---

<aside>핵심 정리</aside>

- 방화벽은 규칙에 따라 네트워크 트래픽을 허용·차단하는 보안 장치다
- 기본적으로 모두 허용하고 위험한 것만 막는 것이 아니라, 기본 차단·필요한 것만 허용하는 방식이 더 안전하다
