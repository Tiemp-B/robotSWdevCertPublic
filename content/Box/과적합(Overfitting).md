# Summary

과적합(Overfitting)은 모델이 **학습 데이터에는 지나치게 잘 맞지만, 처음 보는 데이터(테스트 데이터)에는 성능이 떨어지는** 현상으로, 모델이 학습 데이터의 노이즈까지 암기해버렸을 때 발생한다.

# Notes

<aside>과적합이 발생하는 원인과 신호</aside>

- 모델의 복잡도(파라미터 수 등)가 학습 데이터의 양·다양성에 비해 지나치게 클 때 발생하기 쉬움
- 학습 데이터에 대한 정확도는 계속 오르는데, 검증/테스트 데이터에 대한 정확도는 오히려 떨어지기 시작하면 과적합의 신호
- 모델이 데이터의 일반적인 패턴이 아니라 학습 데이터 고유의 노이즈·우연한 특성까지 암기해버린 상태

"과적합은 모델이 학습 데이터와 테스트 데이터 모두에서 성능이 낮게 나오는 현상을 가리킨다"라는 서술은 오답이다 — 과적합의 핵심은 오히려 **학습 데이터 성능은 매우 높지만 테스트(새로운) 데이터 성능은 떨어지는** 불균형이며, 둘 다 성능이 낮은 것은 과소적합(underfitting)에 해당한다.

<aside>드롭아웃과의 관계</aside>

[[드롭아웃(Dropout)]]은 학습 중 일부 뉴런을 무작위로 비활성화해 모델이 특정 뉴런 조합에 지나치게 의존(암기)하지 못하게 함으로써, 과적합을 줄이는 대표적인 정규화 기법이다.

---

<aside>핵심 정리</aside>

- 과적합은 학습 데이터 성능은 높지만 새로운 데이터 성능은 떨어지는 현상이다
- 학습·테스트 모두 성능이 낮은 것은 과적합이 아니라 과소적합이다
