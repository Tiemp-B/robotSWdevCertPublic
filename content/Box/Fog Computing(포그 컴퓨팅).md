# Summary

포그 컴퓨팅(Fog Computing)은 **엣지와 클라우드 사이에 위치하는 중간 계층**으로, 엣지에서 온 데이터를 분석·집계한 뒤 필요한 것만 클라우드로 올려보내, 엣지 단독보다는 넓은 범위를 다루면서도 클라우드보다는 낮은 지연시간을 제공한다.

# Notes

<aside>포그 컴퓨팅의 위치 — 3계층 구조</aside>

| 계층 | 역할 |
|---|---|
| [[엣지 컴퓨팅(Edge Computing)|엣지]] | 로봇·센서 바로 근처에서 즉시 처리(가장 낮은 지연) |
| 포그 | 여러 엣지 노드의 데이터를 모아 분석·집계, 클라우드로 보내기 전 1차 처리 |
| [[클라우드 컴퓨팅(Cloud Computing)|클라우드]] | 대규모 저장·분석, 전체 모니터링·임무 제어(가장 넓은 범위, 가장 큰 지연) |

포그는 클라우드 컴퓨팅을 네트워크 가장자리 쪽으로 확장한 것으로, 종단 장치와 클라우드 데이터센터 사이에 분산된 노드망으로 컴퓨팅·저장·네트워킹 서비스를 제공한다.

<aside>다중 로봇 시스템에서의 활용</aside>

여러 대의 로봇이 각자 엣지에서 처리한 결과를 포그 계층에 올려 서로 공유하면, 매번 클라우드까지 조회하지 않고도 로봇들끼리 필요한 자원(지도 정보 등)을 빠르게 주고받을 수 있다 — 로봇 계층 → 엣지 계층 → 포그 계층(분산 저장·공유) → 클라우드 계층(전체 모니터링) 순의 계층 구조가 대표적인 예다.

---

<aside>핵심 정리</aside>

- 포그 컴퓨팅은 엣지와 클라우드 사이의 중간 계층으로, 데이터를 1차 분석·집계해 클라우드 부담을 줄인다
- 엣지보다 넓은 범위, 클라우드보다 낮은 지연을 제공하는 절충 지점이다
