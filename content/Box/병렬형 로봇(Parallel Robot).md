# Summary

병렬형(Parallel) 로봇은 여러 개의 짧은 팔이 각각 독립적으로 베이스와 엔드이펙터를 동시에 연결하는 구조로, 베이스-링크-관절이 한 줄로 이어지는 직렬(Serial) 로봇과 근본적으로 다르다.

# Notes

<aside>직렬 로봇 vs 병렬 로봇</aside>

| 구분 | 직렬(Serial) 로봇 | 병렬(Parallel) 로봇 |
|---|---|---|
| 구조 | 베이스-링크-관절-...-엔드이펙터로 이어지는 하나의 개루프(open loop) 사슬 | 여러 개의 팔이 베이스와 엔드이펙터를 동시에 연결 |
| 오차 누적 | 뒤쪽 링크의 정밀도가 앞쪽 링크에 의존(누적) | 각 팔의 오차가 누적되지 않음 |
| 강성·정밀도 | 상대적으로 낮음 | 상대적으로 높음 |
| 대표 예 | 직교좌표형·관절형·SCARA 등 (이 vault의 5대 구조 분류가 모두 직렬) | 델타(Delta) 로봇 |

직교좌표형·원통좌표형·극좌표형·관절형·SCARA형은 모두 베이스에서 엔드이펙터까지 하나의 사슬로 이어지는 **직렬 구조**라는 공통점이 있으며, 병렬 로봇은 이와 대비되는 별개의 구조 범주다.

<aside>델타(Delta) 로봇의 특징</aside>

병렬 로봇의 대표 사례인 델타 로봇은 무거운 모터를 베이스에 고정하고, 팔 자체는 가볍게 구성한다. 그 덕분에 팔을 빠르게 움직일 수 있어, 컨베이어 벨트 위 부품을 빠르게 집어 옮기는 **픽앤플레이스(pick-and-place)** 작업에 특히 널리 쓰인다.

"병렬 로봇은 직렬 로봇보다 항상 넓은 작업 공간을 가진다"라는 서술은 오답이다 — 병렬 로봇은 오히려 강성·속도·정밀도에 강점이 있는 대신, 일반적으로 직렬 로봇보다 **작업 공간이 좁다**는 트레이드오프가 있다.

---

<aside>핵심 정리</aside>

- 직렬 로봇은 하나의 사슬로 이어져 오차가 누적되고, 병렬 로봇은 여러 팔이 동시에 엔드이펙터를 지지해 오차가 누적되지 않는다
- 병렬 로봇(델타 로봇 등)은 강성·속도가 높은 대신 작업 공간이 좁은 경향이 있다
