# Summary

TMR(삼중 모듈 이중화)은 동일한 기능을 수행하는 모듈 3개를 병렬로 두고, **다수결(voting)로 최종 출력을 결정**해 하나의 모듈이 고장 나도 시스템이 정상 동작하도록 하는 고장 허용(fault-tolerant) 설계 기법이다.

# Notes

<aside>TMR의 다수결 동작 원리</aside>

- 동일한 입력에 대해 3개의 독립된 모듈이 각각 결과를 계산
- 3개의 출력을 비교해, **다수(2개 이상)가 일치하는 값을 최종 출력**으로 채택하는 투표(voting) 절차를 거침
- 이 방식이면 3개 중 1개 모듈이 고장(잘못된 값 출력)나도, 나머지 2개가 일치하면 시스템 전체는 정상적인 값을 낼 수 있음

<aside>안전 등급과의 관계</aside>

높은 [[SIL(Safety Integrity Level)]] 등급을 요구하는 안전 필수 시스템(항공, 원자력, 고위험 로봇 응용)에서는 하나의 하드웨어·소프트웨어 결함이 전체 시스템 실패로 이어지지 않도록 TMR 같은 이중화 설계가 요구되는 경우가 많다.

---

<aside>핵심 정리</aside>

- TMR은 동일 기능 모듈 3개의 출력을 다수결로 비교해 하나의 고장을 견디는 고장 허용 설계 기법이다
- 먼저 응답한 값을 그대로 채택하는 방식이 아니라 다수결 투표가 핵심이다
