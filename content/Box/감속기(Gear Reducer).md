# Summary

감속기는 모터의 **고속·저토크** 회전을 **저속·고토크**로 바꿔주는 부품으로, 로봇 관절의 출력 토크는 모터 토크에 감속비와 감속기 효율을 곱해 계산한다.

# Notes

<aside>감속기의 역할과 토크 계산</aside>

$$\tau_{output} = \tau_{motor} \times G \times \eta$$

- $G$: 감속비(gear ratio) — 입력 회전속도 ÷ 출력 회전속도
- $\eta$: 감속기 효율(η, 1보다 작은 값) — 마찰 등으로 인한 손실을 반영

감속비가 클수록 출력 회전속도는 그만큼 줄고, 출력 토크는 이론상 그만큼 커진다. 예를 들어 모터가 3,000rpm으로 회전할 때 감속비 30:1인 감속기를 쓰면 출력축은 100rpm으로 줄고, 토크는 이론상 30배로 커진다.

<aside>이론값과 실제값의 차이 — 효율 손실</aside>

"감속비가 30:1이면 출력 토크는 정확히 모터 토크의 30배가 된다"라는 서술은 오답이다 — 이는 효율 손실을 무시한 **이론값**일 뿐이며, 실제로는 감속기 내부 마찰 등으로 **효율(η)만큼 손실**되어 실제 출력 토크는 이론값보다 작다.

---

<aside>핵심 정리</aside>

- 감속기는 모터의 고속·저토크를 저속·고토크로 바꾸며, 출력 토크는 모터 토크 × 감속비 × 효율이다
- 감속비만큼 토크가 정확히 증가하는 것은 이론값이며, 실제로는 효율 손실 때문에 그보다 작다
