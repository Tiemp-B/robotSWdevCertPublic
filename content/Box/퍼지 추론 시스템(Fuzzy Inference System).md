# Summary

퍼지 추론 시스템은 "약간 가깝다"처럼 애매한(모호한) 정보를 다루기 위해 퍼지화-규칙베이스-추론엔진-비퍼지화의 4단계로 구성된 추론 체계다.

---

<div class="cues-header">Cues</div>

# Notes

<aside>4단계 구성</aside>

| 단계 | 내용 |
|---|---|
| 퍼지화(Fuzzification) | 정확한(crisp) 입력값을 소속함수로 퍼지 집합(애매한 정도)으로 변환 |
| 규칙베이스(Rule Base) | "IF 거리가 가깝다 THEN 속도를 줄인다" 같은 IF-THEN 규칙 저장 |
| 추론엔진(Inference Engine) | 퍼지화된 입력과 규칙베이스로 퍼지 추론 수행 |
| 비퍼지화(Defuzzification) | 추론 결과(퍼지 집합)를 하나의 명확한 수치로 변환(무게중심법 등) |

<aside>로봇 응용 예시</aside>

이동 로봇이 장애물까지의 거리 정보를 퍼지 규칙("가깝다/보통/멀다")으로 추론해 회피 속도·방향을 결정하면, 전통적인 On/Off 제어보다 부드럽고 안정적으로 장애물을 피할 수 있다.

---

<aside>핵심 정리</aside>

- 퍼지 추론 시스템은 퍼지화-규칙베이스-추론엔진-비퍼지화 4단계로 구성된다
- 애매한 정보를 소속함수로 정량화해 다루는 것이 핵심이다
