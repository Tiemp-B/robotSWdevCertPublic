# Summary

주 액터(Primary Actor)는 목표를 가지고 사용 사례를 시작시키는 액터이고, 보조 액터(Secondary Actor)는 그 목표 달성을 위해 시스템에 도움을 주는 액터다.

---

<div class="cues-header">Cues</div>

# Notes

<aside>주 액터와 보조 액터의 차이</aside>

| 구분 | 주 액터(Primary Actor) | 보조 액터(Secondary Actor) |
|---|---|---|
| 사용 사례 시작 | 시작(개시)시킴 | 시작시키지 않음 |
| 역할 | 목표를 가진 주체 — "누구를 위한 사용 사례인가" | 시스템이 목표 달성을 위해 호출해 정보·결과를 받는 대상 |

"보조 액터는 주 액터와 마찬가지로 사용 사례를 직접 시작시키는 주체다"라는 서술은 오답이다 — 보조 액터는 사용 사례를 시작시키지 않으며, 시스템이 필요할 때 도움을 요청하는 대상이다.

<aside>예시 — 로봇 시스템의 주/보조 액터</aside>

**예시**: 재난 구조 로봇의 "임무 시작" 사용 사례에서, 로봇을 조작하는 "사용자"는 사용 사례를 직접 개시하므로 주 액터이고, 로봇이 임무 수행 중 위치 보정을 위해 조회하는 "원격 관제 서버"는 사용 사례를 시작시키지 않고 도움만 제공하므로 보조 액터다.

---

<aside>핵심 정리</aside>

- 주 액터는 사용 사례를 시작시키는 목표의 주체이며, 보조 액터는 시작시키지 않고 도움만 제공한다
