# Summary

IQR(사분위수 범위)은 데이터를 정렬했을 때 **3사분위수(Q3)와 1사분위수(Q1)의 차이**로, 데이터가 중앙에 얼마나 밀집해 있는지를 나타내며 이상치(outlier) 탐지의 기준으로 널리 쓰인다.

# Notes

<aside>IQR과 이상치 판정 기준</aside>

- $IQR = Q3 - Q1$ (전체 데이터의 중간 50% 구간의 폭)
- 통상 $Q1 - 1.5 \times IQR$보다 작거나 $Q3 + 1.5 \times IQR$보다 큰 값을 이상치로 간주
- 평균·표준편차 기반 방법([[Z-score(표준점수)]])과 달리, 극단값 자체의 영향을 덜 받는다는 장점이 있음(중앙값·사분위수는 극단값에 덜 민감)

<aside>로봇 데이터 로깅에서의 활용</aside>

로봇 센서 로그에서 순간적인 튐값(노이즈, 통신 오류로 인한 이상값)을 걸러낼 때, 데이터 분포가 정규분포를 따르지 않거나 극단값이 섞여 있는 경우 평균 기반 Z-score보다 IQR 기반 탐지가 더 안정적인 경우가 많다.

---

<aside>핵심 정리</aside>

- IQR은 Q3-Q1로 정의되며, $Q1-1.5\times IQR$ ~ $Q3+1.5\times IQR$ 범위를 벗어나면 이상치로 판정한다
