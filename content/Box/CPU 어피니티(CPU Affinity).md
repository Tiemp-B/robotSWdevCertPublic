# Summary

CPU 어피니티(코어 고정)는 특정 프로세스·스레드를 특정 CPU 코어에서만 실행되도록 고정하는 기법으로, 멀티코어 환경에서 캐시 미스와 컨텍스트 스위칭 오버헤드를 줄여 실행 시간을 더 예측 가능하게 만든다.

# Notes

<aside>왜 코어를 고정하는가</aside>

- 스레드가 실행 중 다른 코어로 옮겨 다니면, 그 코어의 캐시에 남아있던 데이터(데이터 지역성)를 다시 채워야 해 **캐시 미스**가 늘어남
- 코어를 고정하면 캐시 지역성이 유지되고, 스케줄러가 어떤 코어에 배정할지 매번 다시 계산하는 오버헤드도 줄어듦
- 실시간 제어 루프처럼 실행 시간이 **예측 가능(deterministic)** 해야 하는 작업에 특히 유리함

<aside>로봇 소프트웨어에서의 활용</aside>

로봇의 실시간 모션 제어 루프를 전용 코어에 고정하고, UI·로깅처럼 실시간성이 낮은 작업은 다른 코어에 맡기면, 비실시간 작업이 실시간 작업의 실행을 방해(간섭)하는 것을 막을 수 있다.

---

<aside>핵심 정리</aside>

- CPU 어피니티는 프로세스·스레드를 특정 코어에 고정해 캐시 미스·컨텍스트 스위칭을 줄이는 기법이다
- 부하 분산이 아니라 실행 시간의 예측 가능성을 높이는 것이 목적이다
