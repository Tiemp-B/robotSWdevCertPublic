# Summary

인증(Authentication)은 시스템에 접근하려는 사용자가 **실제로 그 사람(또는 장치)이 맞는지 신원을 확인**하는 과정으로, 권한을 결정하는 [[인가(Authorization)]]보다 먼저 이루어져야 하는 선행 단계다.

# Notes

<aside>인증의 일반적인 방식</aside>

- 지식 기반: 비밀번호처럼 본인만 알고 있는 정보
- 소유 기반: 보안 토큰, 스마트폰 인증 앱처럼 본인만 가지고 있는 물건
- 생체 기반: 지문, 얼굴 인식처럼 본인의 신체적 특징
- 여러 방식을 함께 요구하는 다중 인증(MFA)은 하나의 방식이 뚫려도 다른 방식으로 추가 방어가 가능해 보안성을 높임

"인증은 사용자가 시스템 내에서 어떤 기능을 사용할 수 있는지 권한 범위를 결정하는 과정이다"라는 서술은 오답이다 — 그것은 [[인가(Authorization)]]의 역할이며, 인증의 핵심은 오히려 **그 사용자가 누구인지(신원)를 확인**하는 것이다.

<aside>Kerberos·JWT와의 관계</aside>

kerberos·[[JWT(JSON Web Token)]] 같은 프로토콜·토큰 방식은 이 인증 과정을 네트워크 환경에서 안전하게 수행하기 위한 구체적인 구현 방법이다.

---

<aside>핵심 정리</aside>

- 인증은 사용자(또는 장치)의 신원을 확인하는 과정이다
- 권한 범위를 결정하는 인가와는 다른 개념이며, 인증이 인가보다 먼저 이루어져야 한다
