# Summary

ControlNet은 실시간 제어 데이터와 일반 정보 데이터를 하나의 네트워크에서 **시간 슬롯을 나눠 결정론적으로** 함께 전송할 수 있도록 설계된 산업용 필드버스다.

# Notes

<aside>ControlNet의 결정론적 전송 방식</aside>

- 네트워크 접근 시간을 미리 정해진 슬롯으로 나누어, 제어 데이터가 언제 전송될지 **예측 가능(결정론적)**하게 보장함
- 같은 네트워크 위에서 시간이 중요한 제어 데이터와, 덜 급한 정보성 데이터(설정값, 로그 등)를 함께 실어 보낼 수 있음
- [[CC-Link]], [[DeviceNet]]과 같은 시대의 산업 자동화 필드버스 계열로, 특히 정밀한 타이밍이 중요한 제어 루프에 쓰임

"ControlNet은 전송 순서가 매번 무작위로 결정되어 지연시간을 예측할 수 없는 네트워크다"라는 서술은 오답이다 — ControlNet의 핵심은 오히려 **시간 슬롯 기반의 결정론적 전송**으로 지연시간을 예측 가능하게 만드는 것이다.

<aside>다른 필드버스와의 관계</aside>

ControlNet은 제어 데이터의 타이밍 결정론성을 중시한다는 점에서 [[EtherCAT]]·[[POWERLINK]] 같은 이더넷 기반 실시간 프로토콜의 목표와 유사하지만, 물리 계층은 이더넷이 아닌 전용 케이블을 사용하는 세대의 기술이다.

---

<aside>핵심 정리</aside>

- ControlNet은 시간 슬롯 기반으로 제어 데이터와 정보 데이터를 결정론적으로 함께 전송하는 필드버스다
- 전송 순서가 무작위가 아니라 예측 가능하다는 점이 핵심이다
