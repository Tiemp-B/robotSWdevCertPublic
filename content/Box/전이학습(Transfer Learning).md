# Summary

전이학습은 하나의 작업(원천 도메인)으로 이미 학습된 모델의 지식을 **다른 관련 작업(목표 도메인)에 재활용**해, 처음부터 학습하는 것보다 적은 데이터·시간으로 새 모델을 학습시키는 기법이다.

# Notes

<aside>전이학습이 효과적인 이유</aside>

- 대량의 데이터로 미리 학습된 모델(예: 일반 이미지 인식 모델)은 이미 유용한 특징(edge, 형태 등)을 추출하는 능력을 갖추고 있음
- 이 모델의 초반부(일반적인 특징 추출 부분)는 그대로 재사용하고, 새 작업에 특화된 마지막 부분만 새로 학습(fine-tuning)하면 훨씬 **적은 데이터·시간**으로도 좋은 성능을 낼 수 있음
- 로봇의 특정 작업에 대한 데이터가 적을 때, 일반적인 대규모 데이터로 학습된 모델을 가져와 전이학습으로 활용하는 것이 효율적

<aside>과적합과의 관계</aside>

데이터가 적은 로봇 작업에서 모델을 처음부터 학습시키면 [[과적합(Overfitting)]]이 발생하기 쉬운데, 전이학습으로 이미 검증된 특징 추출 능력을 재활용하면 적은 데이터로도 과적합을 줄이며 학습할 수 있다.

---

<aside>핵심 정리</aside>

- 전이학습은 다른 작업으로 이미 학습된 모델의 지식을 새 작업에 재활용하는 기법이다
- 처음부터 무작위로 학습시키는 표준 방식과 달리, 적은 데이터로도 효율적인 학습이 가능하다
