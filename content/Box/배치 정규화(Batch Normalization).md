# Summary

배치 정규화(Batch Normalization)는 배치 단위로 은닉층의 값을 정규화해 학습을 안정시키는 기법으로, 가중치 초깃값 의존도를 낮추고 ReLU 같은 비유계 활성화 함수의 수치 불안정성을 완화한다.

# Notes

<aside>배치 정규화의 위치와 역할</aside>

배치 정규화는 보통 선형층과 활성화 함수(ReLU 등) 사이에 배치되어, 한 배치 내 데이터에 대해 은닉층의 값을 정규화한다. 가중치의 초깃값에 크게 의존하지 않고도 활성화 값이 적절히 분포되도록 강제해 학습을 안정시키며, 학습률 선택에 대한 민감도도 낮춘다.

<aside>과적합 방지 기법으로서의 배치 정규화</aside>

배치 정규화는 드롭아웃·L1/L2 정규화와 함께 과적합을 방지하는 대표적 기법 중 하나다. 활성화 함수(ReLU 등) 자체는 비선형성 추가·기울기 소실 완화가 목적이며 과적합 방지 기법으로 분류되지 않는다는 점과 구분해야 한다.

---

<aside>핵심 정리</aside>

- 배치 정규화는 배치 단위로 은닉층 값을 정규화해 학습을 안정시키고 가중치 초깃값 의존도를 낮춘다
- 드롭아웃·L1/L2 정규화와 함께 과적합 방지 기법에 속하며, 활성화 함수 자체와는 목적이 다르다
