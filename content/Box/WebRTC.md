# Summary

WebRTC는 브라우저나 앱 간에 별도의 중계 서버를 거치지 않고 **P2P(peer-to-peer)로 직접 연결**해 저지연으로 영상·음성·데이터를 주고받는 실시간 통신 기술이다.

# Notes

<aside>WebRTC의 P2P 저지연 통신</aside>

- 연결 초기 협상(시그널링)에는 서버가 관여하지만, 실제 미디어(영상·음성) 데이터는 **두 장치가 직접 연결**되어 전송됨 — 중계 서버를 거치지 않아 지연이 최소화됨
- 기반 전송 계층으로 [[UDP]]를 사용해, 신뢰성보다 저지연을 우선함
- NAT·방화벽 환경에서도 P2P 연결을 시도하는 다양한 보조 기술(STUN/TURN 등)을 포함

"WebRTC는 모든 미디어 데이터가 반드시 중앙 서버를 거쳐 중계되는 클라이언트-서버 구조다"라는 서술은 오답이다 — WebRTC의 핵심은 오히려 **서버를 거치지 않는 P2P 직접 연결**로 지연을 최소화하는 것이며, 서버는 초기 연결 협상에만 관여한다.

<aside>로봇 원격제어에서의 활용</aside>

로봇 원격제어 중 카메라 영상을 실시간으로 조작자에게 전달할 때, [[WebSocket]]보다 지연이 더 짧은 WebRTC가 적합하다 — 영상·음성처럼 약간의 데이터 유실보다 지연이 더 치명적인 경우에 WebRTC의 저지연 P2P 구조가 강점을 발휘한다.

---

<aside>핵심 정리</aside>

- WebRTC는 UDP 기반의 P2P 직접 연결로 저지연 영상·음성·데이터 통신을 제공하는 기술이다
- 모든 데이터가 중앙 서버를 거치는 구조가 아니라, 서버는 초기 연결 협상에만 관여한다
