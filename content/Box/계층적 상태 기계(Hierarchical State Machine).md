# Summary

계층적 상태 기계(HSM)는 상태를 중첩(nested) 구조로 조직화해, 여러 하위 상태가 공통으로 처리해야 할 로직을 상위 상태에 한 번만 정의하는 방식으로 상태 폭발(state explosion) 문제를 해결한다.

# Notes

<aside>상태 폭발(State Explosion) 문제</aside>

일반적인(평면형) 상태 기계는 상태 수가 많아질수록, 여러 상태에서 **똑같은 예외 처리 로직이 중복**되기 쉽다(예: "통신 두절" 예외를 모든 상태마다 각각 작성). 이렇게 상태·전이가 기하급수적으로 늘어나 관리가 어려워지는 현상을 상태 폭발이라 한다.

<aside>계층적 상태 기계의 해결 방식</aside>

- 상태를 **부모-자식 관계로 중첩**시켜, 여러 하위 상태가 공유하는 공통 로직을 **부모(상위) 상태에 한 번만** 정의
- 각 하위(자식) 상태는 부모의 로직을 그대로 물려받으면서(행위적 상속), **자신만의 차이점만** 추가로 정의하면 됨
- 예: "이동 중"이라는 부모 상태 아래 "전진"·"회전"·"정지 대기" 하위 상태를 두면, "긴급 정지" 이벤트 처리는 부모에 한 번만 정의해도 모든 하위 상태에서 공통으로 작동함

---

<aside>핵심 정리</aside>

- 계층적 상태 기계는 상태를 중첩 구조로 조직화해 상태 폭발 문제를 해결한다
- 공통 로직은 부모 상태에 한 번만 정의하고, 하위 상태는 이를 물려받으며 차이점만 추가한다
