# Summary

ETL(추출-변환-적재)은 여러 원천에 흩어진 데이터를 **추출(Extract)하고, 분석에 적합한 형태로 변환(Transform)한 뒤, 저장소에 적재(Load)**하는 일련의 데이터 처리 파이프라인이다.

# Notes

<aside>ETL 3단계</aside>

| 단계 | 내용 |
|---|---|
| Extract(추출) | 로봇 로그, 센서 DB, 외부 API 등 서로 다른 원천에서 원본 데이터를 가져옴 |
| Transform(변환) | 형식 통일, 결측치 처리, 단위 변환, 중복 제거 등으로 분석 가능한 형태로 가공 |
| Load(적재) | 가공된 데이터를 [[데이터 웨어하우스(Data Warehouse)]] 등 최종 저장소에 저장 |

<aside>로봇 데이터 관리에서의 위치</aside>

로봇 훈련(학습) 데이터 파이프라인에서는 여러 로봇·세션에서 수집된 원시 센서 로그를 ETL 과정을 거쳐 정제한 뒤, 학습에 바로 사용할 수 있는 데이터셋 형태로 데이터 웨어하우스에 적재하는 흐름이 일반적이다.

---

<aside>핵심 정리</aside>

- ETL은 추출-변환-적재 3단계로 이루어진 데이터 처리 파이프라인이다
- 변환(가공·정제) 단계가 빠지면 ETL이라 할 수 없다
