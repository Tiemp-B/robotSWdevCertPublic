# Summary

SERCOS(Serial Realtime Communication System)는 다축 서보 모터 제어에 특화된 실시간 산업용 필드버스로, 여러 축의 동기화된 정밀 모션 제어를 위해 설계됐다.

# Notes

<aside>SERCOS의 특화 영역</aside>

- 로봇 팔·CNC 공작기계처럼 **여러 축의 서보 모터가 정밀하게 동기화되어 움직여야 하는 다축 모션 제어**에 특화된 통신 규격
- 통신 사이클을 짧고 결정론적으로 유지해, 여러 축 사이의 위치·속도 명령 전달 시점 오차를 최소화
- 초기 버전은 광섬유 기반이었고, 이후 버전(SERCOS III)은 표준 이더넷 기반으로 발전

"SERCOS는 다축 동기화 정밀도보다 대용량 파일 전송 처리량을 극대화하는 데 특화된 프로토콜이다"라는 서술은 오답이다 — SERCOS의 핵심은 오히려 **다축 서보 모터의 정밀한 동기화 실시간 통신**이며, 대용량 파일 전송이 목적이 아니다.

<aside>다른 실시간 필드버스와의 관계</aside>

SERCOS는 [[EtherCAT]]·[[POWERLINK]]·[[Profinet]]과 마찬가지로 산업용 실시간 통신을 목표로 하지만, 특히 다축 모션 제어라는 특화된 응용 분야에서 발전해온 규격이라는 점이 특징이다.

---

<aside>핵심 정리</aside>

- SERCOS는 다축 서보 모터의 정밀 동기화 모션 제어에 특화된 실시간 산업용 필드버스다
- 대용량 파일 전송이 아니라 축 간 정밀 동기화가 목적이다
