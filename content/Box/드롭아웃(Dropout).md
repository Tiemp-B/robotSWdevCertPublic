# Summary

드롭아웃은 신경망 학습 과정에서 **매 학습 단계마다 일부 뉴런을 무작위로 비활성화**해, 모델이 특정 뉴런 조합에 지나치게 의존하지 못하게 함으로써 [[과적합(Overfitting)]]을 줄이는 정규화 기법이다.

# Notes

<aside>드롭아웃의 동작 방식</aside>

- 학습(훈련) 단계마다 정해진 확률로 일부 뉴런의 출력을 무작위로 0으로 만들어(비활성화) 그 학습 단계에서 제외함
- 매번 다른 뉴런 조합이 비활성화되므로, 모델이 특정 뉴런 몇 개에만 의존하는 것이 아니라 **더 견고하고 일반화된 특징**을 학습하게 됨
- 실제 추론(테스트) 단계에서는 드롭아웃을 적용하지 않고 전체 뉴런을 사용함(대신 출력 크기를 보정)

"드롭아웃은 모델의 학습 속도를 높이기 위해 신경망의 뉴런 수를 영구적으로 줄이는 기법이다"라는 서술은 오답이다 — 드롭아웃의 핵심은 오히려 **학습 단계마다 일시적으로 무작위 뉴런을 비활성화**하는 것이며, 뉴런을 영구적으로 제거하는 것이 아니다(추론 시에는 전체 뉴런을 사용).

<aside>과적합 방지에서의 위치</aside>

드롭아웃은 [[과적합(Overfitting)]]을 줄이는 여러 정규화 기법 중 하나이며, 학습 데이터에 대한 성능만 계속 오르고 검증 데이터 성능이 떨어지는 과적합 신호가 보일 때 적용을 고려한다.

---

<aside>핵심 정리</aside>

- 드롭아웃은 학습 단계마다 일부 뉴런을 무작위로 비활성화해 과적합을 줄이는 정규화 기법이다
- 뉴런을 영구적으로 제거하는 것이 아니라, 학습 중에만 일시적으로 비활성화한다
