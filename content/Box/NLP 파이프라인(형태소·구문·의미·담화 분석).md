# Summary

자연어처리(NLP) 파이프라인은 **형태소 분석 → 구문 분석 → 의미 분석 → 담화 분석**의 4단계로 이루어지며, 음성 인터페이스에서는 음성인식(STT)과 음성합성(TTS) 사이의 중간 처리 블록에 해당한다.

# Notes

<aside>NLP 4단계</aside>

| 단계 | 내용 |
|---|---|
| ① 형태소 분석 | 문장을 최소 의미 단위(형태소)로 분리하고 품사를 태깅 |
| ② 구문 분석 | 문장 구성요소를 분해해 위계관계·구조를 파악 |
| ③ 의미 분석 | 문장의 뜻을 파악(문법은 맞지만 의미가 틀린 문장도 검출) |
| ④ 담화 분석 | 전체 문맥과 연결해 정확한 의미를 분석 |

"음성 인터페이스의 NLP 처리에서 의미 분석은 형태소 분석보다 먼저 이루어진다"라는 서술은 오답이다 — 더 작은 단위(형태소)를 먼저 분석한 뒤 점차 큰 단위(문맥)로 확장하는 순서(형태소→구문→의미→담화)를 따른다.

<aside>형태소 분석기의 기능</aside>

형태소 분석기는 **어절 분리**(음절 단위로 끊어 조사 등을 붙여 하나의 구·절 단위로 구성)와 **품사 태깅**(체언·용언·조사·어미 등으로 분류)을 수행한다. 예: "가방에 들어가신다" → 가방/명사 + 에/조사 + 들어가/동사 + 시/어미 + ㄴ다/어미.

<aside>음성 인터페이스 전체 흐름에서의 위치</aside>

음성 인터페이스는 **음성인식(STT) → NLP(4단계) → 의도파악·대화관리 → 음성합성(TTS)** 순으로 구성되며, NLP 파이프라인은 STT로 얻은 텍스트를 해석해 의도파악·대화관리 단계로 넘겨주는 중간 처리 블록이다.

---

<aside>핵심 정리</aside>

- NLP 파이프라인은 형태소분석→구문분석→의미분석→담화분석 순으로 진행된다
- 형태소 분석기는 어절 분리와 품사 태깅을 수행하며, 음성 인터페이스에서는 STT와 TTS 사이의 중간 처리 블록이다
