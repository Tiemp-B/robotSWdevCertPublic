# Summary

엔드이펙터는 로봇 팔의 **말단(끝)에 부착되어 실제 작업(파지, 용접, 도장 등)을 수행하는 도구**로, 로봇 팔 자체가 위치를 옮겨주는 역할이라면 엔드이펙터는 그 목적지에서 실제 작업을 실행하는 부분이다.

# Notes

<aside>엔드이펙터의 역할</aside>

- 그리퍼(물체를 집는 손), 용접 토치, 도장 노즐, 흡착 패드 등 작업 목적에 맞는 다양한 형태로 교체·장착 가능
- 로봇 팔의 나머지 관절들이 엔드이펙터를 원하는 위치·자세로 옮겨주면, 엔드이펙터가 실제 작업(잡기, 용접 등)을 수행함
- 로봇 좌표계에서 흔히 "엔드이펙터(툴) 좌표계"를 별도로 두어, 작업 지시를 엔드이펙터 기준으로 표현하기도 함

<aside>순기구학과의 관계</aside>

[[DH 파라미터(Denavit-Hartenberg Parameters)]]를 이용한 순기구학 계산의 최종 목표는 결국 "엔드이펙터가 월드 좌표계 기준으로 어디에, 어떤 자세로 있는가"를 구하는 것이다.

---

<aside>핵심 정리</aside>

- 엔드이펙터는 로봇 팔 말단에서 실제 작업(파지, 용접 등)을 수행하는 물리적 도구다
- 관절 움직임을 계산하는 소프트웨어가 아니라, 하드웨어 구성 요소를 가리킨다
