# Summary

정상상태오차(Steady-State Error)는 시스템이 **충분히 시간이 지나 안정된 이후에도 목표값과 실제 출력 사이에 남아있는 오차**로, 시간이 지나도 사라지지 않고 계속 남는 오차를 가리킨다.

# Notes

<aside>정상상태오차와 PID의 관계</aside>

- [[PID 제어]]에서 비례(P) 항만 사용하면, 오차가 어느 정도 줄어들어도 완전히 0이 되지는 않고 일정한 오차가 남는 경우가 많음(정상상태오차)
- 이 남은 오차를 없애려면 **적분(I) 항**을 추가해, 오차가 누적된 정도를 반영해 점진적으로 출력을 조정해야 함
- 정상상태오차는 과도 응답(상승시간, 오버슈트 등)과는 다른, "충분히 시간이 지난 뒤"의 최종 오차를 다루는 지표

"정상상태오차를 없애려면 비례(P) 게인을 무한히 높이는 것이 근본적인 해법이다"라는 서술은 오답이다 — 정상상태오차를 근본적으로 없애는 것은 오히려 **적분(I) 항**의 역할이며, 비례 게인만 높이면 오버슈트·진동이 커질 뿐 정상상태오차가 완전히 사라지지 않는 경우가 많다.

<aside>다른 응답 특성 지표와의 구분</aside>

[[상승시간(Rise Time)]]·[[오버슈트(Overshoot)]]·[[정착시간(Settling Time)]]이 목표값에 도달하는 "과정"을 다룬다면, 정상상태오차는 충분히 시간이 지난 뒤의 "최종 결과"를 다룬다는 점에서 구분된다.

---

<aside>핵심 정리</aside>

- 정상상태오차는 시스템이 안정된 이후에도 남아있는 목표값과의 오차다
- 비례 게인이 아니라 적분(I) 항으로 없애는 것이 정석이다
