# Summary

PTP(IEEE 1588, Precision Time Protocol)는 **하드웨어 타임스탬핑**을 이용해 [[NTP(Network Time Protocol)|NTP]]보다 훨씬 정밀한(마이크로초 이하) 시간 동기화를 제공하는 프로토콜로, 여러 로봇·드라이브가 동기적으로 움직여야 하는 산업 자동화·모션 제어에 쓰인다.

# Notes

<aside>PTP가 NTP보다 정밀한 이유 — 하드웨어 타임스탬핑</aside>

- NTP는 소프트웨어 계층에서 시각을 처리해 밀리초 수준의 정확도를 가지는 반면, PTP는 메시지가 **네트워크 인터페이스 카드·스위치를 드나드는 순간을 하드웨어 자체가 타임스탬프**로 기록함
- 이 덕분에 운영체제 스케줄링 지연·소프트웨어 처리 지연의 영향을 받지 않아, 패킷 지연을 정밀하게 계산·보정할 수 있고 지터의 영향도 줄어듦
- 적절한 그랜드마스터·스위치 지원이 갖춰지면 마이크로초 수준의 정확도에 도달함

<aside>로봇·산업 자동화에서의 활용</aside>

자동화 라인의 모션 제어처럼 여러 대의 로봇·구동장치·분산 I/O가 동기적으로 움직여야 하는 경우, PTP로 각 장치의 내부 시계를 통일된 타임스탬프 기준으로 맞춘다. 일반적인 로그 시간 정렬·센서 데이터 융합처럼 밀리초 수준으로 충분한 경우는 NTP로도 충분하지만, 정밀한 모션 동기화에는 PTP가 필요하다.

---

<aside>핵심 정리</aside>

- PTP는 하드웨어 타임스탬핑으로 마이크로초 이하 정밀도를 제공하는 시간 동기화 프로토콜이다
- NTP(밀리초급, 소프트웨어 기반)보다 정밀하며, 정밀 모션 제어가 필요한 산업 자동화·로봇에 쓰인다
