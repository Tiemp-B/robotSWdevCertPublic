# Summary

OpenCV(Open Source Computer Vision Library)는 영상처리·객체검출/추적·3차원 비전·머신러닝(DNN 포함)까지 2,500개 이상의 알고리즘을 제공하는 오픈소스 컴퓨터 비전 라이브러리다.

# Notes

<aside>주요 기능</aside>

| 기능 영역 | 내용 |
|---|---|
| 영상처리 | 필터링, 변환, 화질 개선 |
| 객체 검출·추적 | 실시간 객체 검출, 추적, 얼굴/제스처 인식 |
| 3차원 비전 | 카메라 보정, 스테레오 비전 |
| 머신러닝 | kNN·SVM 등 전통 알고리즘, DNN(딥러닝) 모델 실행 기능도 제공 |

<aside>로봇 분야 활용</aside>

컨베이어 벨트 위 제품을 실시간으로 추적해 로봇 팔의 픽업 타이밍을 정확히 계산하거나, 자율주행 로봇이 저장된 참조 이미지로 환경을 매핑해 현재 위치를 파악하고 경로를 계획하는 데 활용된다.

---

<aside>핵심 정리</aside>

- OpenCV는 영상처리·객체검출추적·3차원비전·머신러닝(DNN 포함)을 아우르는 오픈소스 비전 라이브러리다
- 로봇 분야에서는 실시간 객체 추적, 환경 매핑·위치추정·경로계획 등에 활용된다
