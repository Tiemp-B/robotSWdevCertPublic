# Summary

센서 데이터 융합은 여러 센서의 측정값을 결합해, **개별 센서 하나만으로는 얻을 수 없는 더 정확하고 신뢰성 있는 정보**를 만들어내는 기법이다.

---

<div class="cues-header">Cues</div>

# Notes

<aside>센서 융합이 필요한 이유</aside>

- 각 센서는 저마다의 한계(노이즈, 특정 조건에서의 오차, 측정 범위 제약)를 가짐 — 예: 가속도계는 중력과 실제 가속도를 혼동, 자이로스코프는 시간에 따라 오차가 누적(드리프트)
- 서로 다른 특성을 가진 센서를 결합하면, **한 센서의 약점을 다른 센서가 보완**해 더 정확하고 안정적인 추정값을 얻을 수 있음
- [[칼만 필터(Kalman Filter)]] 같은 알고리즘이 여러 센서 측정을 확률적으로 결합하는 대표적인 융합 기법으로 쓰임

<aside>IMU와의 관계</aside>

[[IMU(Inertial Measurement Unit)]] 내부에서 가속도계·자이로스코프(·지자기 센서)의 측정값을 결합해 자세를 추정하는 것이 센서 데이터 융합의 대표적인 예다.

---

<aside>핵심 정리</aside>

- 센서 데이터 융합은 여러 센서의 측정값을 결합해 개별 센서보다 정확하고 신뢰성 있는 정보를 얻는 기법이다
- 하나의 센서만 선택하고 나머지를 무시하는 것이 아니라, 여러 정보를 함께 결합하는 것이 핵심이다
