# Summary

Isolation Forest는 정상 패턴을 학습하는 대신 **이상치 자체를 무작위 분할로 빠르게 고립(isolate)** 시키는 원리로 작동하는 이상치 탐지 알고리즘이다.

# Notes

<aside>고립(Isolation)의 원리</aside>

- 데이터를 무작위로 나누는(랜덤하게 속성·기준값 선택) 여러 개의 트리(포레스트)를 구성
- **이상치는 드물고 정상 데이터와 특성이 크게 다르므로**, 적은 횟수의 분할만으로도 다른 데이터와 빠르게 분리(고립)됨
- 반대로 **정상 데이터는 서로 비슷한 값이 많아**, 고립되기까지 훨씬 더 많은 분할이 필요함

<aside>이상치 점수의 계산</aside>

각 데이터가 고립되기까지 거친 **분할 경로의 길이(path length)** 를 여러 트리에 대해 평균 낸 값을 이상치 점수로 사용한다. 경로가 **짧을수록** 적은 분할만으로 고립됐다는 뜻이므로 이상치일 가능성이 높다고 판단한다.

---

<aside>핵심 정리</aside>

- Isolation Forest는 무작위 분할로 데이터를 고립시키고, 고립까지 걸린 경로 길이로 이상치를 판단한다
- 경로가 짧을수록(적은 분할로 고립될수록) 이상치일 가능성이 높다
- 정상 패턴을 먼저 학습하는 방식이 아니라, 이상치가 고립되기 쉽다는 성질을 직접 활용하는 방식이다
