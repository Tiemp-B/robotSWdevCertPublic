# Summary

게임화(Gamification)는 점수·레벨·보상 같은 **게임적 요소를 게임이 아닌 콘텐츠(교육, 로봇 콘텐츠 등)에 적용**해, 사용자의 참여도와 몰입도를 높이는 콘텐츠 설계 기법이다.

# Notes

<aside>게임화의 핵심 요소</aside>

- 점수(포인트), 레벨업, 배지·업적, 순위표(리더보드) 등 게임에서 흔히 쓰이는 동기 부여 장치를 활용
- 목표는 게임 자체를 만드는 것이 아니라, **비게임 콘텐츠에 대한 사용자의 몰입·지속적 참여**를 유도하는 것
- 로봇 콘텐츠(교육용 로봇, 재활 로봇 등)에서 사용자가 반복 과제를 지루해하지 않고 계속 참여하도록 만드는 데 활용됨

<aside>로봇 콘텐츠 저작에서의 활용</aside>

로봇 콘텐츠 저작 소프트웨어에서 시나리오를 기획할 때, 사용자가 반복적인 로봇 조작 과제를 지속하도록 게임화 요소(단계별 보상 등)를 설계에 포함시키는 경우가 많다.

---

<aside>핵심 정리</aside>

- 게임화는 게임적 요소를 비게임 콘텐츠에 적용해 참여도·몰입도를 높이는 기법이다
