# Summary

유니버설 디자인은 장애·연령·숙련도와 무관하게 **가능한 한 모든 사용자가 공통으로 쓸 수 있도록** 설계하는 원칙으로, Ron Mace가 1997년 제시한 7가지 원칙으로 정리된다.

# Notes

<aside>유니버설 디자인 7원칙</aside>

| 원칙 | 내용 |
|---|---|
| 공평한 사용(Equitable Use) | 다양한 능력의 사용자에게 유용하고 시장성 있게 설계 |
| 사용의 유연성(Flexibility in Use) | 폭넓은 개인 선호·능력을 수용 |
| 간단하고 직관적인 사용(Simple and Intuitive Use) | 경험·지식·언어 능력과 무관하게 이해하기 쉽게 설계 |
| 인지 가능한 정보(Perceptible Information) | 주변 조건이나 사용자의 감각 능력과 무관하게 필요한 정보를 효과적으로 전달 |
| 오류에 대한 관용(Tolerance for Error) | 실수·의도치 않은 행동의 위험과 악영향을 최소화 |
| 적은 신체적 노력(Low Physical Effort) | 효율적이고 편안하게, 피로를 최소화하며 사용 가능 |
| 접근과 사용을 위한 크기와 공간(Size and Space for Approach and Use) | 사용자의 체격·자세·이동성과 무관하게 접근·조작 가능한 크기·공간 제공 |

<aside>사용자 그룹별 차별화 설계와의 관계</aside>

특정 사용자 그룹(고령자·비전문가 등)마다 별도의 UI를 만드는 "그룹별 차별화" 접근과 달리, 유니버설 디자인은 **처음부터 하나의 설계로 최대한 많은 사용자를 포괄**하려는 철학이다. 둘은 상호 배타적이지 않으며, 함께 적용해 설계 품질을 높일 수 있다.

"유니버설 디자인은 장애가 있는 사용자만을 위한 별도의 특수 설계를 의미한다"라는 서술은 오답이다 — 유니버설 디자인의 핵심은 오히려 **장애 유무와 무관하게 모든 사용자가 함께 쓸 수 있는 공통 설계**를 지향한다는 점이다.

---

<aside>핵심 정리</aside>

- 유니버설 디자인은 모든 사용자가 공통으로 쓸 수 있게 설계하는 철학이며, 7원칙(공평한 사용/유연성/간단함/인지가능정보/오류관용/적은노력/적절한크기와공간)으로 정리된다
- 특정 그룹만을 위한 특수 설계가 아니라, 처음부터 폭넓은 사용자를 포괄하는 설계를 지향한다
