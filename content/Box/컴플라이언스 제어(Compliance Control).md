# Summary

컴플라이언스 제어는 로봇 관절·엔드이펙터가 외부에서 힘을 받았을 때 **뻣뻣하게 버티지 않고 유연하게(순응적으로) 반응**하도록 하는 제어 방식으로, 사람·환경과 접촉하는 작업에서 안전성과 적응성을 높인다.

# Notes

<aside>컴플라이언스 제어의 핵심 아이디어</aside>

- 위치만 정확히 맞추려는 순수 위치 제어는 예상치 못한 접촉(장애물, 사람 등)에도 계속 힘을 가해 위험할 수 있음
- 컴플라이언스 제어는 마치 스프링·댐퍼처럼, 외부 힘에 비례해 위치를 살짝 양보하도록 제어함으로써 **접촉 시 충격·과도한 힘을 완화**함
- 협동로봇이 사람과 함께 작업하거나, 정밀한 조립 작업에서 약간의 위치 오차를 유연하게 흡수해야 할 때 유용함

"컴플라이언스 제어의 목표는 외부에서 어떤 힘이 가해지더라도 로봇이 목표 위치를 한 치의 오차 없이 정확히 유지하는 것이다"라는 서술은 오답이다 — 그것은 오히려 순수 위치 제어의 목표에 가까우며, 컴플라이언스 제어의 핵심은 정반대로 **외부 힘에 유연하게 반응해 위치를 어느 정도 양보**하는 것이다.

<aside>힘 제어와의 관계</aside>

컴플라이언스 제어는 힘 제어(임피던스 제어 등)의 한 형태로, 로봇이 위치만 추종하는 것이 아니라 힘-위치 관계를 조절해 순응적으로 동작하게 만드는 접근이다.

---

<aside>핵심 정리</aside>

- 컴플라이언스 제어는 외부 힘에 유연하게 반응해 위치를 양보하는 순응적 제어 방식이다
- 어떤 힘에도 위치를 정확히 고수하는 순수 위치 제어와는 반대되는 목표를 갖는다
