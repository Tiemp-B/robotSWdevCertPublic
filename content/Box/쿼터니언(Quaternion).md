# Summary

쿼터니언은 실수 4개(w, x, y, z)로 3차원 회전을 표현하는 방법으로, 오일러 각과 달리 **짐벌락이 없고** 표현이 연속적이라 로봇 제어기에서 자세의 저장·보간에 흔히 쓰인다.

# Notes

<aside>쿼터니언의 구조</aside>

쿼터니언은 스칼라부(w) 하나와 벡터부(x, y, z) 세 개, 총 4개의 실수로 구성된다. 회전을 표현할 때는 길이가 1인 **단위 쿼터니언**만 사용하는데, 4개의 수에 "길이가 1"이라는 제약이 하나 걸리므로 실제 자유도는 회전의 자유도인 3과 정확히 일치한다.

<aside>오일러 각 대비 장점</aside>

- **짐벌락이 없음** — 오일러 각처럼 특정 각도에서 자유도를 잃는 특이점이 존재하지 않음
- **연속적인 보간** — 두 자세 사이를 매끄럽게 보간하는 SLERP(구면 선형 보간, Spherical Linear Interpolation)에 적합
- 삼각함수 없이 대수 연산만으로 회전을 합성할 수 있어 계산이 간단함

"쿼터니언은 오일러 각과 마찬가지로 특정 각도 조합에서 자유도를 잃는 짐벌락 문제가 발생한다"라는 서술은 오답이다 — 짐벌락은 **오일러 각**의 한계이며, 쿼터니언은 이 문제를 피하기 위한 대안 표현법이다.

<aside>실무에서의 역할 분담</aside>

세 표현법은 서로 다른 목적에 맞게 함께 쓰이는 경우가 많다. **저장·보간은 쿼터니언**, 좌표 변환 등 실제 **계산은 회전행렬**, 사람이 값을 읽고 이해하는 **표시용은 오일러 각**으로 나누어 사용하는 것이 로봇 제어 소프트웨어의 일반적인 방식이다.

---

<aside>핵심 정리</aside>

- 쿼터니언은 (w, x, y, z) 4개 실수로 3차원 회전을 표현하며, 단위 쿼터니언만 회전에 사용한다
- 오일러 각과 달리 짐벌락이 없고 SLERP로 매끄러운 보간이 가능해, 로봇 소프트웨어에서 자세의 저장·보간에 주로 쓰인다
