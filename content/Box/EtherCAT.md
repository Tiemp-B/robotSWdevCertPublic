# Summary

EtherCAT은 표준 이더넷 물리 계층을 사용하면서도, 각 슬레이브 장치가 프레임이 지나갈 때 **즉시(on-the-fly) 자신의 데이터를 읽고 쓰는 방식**으로 마이크로초 단위의 초저지연·결정론적 통신을 구현하는 실시간 산업용 필드버스다.

# Notes

<aside>EtherCAT의 On-the-fly 처리</aside>

- 전통적인 이더넷 기반 통신은 각 슬레이브가 프레임을 완전히 수신 → 처리 → 재전송하는 과정에서 지연이 누적됨
- EtherCAT은 마스터가 하나의 프레임을 모든 슬레이브가 연결된 링을 따라 흘려보내면, 각 슬레이브가 **프레임이 통과하는 순간에 자신에게 해당하는 부분만 즉시 읽고 씀**(하드웨어 수준 처리) — 별도의 수신·처리·재전송 지연이 거의 없음
- 이 덕분에 수십~수백 개의 슬레이브를 연결해도 전체 통신 주기를 마이크로초 단위로 유지 가능

<aside>다른 실시간 이더넷 프로토콜과의 관계</aside>

EtherCAT, [[Profinet]], [[POWERLINK]]는 모두 표준 이더넷 물리 계층 위에서 실시간성을 확보하려는 접근이지만, 구체적인 방식(on-the-fly 처리, 시간 슬롯 분할 등)이 서로 다르다. 로봇 관절 다축 서보 제어처럼 매우 짧은 통신 주기가 필요한 경우 EtherCAT이 특히 많이 채택된다.

<aside>분산 클록(Distributed Clock)</aside>

On-the-fly 처리(프레임 전달 지연, 슬레이브당 1µs 미만)와는 별개의 개념으로, **다축 동기 제어를 위해 전체 슬레이브의 로컬 클록을 정밀하게 맞추는 기능**이다. 분산 클록을 지원하는 첫 번째 슬레이브가 기준 클록 역할을 하고, 마스터가 주기적으로 각 슬레이브의 시간 오프셋·드리프트를 측정·보정해 슬레이브 간 동기 정밀도를 수백 ns~1µs 이내로 유지한다. 여러 축의 모터가 정확히 같은 순간에 움직여야 하는 다축 서보 제어에서 핵심적인 기능이다.

---

<aside>핵심 정리</aside>

- EtherCAT은 이더넷 프레임이 지나가는 순간 각 슬레이브가 즉시 읽고 쓰는(on-the-fly) 방식으로 초저지연 실시간 통신을 구현한다 — 완전 수신 후 처리·재전송하는 순차 방식이 아니다
- **분산 클록(Distributed Clock)**은 on-the-fly 전달 지연과는 별개로, 전체 슬레이브의 클록을 동기화해 다축 제어의 정밀 타이밍을 보장하는 기능이다
