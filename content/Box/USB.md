# Summary

USB는 PC와 주변장치를 연결하는 범용 직렬 버스 표준으로, 데이터 전송뿐 아니라 전원 공급까지 하나의 케이블로 처리하며 버전이 올라갈수록 속도가 빨라지되 **하위 호환성을 유지**한다.

# Notes

<aside>USB의 특징</aside>

- 플러그 앤 플레이(연결하면 자동 인식)를 지원해 별도의 복잡한 설정 없이 장치를 연결할 수 있음
- 데이터 선과 전원 선을 함께 제공해, 별도의 전원 어댑터 없이도 장치에 전력을 공급 가능(USB 전원 공급)
- USB 3.0 등 신버전은 구버전(USB 2.0 등) 포트·케이블과도 동작하는 **하위 호환성**을 유지하도록 설계됨

"USB 3.0은 이전 버전인 USB 2.0 장치나 포트와는 전혀 호환되지 않는 완전히 새로운 규격이다"라는 서술은 오답이다 — USB의 핵심 설계 원칙 중 하나가 오히려 **하위 호환성 유지**이며, USB 3.0 장치도 USB 2.0 포트에서 (속도는 낮아지지만) 동작한다.

<aside>다른 근거리 유선 통신과의 비교</aside>

USB는 PC-주변장치 간 범용 연결에 최적화된 반면, [[I2C]]·[[SPI]]는 보드 내부에서 MCU와 센서를 잇는 저수준 통신에 최적화되어 있어 용도 자체가 다르다.

---

<aside>핵심 정리</aside>

- USB는 데이터와 전원을 함께 제공하는 범용 직렬 버스 표준이다
- 신버전도 구버전과 호환되는 하위 호환성을 유지하도록 설계된다
