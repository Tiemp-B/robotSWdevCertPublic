# Summary

등가 분할은 입력값의 범위를 **같은 방식으로 처리될 것으로 예상되는 몇 개의 그룹(유효/무효 클래스)으로 나눠**, 각 그룹에서 대표값 하나씩만 테스트해도 그 그룹 전체를 검증한 것으로 간주하는 테스트 설계 기법이다.

# Notes

<aside>등가 분할의 논리</aside>

- 입력 범위 전체를 하나하나 다 테스트하는 것은 비현실적이므로, **같은 결과가 나올 것으로 예상되는 값들을 하나의 클래스(그룹)로 묶음**
- 유효한 입력 클래스(정상 처리되어야 함)와 무효한 입력 클래스(오류로 처리되어야 함)로 나누고, 각 클래스에서 대표값 하나씩만 선택해 테스트
- 대표값 하나가 통과하면 같은 클래스에 속한 다른 값들도 동일하게 처리될 것이라고 가정

"등가 분할은 입력 범위의 경계(최소값·최대값 부근)에 있는 값들을 집중적으로 테스트하는 기법이다"라는 서술은 오답이다 — 경계 부근을 집중적으로 테스트하는 것은 [[경계값 분석(Boundary Value Analysis)]]의 특징이며, 등가 분할의 핵심은 오히려 **입력을 같은 결과가 예상되는 그룹으로 나눠 그룹당 대표값만 테스트**하는 것이다.

<aside>경계값 분석과의 관계</aside>

등가 분할로 입력을 유효/무효 클래스로 나눈 뒤, 그 클래스들의 경계 지점을 [[경계값 분석(Boundary Value Analysis)]]으로 세밀하게 테스트하는 식으로 두 기법을 함께 적용하는 것이 일반적인 테스트 케이스 설계 절차다.

---

<aside>핵심 정리</aside>

- 등가 분할은 입력을 같은 결과가 예상되는 그룹으로 나눠 그룹당 대표값만 테스트하는 기법이다
- 경계 부근 집중 테스트는 등가 분할이 아니라 경계값 분석의 특징이다
