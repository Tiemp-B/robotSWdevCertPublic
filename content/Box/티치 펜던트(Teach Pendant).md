# Summary

티치 펜던트는 작업자가 로봇을 직접 손으로 조작해 원하는 위치·동작을 **하나씩 실제로 움직여가며 가르치는(교시)** 휴대용 입력 장치로, 이렇게 기록된 동작을 로봇이 이후 그대로 재생하는 교시형 프로그래밍의 핵심 도구다.

# Notes

<aside>교시 프로그래밍과 오프라인 프로그래밍의 차이</aside>

- 교시(Teach) 프로그래밍: 티치 펜던트로 로봇을 실제로 원하는 위치까지 움직인 뒤 그 지점을 기록 — 실제 로봇과 작업 환경이 있어야 함
- 오프라인 프로그래밍: 실제 로봇 없이 시뮬레이션 소프트웨어상에서 미리 경로·동작을 설계한 뒤 로봇에 전송 — 실제 로봇의 가동 중단 없이 프로그래밍 가능
- 티치 펜던트는 전자(교시 프로그래밍) 방식의 대표적인 도구이며, 정밀한 위치를 직접 눈으로 확인하며 가르칠 수 있다는 장점이 있음

"티치 펜던트는 실제 로봇 없이 시뮬레이션 소프트웨어만으로 로봇의 동작을 미리 설계하는 오프라인 프로그래밍 도구다"라는 서술은 오답이다 — 티치 펜던트의 핵심은 오히려 **실제 로봇을 직접 움직여가며 동작을 가르치는** 교시 프로그래밍 도구라는 점이며, 오프라인 프로그래밍과는 반대되는 접근이다.

<aside>로봇 모션 기초와의 관계</aside>

티치 펜던트로 기록된 여러 지점(경유점) 사이의 실제 움직임은 [[보간법(Interpolation)]]을 통해 부드러운 궤적으로 채워진다.

---

<aside>핵심 정리</aside>

- 티치 펜던트는 작업자가 로봇을 직접 움직여 동작을 가르치는 교시 프로그래밍용 입력 장치다
- 실제 로봇 없이 미리 설계하는 오프라인 프로그래밍과는 반대되는 방식이다
