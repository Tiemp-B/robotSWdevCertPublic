# Summary

HAL(Hardware Abstraction Layer)은 서로 다른 종류의 하드웨어를 **비슷하게 보이도록 감싸는** 소프트웨어 계층으로, 상위 소프트웨어가 하드웨어 종류가 바뀌어도 그대로 동작할 수 있게 한다.

# Notes

<aside>HAL과 디바이스 드라이버의 차이</aside>

- **디바이스 드라이버**는 특정 장치 하나(예: 특정 모델의 모터 컨트롤러)에 특화되어 그 장치와 직접 통신함
- **HAL**은 그보다 더 일반적인 수준에서, 여러 하드웨어의 차이를 흡수해 **공통 인터페이스**로 제공함 — 디바이스 드라이버가 HAL을 이용해 자신의 구조를 단순화하는 경우도 많음
- 커널(또는 상위 코드) 대부분이 하드웨어가 바뀌어도 수정 없이 그대로 동작할 수 있게 하는 것이 HAL의 핵심 목적

<aside>로봇 소프트웨어에서의 의미</aside>

로봇의 모터·센서가 다른 제품으로 교체되어도, HAL이 하드웨어 차이를 감춘 공통 인터페이스를 유지한다면 상위 미들웨어·애플리케이션 코드를 거의 수정하지 않고도 그대로 동작시킬 수 있다.

---

<aside>핵심 정리</aside>

- HAL은 여러 종류의 하드웨어를 공통 인터페이스로 추상화하는 소프트웨어 계층이다
- 특정 장치 하나에 특화된 디바이스 드라이버보다 더 일반적인 수준에서 하드웨어 차이를 흡수한다
