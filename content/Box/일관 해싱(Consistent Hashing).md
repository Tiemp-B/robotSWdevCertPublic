# Summary

일관 해싱은 해시 값의 범위를 원형(ring) 구조로 배치해 샤드를 배정하는 방식으로, [[샤딩(Sharding)|샤딩]]에서 서버가 추가·제거될 때 재배치되는 데이터의 양을 최소화한다.

# Notes

<aside>단순 해시 분배의 문제</aside>

`해시값 % 샤드수`처럼 단순하게 나누면 샤드 수 자체가 바뀔 때(서버 추가·제거) 나머지 연산 결과가 거의 다 바뀌어, **대부분의 데이터가 다른 샤드로 재배치**돼야 하는 큰 비용이 발생한다.

<aside>일관 해싱의 동작</aside>

- 해시 값이 가질 수 있는 전체 범위를 하나의 **원형(ring)** 으로 간주하고, 각 샤드(서버)를 이 원 위의 특정 지점에 배치
- 데이터는 자신의 해시값에서 원을 따라 이동해 처음 만나는 샤드에 저장됨
- 샤드가 추가·제거되면 그 **인접 구간에 속한 데이터만** 재배치되면 되고, 나머지 샤드의 데이터는 그대로 유지됨 — 전체 재배치보다 이동량이 훨씬 적음
- 해시 값이 원 전체에 고르게 흩어지므로, 특정 샤드에 데이터가 몰리는 **핫스팟(hot spot)** 문제도 줄어듦

---

<aside>핵심 정리</aside>

- 단순 나머지 연산 기반 샤딩은 샤드 수 변경 시 대부분의 데이터를 재배치해야 하는 문제가 있다
- 일관 해싱은 해시 공간을 원형으로 배치해, 샤드 변경 시 인접 구간 데이터만 재배치하면 되고 핫스팟도 줄여준다
