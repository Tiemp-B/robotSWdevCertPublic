# Summary

휴리스틱 평가는 UX 전문가가 **정해진 평가 원칙(휴리스틱) 목록에 따라 화면을 검토**해 사용성 문제를 찾아내는 방법으로, 실제 사용자 없이도 개발 초기에 빠르게 문제를 발견할 수 있다.

# Notes

<aside>휴리스틱 평가의 방식</aside>

- "시스템 상태의 가시성", "일관성과 표준", "오류 예방" 같은 잘 알려진 사용성 원칙(휴리스틱) 목록을 기준으로 전문가가 화면을 하나씩 검토
- 실제 사용자를 모집·관찰할 필요가 없어 [[사용성 테스트(Usability Testing)]]보다 빠르고 저렴하게 수행 가능
- 다만 전문가의 경험에 의존하므로, 실제 사용자가 겪는 예상치 못한 문제까지는 발견하지 못할 수 있다는 한계가 있음

<aside>사용성 테스트와의 관계</aside>

두 방법은 상호 보완적으로 쓰인다 — 개발 초기에는 비용이 적은 휴리스틱 평가로 명백한 문제를 빠르게 걸러내고, 이후 [[사용성 테스트(Usability Testing)]]로 실제 사용자 관점의 문제를 추가로 검증하는 순서가 일반적이다.

---

<aside>핵심 정리</aside>

- 휴리스틱 평가는 전문가가 정해진 사용성 원칙에 따라 화면을 검토하는 평가 방법이다
- 실제 사용자를 관찰하는 사용성 테스트와는 다른, 전문가 중심의 방법이다
