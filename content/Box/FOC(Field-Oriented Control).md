# Summary

FOC(Field-Oriented Control, 자속 벡터 제어)는 모터의 3상 전류를 **회전 자기장 기준의 두 축(토크 성분·자속 성분) 벡터로 좌표 변환**해, 마치 직류(DC) 모터처럼 토크를 독립적으로 정밀 제어하는 기법이다.

# Notes

<aside>FOC의 핵심 아이디어</aside>

- 교류(AC) 모터나 [[BLDC 모터]]의 3상 전류는 그 자체로는 토크와 자속이 뒤섞여 있어 직접 제어하기 까다로움
- FOC는 좌표 변환(Clarke/Park 변환)을 통해 이 전류를 **토크를 만드는 성분(q축)과 자속을 만드는 성분(d축)**으로 분리해, 각 성분을 독립적으로 제어함
- 이렇게 분리하면 브러시 DC 모터처럼 토크를 원하는 대로 정밀하게, 빠르게 제어할 수 있음

<aside>로봇 관절 제어에서의 의미</aside>

로봇 관절의 BLDC/서보모터가 부드럽고 정밀한 토크를 내야 할 때 FOC가 널리 쓰이며, 이 위에 위치·속도를 목표값으로 맞추는 [[PID 제어]] 루프가 얹혀 전체 관절 제어 시스템을 구성한다.

---

<aside>핵심 정리</aside>

- FOC는 모터 전류를 토크 성분과 자속 성분으로 좌표 변환해 각각 독립적으로 정밀 제어하는 벡터 제어 기법이다
- 전압 크기만 조절하는 단순 방식이 아니라, 좌표 변환 기반의 정밀 제어 방식이다
