# Summary

옵저버 패턴은 어떤 객체(주체, Subject)의 상태가 바뀔 때, 그 변화를 **구독하고 있는 여러 관찰자(Observer)에게 자동으로 알리는** 디자인 패턴으로, [[MVC 패턴(Model-View-Controller)]]에서 Model의 변화를 View에 반영할 때 흔히 활용된다.

# Notes

<aside>옵저버 패턴의 동작 방식</aside>

- 주체(Subject)는 자신을 구독(등록)한 관찰자(Observer) 목록을 유지
- 주체의 상태가 변경되면, 등록된 모든 관찰자에게 변경 사실을 통지(notify)함
- 주체는 관찰자가 구체적으로 무엇을 하는지 몰라도 되고, 관찰자를 새로 추가·제거해도 주체 코드를 수정할 필요가 없어 **느슨한 결합**을 유지함

<aside>발행-구독 모델과의 관계</aside>

옵저버 패턴은 하나의 프로세스 안에서 객체 간 통지를 다루는 디자인 패턴이고, [[발행-구독 모델(Publish-Subscribe)]]은 여러 프로세스·시스템 간 메시지 전달까지 다루는 더 넓은 통신 패턴이라는 점에서 규모의 차이가 있지만, "구독자에게 변화를 통지한다"는 핵심 아이디어는 같다.

---

<aside>핵심 정리</aside>

- 옵저버 패턴은 주체의 상태 변화를 구독 중인 관찰자들에게 자동으로 통지하는 디자인 패턴이다
- 관찰자가 폴링으로 확인하러 가는 것이 아니라, 주체가 능동적으로 통지(push)한다
