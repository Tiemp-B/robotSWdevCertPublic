# Summary

액션 플로우는 로봇 콘텐츠 시나리오에서 **사용자의 입력이나 이벤트에 따라 다음에 어떤 동작이 이어질지의 흐름**을 정의한 것으로, 콘텐츠의 전체 진행 논리를 나타낸다.

# Notes

<aside>액션 플로우의 구성</aside>

- "사용자가 A 버튼을 누르면 → 로봇이 인사 동작을 하고 → 다음 장면으로 넘어간다"처럼, 조건(트리거)과 그에 따른 동작(액션)의 연결 순서를 정의
- 단순히 동작 하나하나가 아니라, 여러 동작과 조건 분기가 어떻게 **이어지고 갈라지는지의 전체 흐름**을 다룸
- 콘텐츠 정의서·시나리오 기획 단계에서 이 흐름을 명확히 정의해야 저작 단계에서 일관된 콘텐츠를 만들 수 있음

"액션 플로우는 콘텐츠 안의 개별 동작 하나하나를 독립적으로 정의할 뿐, 동작 간의 순서나 조건 분기와는 무관하다"라는 서술은 오답이다 — 액션 플로우의 핵심은 오히려 **동작들이 어떤 조건에서 어떤 순서로 이어지는지의 흐름 자체**를 정의하는 것이다.

<aside>모션 프리미티브와의 관계</aside>

액션 플로우가 "언제 어떤 동작으로 이어지는가"라는 상위 흐름을 정의한다면, 그 흐름 안의 개별 동작 자체는 [[모션 프리미티브(Motion Primitive)]] 같은 재사용 가능한 기본 동작 단위로 구현되는 경우가 많다.

---

<aside>핵심 정리</aside>

- 액션 플로우는 조건·이벤트에 따라 동작들이 어떤 순서로 이어지는지의 흐름을 정의한다
- 개별 동작 하나하나가 아니라, 동작 간의 연결·분기 흐름 자체가 핵심이다
