# Summary

데이터 마이닝은 대량의 데이터 속에서 **사람이 미리 알지 못했던 패턴·규칙·관계를 발견**하는 과정으로, 단순 집계·조회가 아니라 숨겨진 통찰을 찾아내는 분석 기법이다.

---

# Notes

<aside>데이터 마이닝의 특징</aside>

- 이미 알고 있는 질문에 대한 답(예: "지난달 평균 배터리 소모량은?")을 찾는 단순 조회와 달리, **미리 정해지지 않은 패턴**(예: "어떤 조건에서 로봇 고장이 자주 발생하는가")을 탐색적으로 찾아냄
- 분류, 군집화, 연관 규칙 발견 등 다양한 기법이 활용됨
- 방대한 로봇 로그 데이터에서 사람이 수작업으로는 찾기 어려운 상관관계를 발견하는 데 쓰임

<aside>데이터 웨어하우스·샤딩과의 관계</aside>

데이터 마이닝을 수행하려면 먼저 [[데이터 웨어하우스(Data Warehouse)]]에 잘 정제된 대량의 데이터가 쌓여 있어야 하며, 데이터 양이 매우 커지면 [[샤딩(Sharding)]] 같은 분산 저장 기법으로 처리 성능을 확보한다.
