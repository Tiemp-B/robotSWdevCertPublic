# Summary

Subsumption 아키텍처는 로봇의 행동을 **단순한 반응형 계층(layer)들로 쌓아 올리고, 상위 계층이 필요할 때 하위 계층의 출력을 억제(subsume)**하는 방식으로 복잡한 행동을 만들어내는 로봇 제어 아키텍처다.

# Notes

<aside>Subsumption의 계층 구조</aside>

- 각 계층은 독립적으로 감지-행동(sense-act)을 수행하는 단순한 반응형 모듈("장애물 피하기", "전진하기" 등)
- 계층은 우선순위 순으로 쌓이며, **상위 계층이 활성화되면 하위 계층의 출력을 억제(subsume)**하고 자신의 출력을 대신 내보냄
- 중앙 집중식 세계 모델이나 복잡한 계획 없이도, 여러 단순 계층의 상호작용만으로 복잡해 보이는 행동이 나타남(반응형/행동기반 로보틱스)

"Subsumption 아키텍처는 중앙의 단일 계획 모듈이 모든 계층의 행동을 사전에 계산해 지시하는 하향식 구조다"라는 서술은 오답이다 — Subsumption의 핵심은 오히려 **중앙 계획 없이 여러 단순 반응 계층이 우선순위에 따라 서로를 억제**하며 상향식으로 행동을 만들어낸다는 점이다.

<aside>다른 아키텍처 스타일과의 비교</aside>

Subsumption 같은 반응형(reactive) 아키텍처는 계획 기반(deliberative) 아키텍처와 대비되는 대표적인 로봇 소프트웨어 아키텍처 스타일이며, 실제로는 두 방식을 결합한 하이브리드 아키텍처도 널리 쓰인다.

---

<aside>핵심 정리</aside>

- Subsumption 아키텍처는 여러 단순 반응 계층을 쌓고, 상위 계층이 하위 계층 출력을 억제하는 방식으로 행동을 만든다
- 중앙 계획 모듈이 모든 것을 사전 계산하는 하향식 구조가 아니다
