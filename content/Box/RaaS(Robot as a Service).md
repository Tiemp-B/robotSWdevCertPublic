# Summary

RaaS(Robots as a Service)는 로봇을 직접 구매하지 않고 **클라우드 기반 구독 서비스로 로봇 장비와 관련 데이터 서비스를 임대해 쓰는** 비즈니스 모델로, 소프트웨어의 SaaS(Software as a Service)를 로봇공학에 적용한 개념이다.

# Notes

<aside>RaaS의 핵심 — 소유가 아니라 구독</aside>

기업이 로봇을 초기 구매 비용을 들여 소유하는 대신, 클라우드 기반 구독 서비스로 필요한 만큼 로봇과 데이터 서비스를 빌려 쓰는 모델이다. **[[클라우드 컴퓨팅(Cloud Computing)|클라우드 컴퓨팅]]**의 "필요한 만큼 빌려 쓰는" 원리를 로봇 하드웨어·서비스 자체에 적용한 것으로 볼 수 있다.

<aside>실제 플랫폼 사례</aside>

- **AWS RoboMaker**: 머신러닝·모니터링·분석 서비스를 포함한 클라우드 로봇 개발 플랫폼. 3D 시뮬레이션으로 로봇 알고리즘을 훈련하는 데 활용된 사례가 있음
- **Google Cloud Robotics Platform**: AI·클라우드·로봇을 결합해 클라우드에 연결된 협동로봇 생태계를 지향
- 이 외에도 제조사별 RaaS 플랫폼(예: 산업용 로봇 제조사의 구독형 자동화 서비스)이 늘어나는 추세

<aside>클라우드 로보틱스와의 관계</aside>

RaaS는 [[클라우드 컴퓨팅(Cloud Computing)|클라우드 로보틱스]](로봇의 무거운 연산을 클라우드로 오프로드하는 기술적 구조) 위에서 성립하는 **비즈니스 모델**이다 — 클라우드 로보틱스가 "어떻게 연산을 분담하는가"라면, RaaS는 "로봇을 어떤 방식으로 제공·과금하는가"의 문제다.

---

<aside>핵심 정리</aside>

- RaaS는 로봇을 구매가 아니라 클라우드 기반 구독으로 이용하는 비즈니스 모델이다
- AWS RoboMaker, Google Cloud Robotics Platform 등이 대표적인 클라우드 로봇 플랫폼 사례다
- 클라우드 로보틱스(기술적 구조) 위에 성립하는 비즈니스 모델이라는 점에서 구분된다
