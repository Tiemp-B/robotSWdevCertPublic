# Summary

VFH(벡터장 히스토그램)는 로봇 주변의 장애물 분포를 **방향(각도)별 극좌표 히스토그램**으로 표현해, 장애물 밀도가 낮은 방향을 선택해 이동하는 지역 경로계획(장애물 회피) 알고리즘이다.

# Notes

<aside>VFH의 동작 원리</aside>

- 센서(라이다 등)로 측정한 주변 장애물 정보를 로봇 주위 360도를 여러 구간(섹터)으로 나눈 극좌표 히스토그램으로 변환
- 각 방향 구간의 장애물 밀도(점유 확률)를 계산해, **밀도가 낮은(장애물이 적은) 방향 중 목표 방향에 가장 가까운 곳**을 다음 이동 방향으로 선택
- 히스토그램이라는 방향별 요약 정보만으로 판단하므로, 매 순간의 원시 센서 데이터를 그대로 계산하는 것보다 계산이 간단함

"VFH는 로봇이 낼 수 있는 속도 조합을 직접 시뮬레이션해 궤적을 평가하는 알고리즘이다"라는 서술은 오답이다 — VFH의 핵심은 오히려 **방향별 장애물 밀도 히스토그램을 만들어 이동 방향을 선택**하는 것이며, 속도 공간에서 궤적을 직접 시뮬레이션하는 방식은 [[Dynamic Window Approach(DWA)]]에 가깝다.

<aside>DWA와의 비교</aside>

VFH는 방향(헤딩) 선택에 초점을 둔 지역 경로계획 기법이고, [[Dynamic Window Approach(DWA)]]는 속도 공간 자체에서 실현 가능한 궤적을 시뮬레이션해 평가하는 기법이라는 차이가 있다 — 둘 다 지역 장애물 회피에 쓰이지만 접근 방식이 다르다.

---

<aside>핵심 정리</aside>

- VFH는 주변 장애물을 방향별 극좌표 히스토그램으로 표현해 밀도가 낮은 방향을 선택하는 지역 경로계획 기법이다
- 속도 공간에서 궤적을 직접 시뮬레이션하는 방식이 아니라, 방향별 히스토그램 기반 선택이 핵심이다
