# Summary

가상센서 알고리즘은 실제 센서가 감지하지 못하는 영역까지 **소프트웨어적으로 가상의 센서 정보(장애물 등)를 보완·생성**해, 장애물 회피 알고리즘의 판단 정확도를 높이는 기법이다.

# Notes

<aside>가상센서 알고리즘이 필요한 이유</aside>

- 실제 센서(초음파, 라이다 등)는 사각지대, 측정 범위 한계, 노이즈 등으로 인해 주변 환경을 완벽하게 감지하지 못함
- 가상센서 알고리즘은 과거 측정값, 지도 정보, 로봇의 형상(크기) 등을 활용해 **실제 센서로 감지되지 않은 영역에도 가상의 장애물 정보를 추정·보완**함
- 이렇게 보완된 정보를 [[Elastic Force 알고리즘]] 같은 충돌회피 알고리즘의 척력 계산 입력으로 사용하면, 사각지대로 인한 충돌 위험을 줄일 수 있음

<aside>Elastic Force 알고리즘과의 관계</aside>

가상센서 알고리즘은 [[Elastic Force 알고리즘]]과 짝을 이뤄, 실제 센서만으로는 놓칠 수 있는 사각지대의 장애물까지 고려해 경로를 더 안전하게 조정하는 데 함께 쓰인다.

---

<aside>핵심 정리</aside>

- 가상센서 알고리즘은 실제 센서의 사각지대를 소프트웨어적으로 보완하는 기법이다
- 실제 센서를 완전히 대체하는 것이 아니라, 그 정보를 보완하는 역할이다
