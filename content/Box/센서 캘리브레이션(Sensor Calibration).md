# Summary

센서 캘리브레이션은 센서 출력을 알려진 기준값과 비교해 오프셋·이득·선형성·온도 계수를 보정함으로써 개별 센서의 측정 정확도를 확보하는 과정이다.

<aside>센서 융합·카메라 보정과의 구분</aside>

캘리브레이션은 **센서 하나**의 출력을 보정하는 것이고, [[센서 데이터 융합(Sensor Fusion)|센서 융합]]은 **여러 센서**의 데이터를 결합하는 것이다. 시각 센서에 특화된 카메라 보정(3D-2D 좌표계 관계 산출)과도 목적이 다른 별개 개념이다.

---

<aside>핵심 정리</aside>

- 센서 캘리브레이션은 오프셋·이득·선형화·온도 계수를 보정해 개별 센서의 정확도를 확보한다
- 여러 센서를 결합하는 센서 융합, 좌표계 관계를 구하는 카메라 보정과는 구분되는 개념이다
