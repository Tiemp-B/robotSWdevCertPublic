# Summary

디지털 트윈은 실제 로봇·설비를 가상 공간에 **실시간으로 동기화된 디지털 복제본**으로 구현해, 실물을 직접 조작하지 않고도 상태를 모니터링하거나 시나리오를 미리 시뮬레이션할 수 있게 하는 개념이다.

# Notes

<aside>디지털 트윈의 핵심 — 실시간 동기화</aside>

- 단순한 3D 모델이나 정적인 설계 도면과 달리, 디지털 트윈은 실제 장치의 센서 데이터를 실시간으로 반영해 **가상 모델이 실물의 현재 상태를 계속 따라감**
- 가상 모델에서 시뮬레이션한 결과(예: 이 설정으로 바꾸면 어떻게 될까)를 바탕으로, 실물에 적용하기 전에 미리 검증할 수 있음
- [[Gazebo]] 같은 시뮬레이터가 디지털 트윈을 구현하는 도구로 활용될 수 있지만, 디지털 트윈은 "실시간 동기화"가 핵심이라는 점에서 단순 오프라인 시뮬레이션과 구분됨

"디지털 트윈은 설계 시점에 한 번 만들어진 뒤 실물의 상태 변화와 무관하게 고정된 정적 3D 모델을 의미한다"라는 서술은 오답이다 — 디지털 트윈의 핵심은 오히려 **실물과 실시간으로 동기화**된다는 점이며, 고정된 정적 모델은 디지털 트윈이 아니다.

<aside>디지털 트윈의 3가지 유형 — ISO 23247</aside>

국제표준 ISO 23247(제조업 디지털 트윈 프레임워크)은 디지털 트윈을 세 유형으로 구분한다.

| 유형 | 정의 |
|---|---|
| DTP(Digital Twin Prototype) | 아직 실물과 연결되지 않은 "설계도" 수준의 정보 집합 |
| DTI(Digital Twin Instance) | 실물과 실시간으로 동기화된 디지털 표현 — 보통 "디지털 트윈"이라 하면 이것을 가리킴 |
| DTA(Digital Twin Aggregate) | 여러 DTI(또는 DTP)를 모아 여러 대의 장치 전체 경향을 분석하는 집합체 |

이 구분에 따르면, 이 문서 위쪽에서 말한 "실시간 동기화"는 정확히는 **DTI**의 특징이며, 아직 실물과 연결되지 않은 DTP 단계도 "디지털 트윈"이라는 이름 안에 포함된다는 점에 주의해야 한다.

<aside>로봇과 ICT 융합에서의 의미</aside>

로봇의 디지털 트윈을 활용하면, 실제 로봇을 정지시키지 않고도 가상 환경에서 새 작업 시나리오를 미리 검증하거나, 원격지에서도 로봇의 실시간 상태를 가상 모델로 직관적으로 파악할 수 있다.

---

<aside>핵심 정리</aside>

- 디지털 트윈은 실물과 실시간으로 동기화된 디지털 복제본이다
- 고정된 정적 3D 모델이 아니라, 실시간 동기화가 핵심 특징이다
