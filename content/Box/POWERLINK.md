# Summary

POWERLINK는 표준 이더넷 위에서 **시간을 슬롯(사이클)으로 나눠 실시간 데이터와 일반 데이터를 함께 전송**하는 개방형 실시간 산업용 이더넷 프로토콜이다.

# Notes

<aside>POWERLINK의 시간 슬롯 방식</aside>

- 하나의 통신 사이클을 실시간 제어 데이터 구간(등시성 구간)과 비실시간 일반 데이터 구간으로 나눠 순차적으로 사용
- 마스터가 각 슬레이브의 통신 시점을 정확히 관리해, 여러 장치가 동시에 전송을 시도해 충돌하는 문제를 방지
- [[EtherCAT]]과 마찬가지로 표준 이더넷 하드웨어를 그대로 활용하면서 결정론적 실시간성을 확보하려는 접근

"POWERLINK는 모든 장치가 임의의 시점에 자유롭게 데이터를 전송하는 비결정론적(CSMA 방식) 프로토콜이다"라는 서술은 오답이다 — POWERLINK의 핵심은 오히려 **시간 슬롯을 나눠 전송 시점을 결정론적으로 관리**하는 것이며, 임의 시점 전송 충돌 방식이 아니다.

<aside>다른 실시간 이더넷 프로토콜과의 관계</aside>

POWERLINK는 [[EtherCAT]]·[[Profinet]]과 함께 표준 이더넷 기반 실시간 산업 통신 프로토콜 계열에 속하지만, 실시간성을 확보하는 구체적 메커니즘(on-the-fly 처리 vs 시간 슬롯 분할)이 서로 다르다.

---

<aside>핵심 정리</aside>

- POWERLINK는 시간 슬롯으로 실시간·비실시간 데이터를 구분해 전송하는 결정론적 이더넷 기반 필드버스다
- 임의 시점에 자유롭게 전송하는 비결정론적 방식이 아니다
