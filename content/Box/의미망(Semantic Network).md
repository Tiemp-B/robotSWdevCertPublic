# Summary

의미망은 개념·객체를 노드(node)로, 개념 사이의 관계를 링크(edge)로 표현하는 지식 표현 기법으로, 계층·상속 관계 표현에 강점이 있다.

# Notes

<aside>구조와 예시</aside>

- **노드**: 개념·객체·사건(예: "개", "동물")
- **링크**: 노드 사이의 관계(예: "개" → "동물"을 잇는 "is-a"(~이다) 링크)
- "개는 동물이다"처럼 계층 관계를 표현하면, "동물"이 가진 속성을 "개"가 물려받는 **속성 상속**도 자연스럽게 표현할 수 있음

<aside>장단점</aside>

- **장점**: 지식을 시각적·직관적으로 표현할 수 있고, 노드 추가·변경만으로 지식을 쉽게 확장할 수 있음
- **단점**: 지식베이스가 커질수록 노드·링크가 급격히 늘어나 전체 구조가 복잡해지고 다루기 어려워짐

---

<aside>핵심 정리</aside>

- 의미망은 노드(개념)-링크(관계)로 지식을 표현하는 기법이다
- 계층·상속 관계 표현에 강점이 있으나, 지식이 커지면 복잡해지는 단점이 있다
