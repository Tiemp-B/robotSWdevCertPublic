# Summary

동차 변환행렬은 3차원 공간에서의 **회전과 이동(평행이동)을 하나의 $4\times4$ 행렬**로 함께 표현해, 여러 좌표계 간 변환을 행렬 곱셈만으로 연속 적용할 수 있게 하는 표기법이다.

# Notes

<aside>동차 변환행렬의 구조</aside>

$$T = \begin{bmatrix} R_{3\times3} & p_{3\times1} \\ 0\ 0\ 0 & 1 \end{bmatrix}$$

- 좌측 상단 $3\times3$ 부분: 회전행렬(방향 변화)
- 우측 상단 $3\times1$ 부분: 평행이동 벡터(위치 변화)
- 회전과 이동을 하나의 행렬에 담기 때문에, 여러 좌표계를 거치는 변환도 **행렬을 순서대로 곱하기만 하면** 전체 변환을 구할 수 있음(회전과 이동을 매번 따로 계산할 필요가 없음)

<aside>DH 파라미터·순기구학과의 관계</aside>

[[DH 파라미터(Denavit-Hartenberg Parameters)]]로 각 링크 간 관계를 정의하면, 그 각 링크의 관계가 바로 하나의 동차 변환행렬로 표현되며, 첫 관절부터 말단까지 이 행렬들을 순서대로 곱해 순기구학을 계산한다.

<aside>역변환</aside>

동차 변환행렬의 역행렬은 일반 4×4 행렬처럼 계산하지 않고, 회전행렬이 직교행렬이라는 성질을 이용해 $T^{-1} = [R^T, -R^T p;\ 0, 1]$로 구한다. 회전 부분은 전치($R^T$)를, 이동 부분은 $-R^T p$를 쓴다. 순기구학 T(베이스→말단)를 알면, 반대 방향(말단→베이스) 변환은 새로 유도할 필요 없이 이 공식으로 바로 구할 수 있다.

---

<aside>핵심 정리</aside>

- 동차 변환행렬은 회전과 이동을 하나의 4×4 행렬로 통합해 표현하는 방법이다
- 회전과 이동을 따로 계산하지 않고, 행렬 곱셈으로 연속 변환을 처리할 수 있게 한다
- 역변환은 $T^{-1}=[R^T, -R^T p; 0, 1]$로, 회전행렬의 직교성 덕분에 전치와 곱셈만으로 간단히 구할 수 있다
