# Summary

모션 프리미티브는 "전진", "회전", "손 흔들기"처럼 **미리 정의된 작고 재사용 가능한 동작 단위**로, 복잡한 로봇 모션을 이런 기본 동작들의 조합으로 구성하는 콘텐츠 생성 방식이다.

# Notes

<aside>모션 프리미티브 조합 방식</aside>

- 매번 로봇의 모든 관절 궤적을 처음부터 새로 계산하는 대신, 미리 만들어둔 기본 동작(프리미티브)들을 **순서대로 이어 붙이거나 조합**해 새로운 복합 동작을 만듦
- 각 프리미티브는 독립적으로 검증·재사용이 가능해, 콘텐츠 제작 효율을 높임
- 레고 블록을 조합해 새로운 구조물을 만드는 것과 비슷한 방식으로 이해할 수 있음

<aside>보간법과의 관계</aside>

각 모션 프리미티브 내부의 부드러운 궤적 자체는 [[보간법(Interpolation)]]으로 생성되며, 모션 프리미티브는 그렇게 만들어진 여러 궤적 조각을 상위 레벨에서 재사용 가능한 단위로 묶은 것이라 볼 수 있다.

---

<aside>핵심 정리</aside>

- 모션 프리미티브는 미리 정의된 재사용 가능한 기본 동작 단위이며, 이를 조합해 복잡한 로봇 모션을 만든다
