# Summary

BIBO(Bounded Input, Bounded Output) 안정성은 **유계(한계값이 있는) 입력을 넣었을 때 출력도 항상 유계로 유지되는지**를 판단하는 시스템 안정성 개념으로, 로봇 제어 시스템 검증에서 발산 여부를 확인하는 기준이다.

# Notes

<aside>BIBO 안정성의 정의</aside>

- 입력 신호의 크기가 어떤 유한한 값 이내로 제한되어 있다면(Bounded Input)
- 출력 신호의 크기도 반드시 어떤 유한한 값 이내로 제한되어야 한다(Bounded Output)
- 이 조건을 만족하지 못하면(작은 입력에도 출력이 무한히 커지면) 시스템은 **불안정(발산)**하다고 본다

"BIBO 안정성은 입력이 0일 때 출력도 정확히 0이 되는 것을 의미한다"라는 서술은 오답이다 — BIBO 안정성의 핵심은 **입력이 유한하면 출력도 유한한지**의 문제이지, 출력이 특정 값(0)이 되어야 한다는 조건이 아니다.

<aside>로봇 시스템 시험평가에서의 의미</aside>

로봇 제어기의 신뢰성·안정성 시험에서는 유한한 크기의 명령·외란을 입력했을 때 로봇의 응답(관절 각도, 속도 등)이 발산하지 않고 유한한 범위 내로 수렴 또는 유지되는지를 확인한다. 발산이 확인되면 제어 게인이나 피드백 구조에 문제가 있다고 판단한다.

---

<aside>핵심 정리</aside>

- BIBO 안정성은 유한한 입력에 대해 출력도 항상 유한하게 유지되는지를 판단하는 안정성 개념이다
- 출력이 0이 되어야 한다는 의미가 아니라, 발산하지 않는지가 핵심이다
