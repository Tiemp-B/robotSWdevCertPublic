# Summary

DH 파라미터는 로봇 팔의 인접한 두 링크 사이의 관계를 **관절 각도·링크 길이·링크 오프셋·비틀림 각 4개 값**만으로 표현해, 순기구학 계산을 표준화된 절차로 단순화하는 표기법이다.

# Notes

<aside>DH 파라미터 4요소</aside>

![[Pasted image 20260823192528.png]]

| 파라미터 | 의미 |
|---|---|
| 관절 각(θ, theta) | 관절이 회전한 각도(회전 관절의 변수) |
| 링크 길이(a) | 두 관절 축 사이의 최단 거리 |
| 링크 오프셋(d) | 관절 축을 따라 이동한 거리(직동 관절의 변수) |
| 비틀림 각(α, alpha) | 인접한 두 관절 축 사이의 각도 |

각 링크마다 이 4개 값을 정하면, 좌표계 변환을 표준화된 [[동차 변환행렬(Homogeneous Transformation Matrix)]] 하나로 표현할 수 있어, 여러 관절을 이어 붙인 로봇 팔 전체의 말단 위치를 일관된 절차로 계산할 수 있다.

<aside>순기구학과의 관계</aside>

DH 파라미터로 각 링크의 변환행렬을 구한 뒤, 첫 관절부터 말단(엔드이펙터)까지 이 행렬들을 순서대로 곱하면 로봇 팔의 [[2. 순기구학 계산과 특이점|순기구학]] 결과(말단 위치·자세)를 얻는다 — 이미 이 계산 과정 자체는 다른 페이지에서 다뤘으므로 여기서는 DH 파라미터 표기법 자체에 집중한다.

---

<aside>핵심 정리</aside>

- DH 파라미터는 관절 각·링크 길이·링크 오프셋·비틀림 각 4개 표준 변수로 각 링크 간 관계를 표현한다
- 임의의 변수 개수가 아니라, 모든 링크에 동일한 4개 파라미터를 적용하는 표준화된 표기법이다
