# Summary

피츠의 법칙은 대상까지 **도달하는 데 걸리는 시간이 대상까지의 거리가 멀수록 길어지고, 대상의 크기가 클수록 짧아진다**는 인간공학 법칙으로, UI에서 버튼 크기와 배치를 설계하는 근거로 쓰인다.

# Notes

<aside>피츠의 법칙이 UI 설계에 주는 시사점</aside>

- 자주 눌러야 하는 중요한 버튼(예: 비상정지)은 크게 만들고, 사용자가 있을 만한 위치에서 가깝게 배치하면 더 빠르고 정확하게 클릭할 수 있음
- 반대로 화면 구석에 작게 배치된 버튼은 도달 시간이 길어지고 오조작(잘못 클릭) 위험도 커짐
- 로봇 HMI에서 긴급 조작 버튼을 크고 접근하기 쉬운 위치에 배치하는 것은 피츠의 법칙에 기반한 설계다

<aside>정량 공식</aside>

$$MT = a + b \cdot ID, \quad ID = \log_2\left(\frac{2A}{W}\right)$$

MT(이동 시간)는 난이도 지수 ID에 비례하며, ID는 목표까지의 거리 A가 클수록·목표의 폭 W가 작을수록 커진다(a, b는 실험적 상수).

<aside>밀러의 법칙·힉의 법칙과의 구분</aside>

[[밀러의 법칙(Miller's Law)]](기억 용량의 한계)과 [[힉의 법칙(Hick's Law)]](선택지 수와 의사결정 시간)은 각각 다른 인지적 측면을 다루는 반면, 피츠의 법칙은 물리적인 "도달·클릭" 동작의 속도에 관한 법칙이라는 점에서 구분된다.

---

<aside>핵심 정리</aside>

- 피츠의 법칙은 대상까지의 거리가 멀수록, 크기가 작을수록 도달 시간이 길어진다는 법칙이다
- 색상이 아니라 거리와 크기가 클릭 속도에 영향을 미친다는 것이 핵심이다
