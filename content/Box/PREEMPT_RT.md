# Summary

PREEMPT_RT는 일반 리눅스 커널에 **패치를 적용해 선점 가능한 영역을 넓히고 인터럽트 처리를 스레드화**함으로써, 표준 리눅스를 실시간에 가까운 응답성을 갖도록 개조하는 커널 패치다.

# Notes

<aside>PREEMPT_RT가 리눅스를 개조하는 방식</aside>

- 일반 리눅스는 커널 내부의 일부 코드 구간에서 인터럽트·선점이 금지되어, 그 구간이 실행되는 동안 다른 긴급한 작업이 지연될 수 있음
- PREEMPT_RT는 이런 비선점 구간을 최소화하고, 인터럽트 처리 루틴 자체를 커널 스레드로 만들어 **우선순위 기반으로 스케줄링될 수 있게** 함
- 이를 통해 일반 리눅스보다 응답 지연의 최악 시간(WCET에 가까운 개념)을 훨씬 예측 가능하고 짧게 만듦

"PREEMPT_RT는 리눅스 커널과 완전히 별개의 새로운 커널을 만들어 실시간성을 확보하는 방식이다"라는 서술은 오답이다 — PREEMPT_RT의 핵심은 오히려 **표준 리눅스 커널에 패치를 적용**해 선점성을 높이는 방식이며, 별도의 새 커널이 아니다.

<aside>다른 실시간 리눅스 접근과의 비교</aside>

[[RT-Linux]]·[[Xenomai]]는 리눅스 위에 별도의 실시간 마이크로커널(또는 추상화 계층)을 얹어 리눅스와 분리된 실시간 도메인을 만드는 접근인 반면, PREEMPT_RT는 리눅스 커널 자체를 패치해 개조하는 접근이라는 차이가 있다.

---

<aside>핵심 정리</aside>

- PREEMPT_RT는 리눅스 커널에 패치를 적용해 선점성을 높이고 인터럽트를 스레드화하는 실시간화 방식이다
- 별도의 새 커널이 아니라 표준 리눅스 커널의 개조판이다
