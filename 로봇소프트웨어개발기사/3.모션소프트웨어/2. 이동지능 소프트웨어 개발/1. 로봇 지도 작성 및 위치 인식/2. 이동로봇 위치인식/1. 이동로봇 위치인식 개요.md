# Summary

위치인식(localization)은 지도 위에서 로봇 자신의 현재 위치를 파악하는 것으로, 로봇 자체 센서만으로 추정하는 **상대 위치인식**과 외부 기준을 이용하는 **절대 위치인식**으로 나뉘며, 오차를 확률적으로 다루기 위해 베이즈 필터·칼만 필터를 사용한다.
