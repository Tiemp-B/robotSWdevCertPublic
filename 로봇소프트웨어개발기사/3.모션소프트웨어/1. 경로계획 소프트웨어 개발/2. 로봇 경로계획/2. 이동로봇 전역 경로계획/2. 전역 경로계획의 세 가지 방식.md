# Summary

이동 로봇의 전역 경로계획은 지도를 어떻게 표현하느냐에 따라 **셀 분해(cell decomposition)·로드맵(roadmap)·포텐셜 필드(potential field)** 방식으로 나뉘며, 로드맵 방식에서 만든 그래프는 A*·다익스트라 같은 그래프 탐색 알고리즘으로 최적 경로를 찾는다.

# Notes

<aside>셀 분해 방식(Cell Decomposition)</aside>

지도를 작은 셀(격자)로 나누어 각 셀이 장애물인지 이동 가능한지 표시하는 방식이다.

- **격자 방식(regular grids)**: 지도를 일정한 간격의 격자로 나눔 — 구현이 쉽지만 격자를 촘촘히 할수록(해상도를 높일수록) 계산량이 늘어남
- **쿼드 트리 방식(quad tree)**: 격자를 효율적으로 세분화하지만, 세분화 자체에 계산 시간이 많이 들어 자주 쓰이지는 않음

<aside>로드맵 방식(Roadmap Method)</aside>

장애물이 없는 지역에 노드와 링크(엣지)를 정의해 그래프를 만들고, 그 그래프 위에서 탐색하는 방식이다.

| 방식 | 노드를 두는 위치 |
|---|---|
| 가시성 그래프(Visibility Graph) | 장애물의 꼭짓점에 노드를 두고 서로 연결 |
| **보로노이 다이어그램(Voronoi Diagram)** | **장애물들 사이의 중간(가장 먼) 지점**에 노드를 둠 |

"보로노이 다이어그램 방식은 장애물의 꼭짓점에 노드를 두고 이를 링크로 연결하는 방식이다"라는 서술은 **가시성 그래프**와 뒤바뀐 오답이다 — 장애물 꼭짓점에 노드를 두는 것은 가시성 그래프이며, 보로노이 다이어그램은 장애물 사이의 **중간 지점**에 노드를 두어 장애물과 최대한 멀리 떨어진 안전한 경로를 만드는 것이 특징이다.

<aside>그래프 탐색 알고리즘</aside>

로드맵 방식으로 만든 그래프에서 실제 최적 경로를 찾을 때는 다익스트라(Dijkstra's) 방법이나 A* 알고리즘 같은 그래프 검색 기법을 사용한다.

- **A\* 알고리즘**: $f(n) = g(n) + h(n)$ — $g(n)$은 시작점부터 현재 노드까지의 실제 비용, $h(n)$은 현재 노드에서 목표까지의 **추정 비용(휴리스틱 함수)**
- A* 알고리즘이 최적 경로를 보장하려면 휴리스틱 함수 $h(n)$이 **실제 남은 비용을 과대평가하지 않아야**(admissible) 한다

"A* 알고리즘의 휴리스틱 함수 h(n)은 실제 남은 비용보다 항상 크게 설정해야 최적 경로를 빠르게 찾을 수 있다"라는 서술은 오답이다 — 휴리스틱이 실제 비용을 **과대평가**하면 최적 경로를 보장하지 못할 수 있으며, h(n)은 실제 남은 비용을 **과대평가하지 않는(admissible)** 조건을 만족해야 한다.

<aside>포텐셜 필드 방식(Potential Field Method)</aside>

목표의 인력과 장애물의 척력을 합산해 경로를 생성하는 방식이다. 자세한 원리와 지역 최솟값(local minima) 문제는 [[3. 장애물 회피와 포텐셜 필드|과목2 "로봇 작업 환경 분석"]]에서 이미 다뤘다. 개선된 형태인 gradient method는 장애물에 큰 가중치를 두어 지역 최솟값 문제를 완화한다.

---

<aside>핵심 정리</aside>

- 전역 경로계획은 셀 분해·로드맵·포텐셜 필드 방식으로 나뉘며, 로드맵은 다시 가시성 그래프(장애물 꼭짓점 노드)와 보로노이 다이어그램(장애물 중간 지점 노드)으로 구분된다
- A* 알고리즘의 휴리스틱 함수는 실제 비용을 과대평가하지 않아야 최적 경로를 보장한다
