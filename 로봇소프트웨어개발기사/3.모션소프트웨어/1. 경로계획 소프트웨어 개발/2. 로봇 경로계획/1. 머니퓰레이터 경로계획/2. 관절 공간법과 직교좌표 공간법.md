# Summary

관절 공간법은 경로를 **관절각의 함수**로 계산이 간단하게 표현하지만 엔드이펙터의 실제 이동 경로 모양을 예측하기 어렵고, 직교좌표 공간법은 **엔드이펙터 위치**를 직접 계획해 경로 모양은 예측하기 쉽지만 매 주기 역기구학을 풀어야 하는 부담이 있다.

# Notes

<aside>관절 공간법(Joint Space Method)</aside>

이동 경로의 각 경유점을 [[2. 역기구학 해의 특징(닫힌 형태·수치 해법)|역기구학]] 문제로 풀어 각 관절의 각도로 미리 표현해두고, 관절각을 시간에 대한 함수(3차·5차 다항식 등)로 정의해 경로를 계획하는 방법이다.

- **장점**: 각 관절을 독립적으로 계획할 수 있어 계산이 비교적 간단
- **단점**: 관절 공간에서의 경로가 매끄럽더라도, 그 결과로 나타나는 엔드이펙터의 실제 이동 경로 모양은 직선이 아닐 수 있어 예측하기 어려움

<aside>직교좌표 공간법(Cartesian Space Method)</aside>

엔드이펙터가 지나갈 경로점을 직교좌표 공간에서 직접 계획한 뒤, 매 제어 주기(sampling time)마다 역기구학을 풀어 관절각을 구하고 그 오차만큼 모터를 구동하는 방법이다.

- **장점**: 엔드이펙터의 실제 이동 경로를 정확히 예측·제어할 수 있음
- **단점**: 매 주기마다 역기구학을 반복 계산해야 해 연산 부담이 크고, 기하학적으로 이동이 불가능한 경로(관절 구조상 지나갈 수 없는 영역)가 설정될 수 있는 문제가 있음

"관절 공간법은 매 제어 주기마다 역기구학 문제를 반복적으로 풀어야 하므로 연산 부담이 크다"라는 서술은 **직교좌표 공간법**과 뒤바뀐 오답이다 — 매 주기 역기구학을 반복 계산하는 것은 직교좌표 공간법의 특징이며, 관절 공간법은 경유점에서 미리 역기구학을 한 번만 풀어두므로 상대적으로 제약이 적다.

<aside>실무에서의 선택</aside>

대부분의 산업용 로봇 제어 시스템은 두 방법을 함께 사용하되, 상대적으로 제약이 적은 **관절 공간법을 더 많이 사용**한다. 직교좌표 공간법은 기하학적 문제(경로상 이동 불가능 지점, 특정 지점에서 요구되는 관절 속도가 무한대에 가까워지는 문제 등)가 발생할 가능성이 크기 때문이다.

<aside>예시 — 두 방법의 선택 기준</aside>

**예시**: 단순히 두 지점 사이를 빠르게 오가기만 하면 되는 픽앤플레이스(pick-and-place) 작업에는 계산이 간단한 관절 공간법이 적합하고, 용접선처럼 엔드이펙터가 지나가는 경로 모양 자체가 중요한 작업에는 직교좌표 공간법이 적합하다.

---

<aside>핵심 정리</aside>

- 관절 공간법은 계산이 간단하지만 엔드이펙터 경로 모양 예측이 어렵고, 직교좌표 공간법은 경로 예측은 쉽지만 매 주기 역기구학 연산 부담과 기하학적 문제가 있다
- 산업 현장에서는 제약이 적은 관절 공간법을 더 널리 사용한다
