# Summary

**[[지글러-니콜스 동조법(Ziegler-Nichols Method)|지글러-니콜스 동조법]]**은 시스템을 일부러 지속 진동시켜 얻은 **임계 게인($K_u$)**과 **임계 주기($T_u$)**로부터 PID 게인을 정해진 비율로 계산하는 실험적 동조 방법이다.

# Notes

<aside>동조(Tuning)의 개념</aside>

동조란 PID 제어기의 계수(게인)를 조정하는 것을 말하며, 이를 자동으로 수행하는 것을 자동 동조(auto-tuning)라고 한다. 지글러-니콜스 동조법과 계전기(relay) 동조법이 대표적이며, 이 방법들은 **제어 대상 시스템의 정밀한 수학적 모델을 사용하지 않고** 간단한 실험 과정을 거쳐 계수를 결정한다는 공통점이 있다.

<aside>임계 게인과 임계 주기 구하기</aside>

지글러-니콜스 동조법(폐루프 방법)은 다음 절차로 진행한다.

1. 적분(I)·미분(D) 게인은 0으로 두고, 비례(P) 게인만 있는 상태로 시스템을 폐루프로 구성
2. 비례 게인을 점점 키워가며, 시스템 출력이 **일정한 진폭으로 지속 진동(임계 진동)**하기 시작하는 지점을 찾음
3. 이때의 비례 게인을 **임계 게인($K_u$, ultimate gain)**, 그 진동의 주기를 **임계 주기($T_u$, ultimate period)**라 함

<aside>임계 게인·주기로부터 PID 게인 산출</aside>

| 제어기 종류 | $K_p$ | $T_i$(적분 시간) | $T_d$(미분 시간) |
|---|---|---|---|
| P | $0.5 K_u$ | — | — |
| PI | $0.45 K_u$ | $T_u / 1.2$ | — |
| PID | $0.6 K_u$ | $T_u / 2$ | $T_u / 8$ |

즉, PI 제어기의 적분 시간은 $T_i = T_u / 1.2$로 계산한다.

"지글러-니콜스 동조법에서 PI 제어기의 적분 시간은 임계 주기에 비례상수를 곱해 구하며, 임계 주기가 길어질수록 적분 시간도 함께 짧아진다"라는 서술은 오답이다 — 적분 시간은 $T_i = T_u/1.2$로, 임계 주기 $T_u$에 **비례**하므로 임계 주기가 길어지면 적분 시간도 함께 **길어진다**.

<aside>예시 — 지글러-니콜스 적용</aside>

**예시**: 어떤 서보 제어 루프에서 비례 게인을 서서히 높이다가 $K_u = 10$에서 주기 $T_u = 2$초의 지속 진동이 관찰되었다면, PI 제어기로 튜닝할 경우 $K_p = 0.45 \times 10 = 4.5$, $T_i = 2/1.2 \approx 1.67$초로 초기 게인을 설정한 뒤 실제 응답을 보며 미세 조정한다.

---

<aside>핵심 정리</aside>

- 지글러-니콜스 동조법은 임계 게인·임계 주기를 실험적으로 구한 뒤 정해진 비율로 PID 게인을 산출하는 방법이다
- PI 제어기의 적분 시간은 $T_u/1.2$로, 임계 주기에 비례한다
