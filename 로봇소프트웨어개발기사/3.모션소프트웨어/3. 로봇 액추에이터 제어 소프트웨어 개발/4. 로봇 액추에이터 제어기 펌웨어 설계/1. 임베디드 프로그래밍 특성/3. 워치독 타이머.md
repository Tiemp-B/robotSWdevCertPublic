# Summary

**[[워치독 타이머(Watchdog Timer)|워치독 타이머]]**는 소프트웨어가 오작동으로 멈췄을 때(무한루프·행 등) 이를 감지해 시스템을 강제로 리셋시켜, 사람의 개입 없이도 로봇 제어기가 스스로 복구하도록 하는 하드웨어 타이머다.

# Notes

<aside>워치독 타이머의 동작 원리</aside>

워치독 타이머는 일정 시간(타임아웃)마다 자동으로 카운트다운되는 하드웨어 타이머로, 정상 동작 중인 소프트웨어는 타이머가 만료되기 전에 주기적으로 **타이머를 리셋(kick/feed)**시켜야 한다.

- 소프트웨어가 정상 동작 중이면: 매 주기 타이머를 계속 리셋 → 타임아웃이 발생하지 않음
- 소프트웨어가 무한루프·행(hang) 등으로 멈추면: 타이머 리셋 신호를 보내지 못함 → 타임아웃 발생 → 워치독이 시스템을 강제로 리셋(재부팅)

<aside>워치독 타이머의 목적</aside>

"워치독 타이머의 주요 목적은 CPU의 연산 속도를 향상시켜 프로그램 실행을 가속하는 것이다"라는 서술은 오답이다 — 워치독 타이머는 연산 속도와는 무관하며, 목적은 **소프트웨어의 비정상적인 멈춤(오작동)을 감지해 자동으로 복구(리셋)**시키는 것이다.

<aside>로봇 제어기에서의 중요성</aside>

로봇처럼 사람이 상시 지켜보지 않는 무인 시스템에서, 제어 소프트웨어가 예기치 않은 오류로 멈춰버리면 로봇이 위험한 상태로 정지하거나 계속 잘못된 동작을 반복할 수 있다. 워치독 타이머는 이런 상황에서 시스템을 강제로 리셋해 안전한 초기 상태로 복귀시키는 최후의 안전장치 역할을 한다.

<aside>예시 — 워치독 타이머의 동작</aside>

**예시**: 로봇 액추에이터 제어 루프가 100ms 주기로 워치독 타이머를 리셋하도록 설계되어 있는데, 어떤 예외 상황으로 제어 루프가 무한 대기 상태에 빠지면 타이머 리셋 신호가 끊기고, 정해진 타임아웃(예: 500ms) 후 워치독이 시스템을 강제 리부팅해 액추에이터가 위험한 상태로 고착되는 것을 방지한다.

---

<aside>핵심 정리</aside>

- 워치독 타이머는 소프트웨어가 주기적으로 리셋시키지 않으면 타임아웃되어 시스템을 강제 리셋시키는 하드웨어 타이머다
- 목적은 연산 속도 향상이 아니라 오작동(멈춤) 감지와 자동 복구다
