# Summary

모터 드라이버 펌웨어를 설계할 때는 **PWM 주파수**를 적절히 선정해야 하며, 여러 태스크를 동시에 처리하는 **멀티스레딩** 구조에서는 공유 자원 접근에 주의해야 한다.
