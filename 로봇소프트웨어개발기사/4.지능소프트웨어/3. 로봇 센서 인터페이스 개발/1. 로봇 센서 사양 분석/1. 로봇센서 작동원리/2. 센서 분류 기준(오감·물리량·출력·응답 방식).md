# Summary

센서는 사람의 오감·계측 물리량 같은 **개념적 분류**와, MCU 신호 처리 방식을 좌우하는 **출력 방식·응답 방식**의 **기능적 분류**로 나눌 수 있다.

# Notes

<aside>사람의 오감에 따른 센서 분류</aside>

| 오감 | 센서 |
|---|---|
| 시각 | 포토 다이오드, 컬러 센서, 카메라 |
| 청각 | 마이크 |
| 후각 | 가스 센서 |
| 미각 | 바이오 센서, 미각 센서 |
| 촉각 | 온도 센서, 터치 센서, 압력 센서 |

<aside>계측 물리량에 따른 센서 분류</aside>

| 물리량 | 센서 |
|---|---|
| 기계 | 위치·형상·속도·힘·토크·압력·진동·질량 센서 |
| 전기 | 전압·전류·전하·전기전도도 센서 |
| 자기 | 자기장·자속·투자율 센서 |
| 온도 | 온도·열전달·열전도도·비열 센서 |
| 기타 | 음향·근접도·화학조성·광전기·방사·레이저·측각·음성·시각 센서 |

"로봇 센서의 작동 원리에 따른 분류에는 소프트웨어 개발 언어에 따른 분류가 포함된다"라는 서술은 오답이다 — 센서의 작동 원리 분류는 **오감·계측 물리량·출력 방식·응답 방식** 등 물리적·신호적 기준이며, 소프트웨어 개발 언어와는 무관하다.

<aside>출력 방식에 따른 센서 분류</aside>

| 방식 | 특징 |
|---|---|
| 전압 출력형 | 측정값을 전압으로 출력 |
| 전류 출력형 | 측정값을 전류로 출력, 저항을 연결해 전압으로 변환(산업 현장에서는 노이즈에 강한 4~20mA 전류 출력을 선호) |
| 디지털 신호형 | 측정값을 디지털 신호로 출력 |
| 아날로그 신호형 | 측정값을 아날로그 신호로 출력, ADC로 디지털 변환 |
| 통신 신호형 | 정해진 디지털 통신 방식(Field bus 등)으로 일련의 신호를 전송 |

<aside>응답 방식에 따른 센서 분류</aside>

| 방식 | 특징 |
|---|---|
| 일반형 | 센서의 측정값이 항상 준비되어 있음 |
| 요구-응답형 | MCU가 요청할 때만 측정값을 전송 |
| 주기적 응답형 | 초기 설정 이후 MCU 요청 없이도 주기적으로 측정값 전송 |
| 계속 응답형(continuous stream) | MCU 요청과 무관하게 측정값이 준비되면 센서가 계속 전송 |

"주기적 응답형 센서는 MCU가 매번 요청 신호를 보내야만 측정값을 전송한다"라는 서술은 **요구-응답형**과 뒤바뀐 오답이다 — 주기적 응답형은 초기 설정 이후에는 **MCU의 요청 없이도** 정해진 주기마다 스스로 측정값을 전송한다.

---

<aside>핵심 정리</aside>

- 센서는 오감·계측 물리량으로 개념적 분류, 출력 방식·응답 방식으로 신호처리 방식이 결정되는 기능적 분류가 가능하다
- 주기적 응답형은 요청 없이 스스로 주기 전송하며, 요구할 때만 전송하는 것은 요구-응답형이다
