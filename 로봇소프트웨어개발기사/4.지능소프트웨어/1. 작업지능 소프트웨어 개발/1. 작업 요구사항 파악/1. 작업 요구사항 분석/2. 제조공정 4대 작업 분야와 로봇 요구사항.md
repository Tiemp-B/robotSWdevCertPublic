# Summary

제조공정에서 로봇이 수행하는 작업은 **자재취급·공정처리·조립·검사**의 4대 분야로 나뉘며, 각 분야마다 로봇에게 요구하는 기능(힘·정밀도·속도 등)이 다르다.

# Notes

<aside>자재취급(Material Handling)</aside>

로봇이 자재·부품을 안전하게 들어 올려 정확한 위치에 놓는 작업이다.

| 세부 작업 | 내용 |
|---|---|
| 부품배치(pick-and-place) | 부품을 들어 올려 목적 위치에 정확히 놓음 — 영상인식·역기구학·정밀제어 필요 |
| 적재 및 하역(palletizing) | 부품·제품을 쌓거나 하나씩 내림 — 무거운 경우 큰 작업 토크 필요 |
| 기계 장착·탈착(loading/unloading) | 생산 기계에 부품을 공급·회수 — 기계와의 작업 사이클 시간 동기화(제어기 간 통신) 필요 |

<aside>공정처리(Process Operations)</aside>

로봇이 부품·자재에 용접·도장·절삭가공·도포 작업을 수행하는 것으로, 공정에 적합한 공구(tool)를 엔드이펙터에 설치해야 하는 것이 특징이다.

| 작업 | 요구되는 로봇 능력 |
|---|---|
| 점용접(spot welding) | 무거운 용접총 적재 하중, 지점간(point-to-point) 제어 |
| 아크용접(arc welding) | 연속 경로제어 능력 |
| 절삭가공·디버링 | 위치·자세 동시 제어, 고강성, 작업면과의 상호작용력 제어 |
| 도포(coating) | 연속 경로제어, 경로점 최적화 |

"자재취급 작업에는 정밀한 경로 제어 능력이, 공정처리 중 아크용접 작업에는 지점간(point-to-point) 제어만 있으면 충분하다"라는 서술은 오답이다 — 아크용접은 경로를 따라 **연속적으로** 접합해야 하므로 연속 경로제어 능력이 중요하며, 지점간 제어로 충분한 것은 오히려 점용접이다.

<aside>조립(Assembly)과 검사(Inspection)</aside>

- **조립**: 부품을 체결·해체해 제품을 만드는 작업. 말단장치가 부품을 쉽게 들어 올리고 조립할 수 있어야 하며, 협동로봇·양팔 로봇 기술이 활용됨
- **검사**: 부품·장치가 움직이며 불량 여부를 판단, 고도의 정밀성 요구. 비파괴검사 로봇은 초음파 등을 이용해 사람이 접근하기 힘든 곳(압력 용기 등)을 안전하게 진단

---

<aside>핵심 정리</aside>

- 자재취급·공정처리·조립·검사는 각기 다른 로봇 능력(정밀도·토크·경로제어 방식)을 요구한다
- 점용접은 지점간 제어, 아크용접·도포는 연속 경로제어가 핵심이며 이 둘을 혼동하지 않아야 한다
