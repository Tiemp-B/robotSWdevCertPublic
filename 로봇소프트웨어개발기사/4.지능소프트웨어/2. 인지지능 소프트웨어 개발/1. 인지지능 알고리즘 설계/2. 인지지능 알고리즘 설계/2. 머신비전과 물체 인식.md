# Summary

**머신비전**은 영상 획득-영상 처리-영상 분석의 3단계로 진행되며, 물체 인식은 미리 저장된 표준 모델과 비교하는 **원형 정합**과 물체의 특징점을 비교하는 **특징 정합**으로 나뉜다.

# Notes

<aside>머신비전의 3단계</aside>

| 단계 | 내용 |
|---|---|
| 영상 획득(image acquisition) | 영상 센서(CCD 등)로 3차원 세계를 2차원 영상 평면에 투영. 아날로그 신호를 표본화·양자화해 디지털 값으로 변환 |
| 영상 처리(image processing) | 잡음 제거(마스크로 주변 화소와 평균), 경계 검출(소벨 마스크 등), 영상의 이진화(임계치 기준 0/1) |
| 영상 분석(image analysis) | 영역 분할(비슷한 특징의 화소를 하나의 영역으로), 특징 추출(밝기·면적·둘레 등 기하학적 특징 검출) |

"머신비전에서 영상의 이진화는 물체와 배경을 구분하지 않고 모든 화소를 동일한 값으로 통일하는 작업이다"라는 서술은 오답이다 — 이진화는 임계치를 기준으로 배경 화소에는 0을, **물체 화소에는 1을 할당**해 물체와 배경을 구분하는 작업이다.

<aside>카메라 보정(Calibration)</aside>

인지지능을 적용하기 전에는 로봇 카메라의 보정이 되어 있는지 확인해야 한다. 카메라 보정이란 3차원 공간 좌표계와 2차원 영상 좌표계 사이의 기하학적 관계를 수식으로 표현하는 작업으로, 카메라의 내부 변수(광학·기하학적 특성)와 외부 변수(회전각·이동 변위)를 조정한다.

<aside>물체 인식(Object Recognition) 방법</aside>

| 방법 | 원리 |
|---|---|
| 원형 정합(template matching) | 분석된 물체를 미리 저장된 표준 모델(원형)과 비교해 가장 가까운 모델을 인식 물체로 선정 |
| 특징 정합(feature matching) | 물체의 특징점·부분 구조를 부호화해 다른 영상의 특징점과 정합성을 판단 — 물체의 병진·회전·배율 변화에도 강건 |

<aside>SIFT와 SURF</aside>

특징 정합에 널리 쓰이는 대표적 알고리즘으로 **SIFT(Scale Invariant Feature Transform)**와 **SURF(Speed-Up Robust Features)**가 있다.

- SIFT: 가려짐(occlusion)에 강인하고 배경이 복잡해도 특징을 잘 검출하지만, 상대적으로 **느림**
- SURF: SIFT를 속도 면에서 개선한 방식으로, 인식 속도가 **빨라야** 하는 경우에 사용

"인식 속도가 빨라야 하는 경우에는 SIFT를, 정확도가 우선인 경우에는 SURF를 사용한다"라는 서술은 오답이다 — 속도가 우선일 때는 **SURF**, 정확도(가려짐·복잡한 배경 대응)가 우선일 때는 **SIFT**를 사용한다.

---

<aside>핵심 정리</aside>

- 머신비전은 영상 획득-처리-분석의 3단계이며, 이진화는 임계치로 물체(1)와 배경(0)을 구분하는 작업이다
- 원형 정합은 표준 모델과의 비교, 특징 정합은 특징점 비교이며, SIFT(정확도)와 SURF(속도)는 서로 다른 우선순위를 가진다
