# Summary

**[[마르코프 체인(Markov Chain)|마르코프 체인]]**은 다음 상태가 현재 상태에만 의존한다고 가정해 사용 패턴을 모델링하는 방법이며, 시계열 형태의 사용 데이터를 분석하기 전에는 통계적 성질이 시간에 따라 변하지 않는지, 즉 **정상성(Stationarity)**을 먼저 검증해야 한다.

# Notes

<aside>마르코프 체인(Markov Chain) 모델링</aside>

마르코프 체인은 시스템이 여러 상태(state) 사이를 확률적으로 전이(transition)하는 과정을 모델링하며, 핵심 가정은 **마르코프 성질(Markov Property)** — 다음 상태로의 전이 확률이 **현재 상태에만 의존**하고, 그 이전까지의 전체 이력에는 의존하지 않는다는 것이다.

"로봇의 사용 패턴을 마르코프 체인으로 모델링할 때 가장 중요한 특성은 사용자의 과거 전체 사용 이력을 모두 반영하는 것이다"라는 서술은 오답이다 — 마르코프 체인의 핵심 특성은 오히려 **현재 상태만으로 다음 상태를 예측**하는 것(과거 전체 이력에 의존하지 않는 무기억성)이다.

<aside>시계열 데이터의 정상성(Stationarity)</aside>

정상성이란 시계열 데이터의 평균·분산 등 통계적 성질이 시간이 지나도 변하지 않는 성질을 말한다. 대부분의 시계열 분석 기법은 데이터가 정상성을 만족한다고 가정하므로, 분석 전에 정상성 여부를 검증해야 한다.

- **정상성 검증 방법**: ADF 검정(Augmented Dickey-Fuller Test) 같은 단위근 검정(unit root test)을 사용해 통계적으로 정상성 여부를 판단
- 정상성을 만족하지 않으면(추세·계절성이 있으면) 차분(differencing) 등으로 변환한 뒤 분석

"시계열 데이터의 정상성을 검증하는 가장 적절한 방법은 데이터를 그래프로 그려 육안으로 추세를 확인하는 것뿐이다"라는 서술은 오답이다 — 육안 확인은 참고용일 뿐이며, 정상성은 **ADF 검정 같은 통계적 가설 검정**으로 객관적으로 판단해야 한다.

<aside>예시 — 로봇 사용 패턴의 마르코프 체인화</aside>

**예시**: 청소 로봇의 "대기 → 청소 시작 → 청소 중 → 충전 → 대기" 같은 상태 전이 이력을 마르코프 체인으로 모델링하면, "청소 중" 상태에서 다음에 "충전" 상태로 갈 확률을 과거 전체 이력 없이 현재 상태만으로 추정할 수 있어 다음 행동을 예측하는 데 활용할 수 있다.

<aside>핵심 정리</aside>

- 마르코프 체인의 핵심은 과거 전체 이력이 아니라 현재 상태만으로 다음 상태를 예측하는 것이다
- 시계열 정상성은 육안 확인이 아니라 ADF 검정 같은 통계적 방법으로 검증한다
