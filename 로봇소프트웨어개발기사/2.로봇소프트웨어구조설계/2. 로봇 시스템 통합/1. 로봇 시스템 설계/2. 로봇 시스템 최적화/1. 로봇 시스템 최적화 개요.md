# Summary

**로봇 시스템 최적화**는 통합이 끝난 시스템의 CPU·메모리·전력·응답성을 개선해, 제한된 임베디드 자원 안에서 로봇이 안정적으로 동작하도록 만드는 활동이다.

<aside>이미 다룬 내용과의 관계</aside>

주기적 처리 vs [[3. 가비지 컬렉션과 이벤트 기반 처리|이벤트 기반 처리]]의 효율성 비교, 자동 메모리 회수(가비지 컬렉션)는 이미 "미들웨어 프로세스 관리"에서 다뤘으므로 여기서는 반복하지 않고 링크로 참조한다. 이 세세항목은 **CPU·전력 관점의 구체적 최적화 기법**에 집중한다.

<aside>이 세세항목의 구성</aside>

이후 페이지는 [[2. CPU·메모리 최적화 기법|CPU·메모리 최적화 기법]](프로파일링, 폴링 축소, 알고리즘·스레드 최적화), [[3. 전력 소비 최적화 기법|전력 소비 최적화 기법]](저전력 모드, DVFS, 불필요한 하드웨어 비활성화)을 다룬다.

<aside>핵심 정리</aside>

- 로봇 시스템 최적화는 통합 이후 단계에서 CPU·메모리·전력 등 자원 사용을 개선하는 활동이며, 메모리 자동 회수(가비지 컬렉션)나 이벤트 기반 처리 자체는 이미 다룬 개념이다
