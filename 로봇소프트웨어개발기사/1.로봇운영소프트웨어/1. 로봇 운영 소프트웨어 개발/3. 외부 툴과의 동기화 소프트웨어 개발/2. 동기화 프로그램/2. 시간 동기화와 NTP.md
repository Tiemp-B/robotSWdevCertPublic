# Summary

로봇, 원격제어기, 여러 대의 로봇들은 각자 별도의 하드웨어에서 독립적으로 동작하며 네트워크로만 연결된 **분산 시스템**을 이룬다. 이런 분산 시스템에서는 각 기기가 저마다 독립된 시계를 갖기 때문에 시간이 서서히 어긋나는 [[클럭 드리프트(Clock Drift)|클럭 드리프트]]가 발생한다.  이를 보완하기 위해 **[[NTP(Network Time Protocol)|NTP]]**(Network Time Protocol)는 네트워크를 통해 여러 기기의 시계를 기준 서버와 맞추는 대표적인 시간 동기화 프로토콜이다.

# Notes

<aside>분산 시스템인 로봇 원격제어 환경</aside>

[[1. 동기화 프로그램 개요]]에서 짚었듯 로봇과 외부 툴은 물리적으로 분리된 별도의 시스템이다. 로봇 본체, 원격제어기, 그리고 여러 대의 로봇이 함께 동작하는 환경에서는 각 기기가 **자신만의 프로세서와 시계를 가진 채 네트워크로만 연결**되어 있을 뿐, 하나의 시계나 메모리를 공유하지 않는다. 이렇게 물리적으로 분리된 여러 컴퓨팅 노드가 협력해 동작하는 구조를 **분산 시스템**이라 하며, 로봇 원격제어·다중 로봇 환경도 여기에 해당한다.

<aside>분산 시스템에서 시간 동기화가 필요한 이유</aside>

각 기기의 하드웨어 시계는 미세하게 다른 속도로 흐르기 때문에 시간이 지날수록 서로 어긋나는 **클럭 드리프트**가 발생한다. 여러 로봇의 이벤트를 시간 순서대로 재구성하거나 로그를 비교·분석하려면, 그 전에 각 기기의 시계가 서로 일치해 있어야 한다.

<aside>NTP(Network Time Protocol) 개념</aside>

계층적 구조(**Stratum**)를 가진 시간 서버들로부터 클라이언트가 시각을 받아와 자신의 시계를 보정하는 프로토콜이다.

| 계층 | 설명 |
|---|---|
| Stratum 0 | 원자시계·GPS 등 기준 시각원 자체 |
| Stratum 1 | Stratum 0에 직접 연결된 서버 |
| Stratum 2 이하 | 상위 Stratum 서버로부터 시각을 받는 하위 서버·클라이언트 |

<aside>NTP의 시간 보정 방식</aside>

클라이언트는 서버에 요청을 보내고 응답을 받기까지의 **왕복 시간(Round-Trip Time)**을 측정해 네트워크 지연을 추정하고, 이를 바탕으로 정확한 시각 차이를 계산해 보정한다. 이 과정을 여러 번 반복·필터링하며 점진적으로 오차를 줄여나간다.

<aside>NTP에 대한 오답 함정</aside>

- "NTP는 한 번의 요청-응답만으로 완벽하게 시각을 동기화한다"는 옳지 않다 — 실제로는 반복 측정과 필터링으로 점진적으로 오차를 줄여 나간다
- "NTP는 네트워크 지연을 전혀 고려하지 않는다"도 옳지 않다 — 왕복 시간 측정을 통한 지연 보정이 NTP의 핵심 메커니즘이다

<aside>NTP 정확도의 한계</aside>

네트워크 지연이 비대칭적이거나(왕복 경로의 지연이 서로 다름) 지터가 크면 보정 오차가 커진다. 이 때문에 일반적인 NTP는 수 밀리초~수십 밀리초 수준의 정확도를 가지며, 이보다 훨씬 높은 정밀도가 필요한 경우(예: 정밀 계측)에는 PTP(Precision Time Protocol) 같은 프로토콜을 사용하기도 한다.

<aside>예시 — 다수 로봇의 이벤트 로그 시간 정렬</aside>

**예시**: 여러 로봇이 각자의 로컬 시계로 이벤트를 기록하면, 로그를 한데 모았을 때 실제 발생 순서와 다르게 뒤섞일 수 있다. 각 로봇이 NTP로 동일한 기준 시각에 동기화되어 있으면, 여러 로봇의 로그를 시간 순서대로 정확히 재구성할 수 있다 — [[5. 데이터 로깅과 이상치 탐지]]에서 다룬 로깅 데이터의 신뢰도가 바로 이 시간 동기화에 달려 있다.

---

<aside>핵심 정리</aside>

- 분산된 기기들은 클럭 드리프트로 시간이 서서히 어긋나며, NTP는 이를 네트워크로 보정하는 대표적 프로토콜이다
- NTP는 **왕복 시간 측정으로 네트워크 지연을 보정**하며 반복 측정으로 오차를 줄인다 — 한 번의 요청으로 완벽히 동기화되지 않는다
- 일반 NTP의 정확도는 수 밀리초~수십 밀리초 수준이며, 더 높은 정밀도가 필요하면 PTP 등을 사용한다
