# Summary

로봇 제어기가 엔드 이펙터를 원하는 위치로 움직이려면, 위치를 표현하는 기준인 **[[로봇 좌표계(Coordinate System)|좌표계]]**와 시작점에서 목표점까지 어떤 경로로 움직일지 정하는 **[[보간법(Interpolation)|보간법]]**이 필요하다. 좌표계·변환행렬·기구학 해석의 수학적 상세는 과목3 [[1. 좌표계 개요]]에서 본격적으로 다루므로, 여기서는 로봇 제어기가 다루는 개념 차원에서만 정리한다.

# Notes

<aside>로봇 좌표계 4종</aside>

로봇의 위치·자세는 항상 어떤 기준(원점)에 대한 상대 표현이며, 로봇 제어기는 목적에 따라 서로 다른 좌표계를 함께 사용한다. 서로 다른 좌표계라도 고정된 변환(Transform) 관계로 연결돼 있어 하나의 좌표계 값을 다른 좌표계로 옮겨 계산할 수 있다.

- **월드 좌표계(World Frame)**: 로봇 베이스가 아니라 **작업장 전체를 기준**으로 하는 절대 좌표계 — 여러 로봇·장비의 위치를 하나의 공통 기준으로 통합할 때 사용
- **베이스 좌표계(Base Frame)**: 로봇 본체의 고정 받침대를 원점으로 하는 좌표계 — 로봇 자체 기구학 계산의 기준
- **툴 좌표계(Tool Frame / TCP)**: 엔드 이펙터(그리퍼·용접기 등) 끝단을 원점으로 하는 좌표계 — 엔드 이펙터를 교체하면 정의도 함께 바뀜
- **조인트 좌표계(Joint Frame)**: 각 관절의 회전/직선 변위(관절각)로 자세를 표현하는 좌표계 — 순기구학/역기구학 계산의 입출력 공간

"베이스 좌표계가 곧 작업장 전체를 기준으로 하는 절대 좌표계"라는 서술은 베이스(로봇 기준 상대 좌표계)와 월드(작업장 기준 절대 좌표계)를 뒤바꾼 오답이다. 좌표계 간 변환에 쓰이는 동차변환행렬·DH 파라미터 등 수학적 유도는 과목3 [[2. 변환행렬]]·[[3. 로봇 기구학 해석]]에서 다루므로 반복하지 않는다.

<aside>보간법 3종 + 관절 보간</aside>

로봇은 시작점~목표점 사이를 한 번에 점프하지 않고, 여러 경유점(way point)으로 나누어 매 제어 주기마다 순서대로 명령을 낸다. **경유점을 어떤 경로 모양으로 연결하는가**가 보간법이며, 방식에 따라 경로 정확성·계산 복잡도가 달라진다.

- **직선 보간(Linear Interpolation)**: 시작점-목표점을 직선으로 연결 — 정확한 직선 운동이 필요할 때
- **원호 보간(Circular Interpolation)**: 세 점(시작·경유·목표) 또는 중심점+반지름으로 원호 경로 생성 — 곡선 용접 등
- **스플라인 보간(Spline Interpolation)**: 여러 경유점을 매끄러운 다항식 곡선으로 연결 — 급격한 속도·가속도 변화를 피해야 할 때
- **관절 보간(Joint Interpolation)**: 말단장치의 경로 모양이 아니라 **각 관절의 각도**를 기준으로, 목표 자세에 모든 관절이 동시에 도착하도록 관절마다 필요한 각도 차이에 맞춰 **등속도로 동시에 회전**시키는 방식

직선 보간은 말단장치 경로가 직선이 되도록 각 관절을 복잡하게 조정해야 하지만, 관절 보간은 각 관절이 각자 등속도로 움직이기만 하면 되므로 **동작에 필요한 전체 에너지와 계산량이 더 적다** — "관절 보간이 직선 보간보다 계산·에너지를 더 많이 필요로 한다"는 서술은 두 방식의 특성을 뒤바꾼 오답이다. 다만 관절 보간은 말단장치가 지나가는 경로의 모양을 예측하기 어려워, 경로 자체의 정확성이 중요한 작업(직선 용접 등)에는 직선 보간이 더 적합하다.

**수동 교시(Lead-through Teaching)**로 프로그래밍할 때는 위 정형화된 곡선 보간이 아니라, 교시 중 촘촘하게 기록된 경유점들을 **그대로 순서대로 재생**하는 방식으로 경로가 만들어진다 — 사전에 정한 곡선 유형이 아니라 교시 시점의 불규칙한 점 나열이라는 점이 다르다.

<aside>핵심 정리</aside>

- **월드 좌표계** = 작업장 기준 절대 좌표계 / **베이스·툴·조인트 좌표계** = 로봇(그 일부) 기준 상대 좌표계
- **직선 보간**(직선 경로) · **원호 보간**(곡선 경로) · **스플라인 보간**(부드러운 다항식 경로)
- **관절 보간** = 각 관절 각도를 등속도로 동시 회전 → 에너지·계산량 더 적음, 경로 모양 예측 어려움
- 좌표계 변환행렬·기구학 해석의 수학적 상세는 과목3에서 다룸(중복 없음)
