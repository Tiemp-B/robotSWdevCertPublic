# Summary

딥러닝 모델을 실제로 훈련시키다 보면 이론만으로는 드러나지 않는 실무적인 문제들을 마주친다. 훈련 데이터에만 지나치게 맞춰지는 **[[과적합(Overfitting)|과적합]]**, 한 번에 학습에 사용하는 데이터 양을 정하는 **배치 크기(Batch Size)**, 그리고 기존에 학습된 모델을 재활용하는 **[[전이학습(Transfer Learning)|전이학습]]**이 대표적이다.

# Notes

<aside>과적합(Overfitting)이란</aside>

모델이 **훈련 데이터에는 매우 잘 맞지만, 새로운(훈련에 쓰이지 않은) 데이터에는 성능이 떨어지는** 현상이다. 모델이 훈련 데이터의 일반적인 패턴이 아니라 세부적인 잡음(noise)까지 암기해 버렸을 때 발생한다.

<aside>과적합을 방지하는 기법</aside>

| 기법 | 설명 |
|---|---|
| [[드롭아웃(Dropout)|드롭아웃(Dropout)]] | 학습 과정에서 매번 무작위로 일부 뉴런을 비활성화해, 특정 뉴런 조합에 지나치게 의존하지 못하게 함 |
| 데이터 증강(Data Augmentation) | 훈련 이미지를 회전·반전·밝기 조절 등으로 다양화해 데이터 양과 다양성을 늘림 |
| 조기 종료(Early Stopping) | 검증 데이터 성능이 더 이상 좋아지지 않는 시점에 학습을 멈춤 |
| 정규화(Regularization) | 모델 파라미터가 지나치게 커지지 않도록 페널티를 부여 |

"학습 과정에서 무작위로 일부 뉴런을 비활성화하는 정규화 기법"은 **드롭아웃(Dropout)**을 가리키는 정의다.

<aside>배치 크기(Batch Size)</aside>

**배치 크기**는 모델의 파라미터를 한 번 갱신할 때 사용하는 훈련 데이터 샘플의 개수다.

| 배치 크기 | 특징 |
|---|---|
| 작을 때 | 파라미터가 자주 갱신되어 학습이 불안정할 수 있지만, 메모리 사용량이 적고 일반화에 유리한 경우가 있음 |
| 클 때 | 한 번의 갱신이 더 안정적인 방향으로 이뤄지지만, 메모리를 많이 사용하고 지역적인 좋은 해를 지나칠 수 있음 |

"배치 크기를 무조건 크게 설정할수록 항상 더 좋은 모델이 학습된다"는 서술은 배치 크기가 메모리·일반화 성능과 트레이드오프 관계에 있다는 점을 무시한 오답이다.

<aside>전이학습(Transfer Learning)</aside>

**[[전이학습(Transfer Learning)|전이학습]]**은 대규모 데이터로 이미 학습된 기존 모델(사전학습 모델)의 지식을 가져와, 데이터가 적은 새로운 문제에 맞게 일부만 다시 학습(미세조정, Fine-tuning)시키는 방법이다.

- **장점**: 처음부터 학습할 때보다 **훨씬 적은 데이터와 시간**으로도 준수한 성능을 얻을 수 있다
- 로봇 훈련처럼 실제 환경에서 수집 가능한 데이터가 제한적인 경우에 특히 유용하다

<aside>예시 — 소량 데이터로 새 부품 인식 모델 만들기</aside>

**예시**: 이미 수백만 장의 일반 사물 이미지로 학습된 이미지 분류 모델을 가져와, 회사가 보유한 수백 장의 특정 부품 사진만으로 마지막 층을 다시 학습시키면, 처음부터 새로 학습시키는 것보다 훨씬 적은 데이터로도 부품을 잘 구분하는 모델을 얻을 수 있다(전이학습). 이 과정에서 배치 크기와 드롭아웃 비율을 조정하며 과적합 여부를 계속 확인한다.

---

<aside>핵심 정리</aside>

- 과적합은 훈련 데이터에만 잘 맞고 새로운 데이터에는 성능이 떨어지는 현상이며, 드롭아웃·데이터 증강·조기 종료·정규화로 방지한다
- 배치 크기는 크다고 항상 좋은 것이 아니라 메모리·일반화 성능과 트레이드오프 관계에 있다
- 전이학습은 사전학습 모델을 가져와 적은 데이터로 미세조정하는 방법으로, 데이터가 부족한 로봇 훈련에 특히 유용하다
